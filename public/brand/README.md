# brand

제공자 로그인 버튼 심볼. **손으로 그리지 않고 각사 공식 가이드의 파일을 그대로 쓴다.**

| 파일         | 출처                                                                                                                               |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `kakao.svg`  | Kakao Developers › 카카오 로그인 › 디자인 가이드 (https://developers.kakao.com/docs/latest/ko/kakaologin/design-guide) 의 심볼     |
| `google.svg` | Google Identity › Sign in with Google branding guidelines (https://developers.google.com/identity/branding-guidelines) 의 "G" 로고 |

- 버튼 색·여백은 같은 가이드를 따른다(카카오 배경 #FEE500 · 라벨 #191919, Google 흰 배경 · 회색 테두리).
- 파일이 없어도 앱·테스트·E2E 는 동작한다(`<img alt="">` 가 비어 보일 뿐). 저장소에 넣기 전 사용 조건을 확인한다.
