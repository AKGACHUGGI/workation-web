# W-02 티어리스트 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/tier`에서 12개 시군구(또는 행정동)를 프리셋 종합 점수 또는 지표 하나로 S/A/B/C 등급으로 나눠 보여 주고, 이후 페이지(W-03·W-04·W-05·W-01·W-08)가 재사용할 tier 데이터 레이어·mock·공통 계산을 만든다.

**Architecture:** `GET /api/tier?month&scope` 응답(`TierResponse`)만 서버에서 받고, 탭·프리셋·직접 설정·개별 지표·시군구 필터는 모두 프론트 순수 함수(`buildTiers`, `filterTiers`, `toTierMode`)로 다시 계산한다. URL 쿼리가 화면 상태의 진실이며(`useTierParams`), mock 모드는 `features/tier/api.ts`가 `@/mocks/tier`를 동적 import해 10월 수작업 픽스처 + 결정적 생성기로 응답을 만든다.

**Tech Stack:** React 19 · TypeScript 6 · Vite 8 · Tailwind v4 토큰 · react-router-dom 7 · @tanstack/react-query 5 · Vitest 5 + Testing Library · Playwright · Python 3 + pandas(mock 생성 스크립트, CI 밖)

- 조용한 곳 `Q = (3q + 3c + p + o) / 8`

- 직접 설정(조용·시기·숙박) `C = (q + c + o) / 3`

- 활기 순위(원 점수): 전주 69.89 · 제주 64 · 서귀포 61.67 · 속초 56.89 · 강릉 55.22 · 순천 54.89 · 고성 47(7위) · 동해 44.67 · 양양 42.89 · 부안 40.89 · 정읍 34.89 · 고흥 17.11 — 스펙과 일치.
- 직접 설정 순위(원 점수): 양양 67 · 고성 56 · 속초 51 · 부안 39 · 서귀포 38 · 강릉 36 · 동해 35.33 = 전주 35.33(동점 → 이름순 동해 먼저) · 제주 32 · 순천 30 · 고흥 28 · 정읍 21.

**스펙과 다른 점 2가지 (불가능 증명 포함):**

1. **전주 직접 설정 35점 (스펙 34점).** `p = 8Q − 9C + 2o`에서 전주(Q 52, C 34)는 반올림 허용 범위(8Q ≥ 412, 9C < 310.5)를 넣어도 `p ≥ 101.5 + 2o`가 되어 `p ≤ 100`을 만족할 수 없다. 가장 가까운 해는 C = 35.33(표시 35)이며 순위(동해와 동점, 이름순으로 동해 다음)는 스펙과 같다.
2. **강릉 숙박 성향 S(86) (요청 등급 A).** 강릉(Q 29, C 36)에서 또래 S(p ≥ 75)를 지키려면 `o ≥ 84`가 필요해 숙박을 A(≤ 74)로 둘 수 없다. 또래 S를 우선했다. W-08 즐겨찾기 mock은 자체 점수를 가지므로 영향이 없다.

`overnight`는 연중 상수다. 생성기(`deriveMonth`)와 `scripts/gen-mock.py` 모두 달마다 바꾸지 않는다.

```ts
import type { MonthParam } from '@/features/metric/month'
import type { Grade, MetricKey, MetricScores, Weights } from '@/features/metric/types'

export type { MonthParam } from '@/features/metric/month'

export type TierScope = 'sigungu' | 'dong'
export type TierTab = 'value' | 'metric'
export type Terrain = 'coast' | 'mountain' | 'city'

/** GET /api/tier?month={month}&scope={scope} — 백엔드 계약 */
export type TierResponse = {
  month: MonthParam
  scope: TierScope
  items: TierItem[]
}

export type TierItem = {
  id: string // 시군구코드(5자리) 또는 행정동코드(10자리)
  name: string // "양양군" / "거진읍"
  province: string // "강원특별자치도"
  sigungu?: { id: string; name: string } // scope=dong 일 때 필수
  photoUrl: string
  scores: MetricScores // 0~100 정수, 같은 month·scope 안의 백분위
  inherited: MetricKey[] // 상위 단위 값을 물려받은 지표. dong → ['overnight'], sigungu → []
  terrain: Terrain[] // 지형(수동 관리). 행정동은 소속 시군구 값. W-01 지형 필터가 쓴다
}

/** 등급 계산 기준. selected 는 직접 설정에서 고르지 않은 지표를 흐리게 표시할 때만 쓴다 */
export type TierMode =
  { tab: 'value'; weights: Weights; selected?: MetricKey[] } | { tab: 'metric'; metric: MetricKey }

/** score 는 반올림 전 값. 화면 표시는 Math.round */
export type TierEntry = { item: TierItem; score: number; grade: Grade }
export type TierGroup = { grade: Grade; entries: TierEntry[] }
```

```ts
import { composite, toGrades } from '@/features/metric/score'
import { GRADES, METRIC_KEYS } from '@/features/metric/types'
import type { MetricKey, Weights } from '@/features/metric/types'
import type { TierEntry, TierGroup, TierItem, TierMode } from '@/features/tier/types'

/** 직접 설정: 선택한 지표 1, 나머지 0 */
export function customWeights(selected: readonly MetricKey[]): Weights {
  return Object.fromEntries(METRIC_KEYS.map((k) => [k, selected.includes(k) ? 1 : 0])) as Weights
}

function scoreOf(item: TierItem, mode: TierMode): number {
  return mode.tab === 'value' ? composite(item.scores, mode.weights) : item.scores[mode.metric]
}

function compareEntries(a: TierEntry, b: TierEntry): number {
  return b.score - a.score || a.item.name.localeCompare(b.item.name, 'ko')
}

/** 점수 → 사분위 등급 → S·A·B·C 4개 그룹(빈 그룹 포함) */
export function buildTiers(items: TierItem[], mode: TierMode): TierGroup[] {
  const scores = items.map((item) => scoreOf(item, mode))
  const grades = toGrades(scores)
  const entries: TierEntry[] = items.map((item, i) => ({
    item,
    score: scores[i],
    grade: grades[i],
  }))
  return GRADES.map((grade) => ({
    grade,
    entries: entries.filter((e) => e.grade === grade).sort(compareEntries),
  }))
}

/** 등급 계산 뒤에 시군구로 거른다. 필터는 등급을 바꾸지 않는다 */
export function filterTiers(groups: TierGroup[], sgg: string): TierGroup[] {
  if (sgg === 'all') return groups
  return groups.map((g) => ({ ...g, entries: g.entries.filter((e) => e.item.sigungu?.id === sgg) }))
}
```

```ts
import { monthNumber } from '@/features/metric/month'
import type { MonthParam } from '@/features/metric/month'
import type { MetricKey } from '@/features/metric/types'
import type { TierItem } from '@/features/tier/types'

/** 문자열 → 32비트 부호 없는 정수 (결정적) */
export function hashStr(s: string): number {
  let h = 0
  for (let i = 0; i < s.length; i++) h = (h * 31 + s.charCodeAt(i)) >>> 0
  return h
}

/** 값 배열 → 백분위(0~100 정수). 자기보다 작은 값의 비율. 1개면 50 */
export function toPercentiles(values: number[]): number[] {
  const n = values.length
  if (n < 2) return values.map(() => 50)
  return values.map((v) => Math.round((100 * values.filter((x) => x < v).length) / (n - 1)))
}

/** -20 ~ +20 결정적 흔들림. annual 은 m = 0 */
function offset(id: string, key: MetricKey, m: number): number {
  return ((hashStr(`${id}:${key}`) + m * 37) % 41) - 20
}

/**
 * 10월 픽스처에서 다른 달(또는 연간)을 만든다. scripts/gen-mock.py 결과(generated/)가 없을 때 쓰는 대체물.
 * quiet·crowd·peer·vibe 는 흔든 뒤 같은 집합 안에서 다시 백분위로 바꾸고, overnight 는 연중 상수라 그대로 둔다.
 */
export function deriveMonth(base: TierItem[], month: MonthParam): TierItem[] {
  if (month === '2025-10') return base
  const m = monthNumber(month) ?? 0
  const column = (key: MetricKey) =>
    toPercentiles(base.map((it) => it.scores[key] + offset(it.id, key, m)))
  const quiet = column('quiet')
  const crowd = column('crowd')
  const peer = column('peer')
  const vibe = column('vibe')
  return base.map((it, i) => ({
    ...it,
    scores: {
      quiet: quiet[i],
      crowd: crowd[i],
      peer: peer[i],
      overnight: it.scores.overnight,
      vibe: vibe[i],
    },
  }))
}
```

```ts
import { parseMetrics, serializeMetrics } from '@/features/metric/params'
import { METRIC_KEYS } from '@/features/metric/types'
import type { MetricKey } from '@/features/metric/types'
import type { TierScope, TierTab } from '@/features/tier/types'

/** 직접 설정 기본 선택 (스펙 §4) */
export const DEFAULT_METRICS: MetricKey[] = ['quiet', 'crowd', 'overnight']

export function parseTab(raw: string | null): TierTab | null {
  return raw === 'value' || raw === 'metric' ? raw : null
}

export function parseScope(raw: string | null): TierScope | null {
  return raw === 'sigungu' || raw === 'dong' ? raw : null
}

export function parseMetricKey(raw: string | null): MetricKey | null {
  return raw !== null && (METRIC_KEYS as readonly string[]).includes(raw)
    ? (raw as MetricKey)
    : null
}

/** 'all' 또는 시군구 코드 5자리. 응답에 없는 id 는 페이지가 데이터를 받은 뒤 'all' 로 고친다 */
export function parseSgg(raw: string | null): string | null {
  return raw === 'all' || (raw !== null && /^\d{5}$/.test(raw)) ? raw : null
}

/** 값 자체는 유효하지만 조합·표기를 고쳐야 하는 경우. 고칠 게 없으면 null */
export function correctTierParams(sp: URLSearchParams): URLSearchParams | null {
  const next = new URLSearchParams(sp)
  let changed = false
  if (sp.get('scope') === 'dong' && sp.get('metric') === 'overnight') {
    next.set('metric', 'quiet')
    changed = true
  }
  const raw = sp.get('metrics')
  const parsed = parseMetrics(raw)
  if (raw !== null && parsed !== null && serializeMetrics(parsed) !== raw) {
    next.set('metrics', serializeMetrics(parsed))
    changed = true
  }
  return changed ? next : null
}
```

```ts
import { useEffect } from 'react'
import { useSearchParams } from 'react-router-dom'
import type { MonthParam } from '@/features/metric/month'
import { parseMetrics, serializeMetrics } from '@/features/metric/params'
import type { MetricKey, PresetKey } from '@/features/metric/types'
import {
  correctTierParams,
  DEFAULT_METRICS,
  parseMetricKey,
  parseScope,
  parseSgg,
  parseTab,
} from '@/features/tier/params'
import type { TierScope, TierTab } from '@/features/tier/types'
import { useMonthParam, usePresetParam, useQueryState } from '@/hooks/useQueryState'
import type { SetQueryState } from '@/hooks/useQueryState'

export type TierParams = {
  tab: TierTab
  setTab: SetQueryState<TierTab>
  preset: PresetKey
  setPreset: SetQueryState<PresetKey>
  metrics: MetricKey[]
  setMetrics: SetQueryState<MetricKey[]>
  metric: MetricKey
  setMetric: SetQueryState<MetricKey>
  scope: TierScope
  setScope: SetQueryState<TierScope>
  sgg: string
  setSgg: SetQueryState<string>
  month: MonthParam
  setMonth: SetQueryState<MonthParam>
}

/** W-02 URL 상태 (스펙 §4). 모든 변경은 push, 보정은 replace */
export function useTierParams(): TierParams {
  const [searchParams, setSearchParams] = useSearchParams()
  const [tab, setTab] = useQueryState<TierTab>('tab', parseTab, 'value')
  const [preset, setPreset] = usePresetParam()
  const [metrics, setMetrics] = useQueryState<MetricKey[]>(
    'metrics',
    parseMetrics,
    DEFAULT_METRICS,
    serializeMetrics,
  )
  const [metric, setMetric] = useQueryState<MetricKey>('metric', parseMetricKey, 'quiet')
  const [scope, setScope] = useQueryState<TierScope>('scope', parseScope, 'sigungu')
  const [sgg, setSgg] = useQueryState<string>('sgg', parseSgg, 'all')
  const [month, setMonth] = useMonthParam()

  const needsCorrection = correctTierParams(searchParams) !== null
  useEffect(() => {
    if (!needsCorrection) return
    setSearchParams((prev) => correctTierParams(prev) ?? prev, { replace: true })
  }, [needsCorrection, searchParams, setSearchParams])

  return {
    tab,
    setTab,
    preset,
    setPreset,
    metrics,
    setMetrics,
    metric,
    setMetric,
    scope,
    setScope,
    sgg,
    setSgg,
    month,
    setMonth,
  }
}
```

```ts
import {
  METRIC_DEFINITION,
  METRIC_LABEL,
  METRIC_SHORT_LABEL,
  PRESET_LABEL,

import type { Grade, MetricKey, PresetKey } from '@/features/metric/types'
import type { TierTab } from '@/features/tier/types'

export type TierCopyParams = {
  tab: TierTab
  preset: PresetKey
  metrics: MetricKey[]
  metric: MetricKey
}

export const TIER_RANGE: Record<Grade, string> = {
  S: '상위 25%',
  A: '상위 25~50%',
  B: '하위 25~50%',
  C: '하위 25%',
}

/** 개별 지표 S 등급 설명 (Figma 문구는 quiet. 나머지는 같은 형식, 디자인 검수 대상) */
const METRIC_TOP: Record<MetricKey, string> = {
  quiet: '동네 조용함 · 낮 유입 지수 낮음',
  crowd: '시기 여유 · 이 달 혼잡도 낮음',
  peer: '또래 밀도 · 20~40대 비중 높음',
  overnight: '숙박 성향 · 머무는 방문객 많음',
  vibe: '저녁 활기 · 저녁 유동 많음',
}

const METRIC_BOTTOM: Record<MetricKey, string> = {
  quiet: '낮에 사람이 몰리는 지역',
  crowd: '이 달 사람이 몰리는 지역',
  peer: '또래 비중이 낮은 지역',
  overnight: '당일 방문 위주 지역',
  vibe: '저녁이 한산한 지역',
}

/** 등급 패널 설명 (스펙 §6 TIER_COPY) */
export function tierDescription(p: TierCopyParams, grade: Grade): string {
  if (grade === 'A') return '평균 이상'
  if (grade === 'B') return '평균 이하'
  if (p.tab === 'metric') return grade === 'S' ? METRIC_TOP[p.metric] : METRIC_BOTTOM[p.metric]
  if (p.preset === 'custom') {
    const labels = p.metrics.map((k) => METRIC_SHORT_LABEL[k]).join(' · ')
    return grade === 'S' ? `직접 설정 종합 점수 (${labels})` : '선택한 조건과 거리 있음'
  }
  const label = PRESET_LABEL[p.preset]
  return grade === 'S' ? `${label} 프리셋 종합 점수` : `${label} 조건과 거리 있음`
}

const ABBR =
  '카드의 세부 등급은 조용 = 동네 조용함, 시기 = 시기 여유, 또래 = 또래 밀도, 숙박 = 숙박 성향, 활기 = 저녁 활기.'
const MASK = '마스킹 비율 30% 초과 행정동은 비공개.'
const group = (keys: MetricKey[]) => keys.map((k) => METRIC_LABEL[k]).join(' · ')

/** 하단 주석 (스펙 §3-6) */
export function tierFootnote(p: TierCopyParams): string {
  if (p.tab === 'metric') {
    return [
      '개별 지표 탭은 선택한 지표 하나의 백분위로 등급을 나눕니다.',
      `${METRIC_DEFINITION[p.metric]}.`,
      `동네 성격 그룹(${group(['quiet', 'peer', 'vibe'])})은 행정동 단위가 기본, 시기 · 체류 그룹(${group(['crowd', 'overnight'])})은 시군구 단위.`,
      MASK,
    ].join(' ')
  }
  if (p.preset === 'custom') {
    return [
      '직접 설정에서는 고른 지표만 같은 가중치로 평균해 등급을 나눕니다. 고르지 않은 지표의 세부 등급은 흐리게 표시.',
      ABBR,
      MASK,
    ].join(' ')
  }
  return [
    '등급은 선택한 프리셋의 종합 점수를 같은 단위 안에서 사분위로 나눈 것입니다.',
    ABBR,
    MASK,
  ].join(' ')
}
```

```python
#!/usr/bin/env python3
"""W-02 tier mock 생성기.

사용법: python scripts/gen-mock.py <processed_dir> <feature_dir>
출력:   src/mocks/tier/generated/{sigungu|dong}-{annual|2025-MM}.json (26개)

백분위 규칙은 W-02 스펙 §5 (백엔드 계약과 동일):
- 같은 month·scope 안의 모든 단위가 모집단, 0~100 정수
- quiet(day_inflow)·crowd 는 낮을수록 높은 점수, peer·vibe·overnight 는 높을수록
- overnight 는 시군구 숙박 계수의 12개월 평균(연중 상수). 행정동은 소속 시군구 값을 행정동 모집단에서 다시 백분위
- 마스킹 비율 30% 초과·특수시설 행정동은 제외 (모집단에서도 제외)
- annual 은 12개월 원천 값 평균으로 백분위
"""
import json
import sys
from pathlib import Path

import pandas as pd

ROOT = Path(__file__).resolve().parent.parent
OUT = ROOT / 'src' / 'mocks' / 'tier' / 'generated'
MONTHS = [f'2025-{m:02d}' for m in range(1, 13)]
METRICS = ['quiet', 'crowd', 'peer', 'vibe', 'overnight']
HIGHER_IS_BETTER = {'quiet': False, 'crowd': False, 'peer': True, 'vibe': True, 'overnight': True}

# 원본 CSV 컬럼 → 내부 이름. 컬럼명이 다르면 이 사전만 고친다.
SGG_COLUMNS = {
    'sgg_id': 'id', 'sgg_name': 'name', 'month': 'month',
    'day_inflow': 'quiet', 'crowd': 'crowd', 'peer_share': 'peer',
    'evening_vibe': 'vibe', 'overnight_coef': 'overnight',
}
DONG_COLUMNS = {
    'dong_id': 'id', 'dong_name': 'name', 'sgg_id': 'sgg', 'month': 'month',
    'day_inflow': 'quiet', 'crowd_dong': 'crowd', 'peer_share': 'peer',
    'evening_vibe': 'vibe', 'special_facility': 'special',
}
MASK_COLUMNS = {'dong_id': 'id', 'mask_ratio': 'mask_ratio'}


def percentile(values: pd.Series, higher_is_better: bool) -> pd.Series:
    """작은 값이 0, 큰 값이 100 (lower-is-better 면 반대). 동점은 같은 값."""
    n = len(values)
    if n < 2:
        return pd.Series([50] * n, index=values.index)
    rank = values.rank(method='min', ascending=higher_is_better)
    return ((rank - 1) / (n - 1) * 100).round().astype(int)


def pick(df: pd.DataFrame, month: str) -> pd.DataFrame:
    if month != 'annual':
        return df[df['month'] == month].copy()
    keys = ['id', 'name'] + (['sgg'] if 'sgg' in df.columns else [])
    return df.groupby(keys, as_index=False)[METRICS].mean()


def score_rows(df: pd.DataFrame, with_sgg: bool) -> list[dict]:
    df = df.reset_index(drop=True)
    scores = {k: percentile(df[k], HIGHER_IS_BETTER[k]) for k in METRICS}
    rows = []
    for i, r in df.iterrows():
        row = {'id': str(r['id']), 'name': str(r['name']), 'scores': {k: int(scores[k][i]) for k in METRICS}}
        if with_sgg:
            row['sggId'] = str(r['sgg'])
        rows.append(row)
    return rows


def write(scope: str, month: str, rows: list[dict]) -> None:
    path = OUT / f'{scope}-{month}.json'
    path.write_text(json.dumps(rows, ensure_ascii=False, indent=1) + '\n', encoding='utf-8')
    print(f'{path.relative_to(ROOT)}  {len(rows)}개')


def main(processed_dir: Path, feature_dir: Path) -> None:
    sgg = pd.read_csv(feature_dir / 'sgg_month_features.csv', dtype={'sgg_id': str}).rename(columns=SGG_COLUMNS)
    dong = pd.read_csv(feature_dir / 'dong_month_features.csv', dtype={'dong_id': str, 'sgg_id': str}).rename(
        columns=DONG_COLUMNS
    )
    mask = pd.read_csv(processed_dir / 'dong_mask_ratio.csv', dtype={'dong_id': str}).rename(columns=MASK_COLUMNS)

    overnight = sgg.groupby('id')['overnight'].mean()  # 연중 상수
    sgg['overnight'] = sgg['id'].map(overnight)

    dong = dong.merge(mask, on='id', how='left')
    dong = dong[(dong['mask_ratio'].fillna(0) <= 0.3) & (dong['special'].fillna(0) == 0)]
    dong['overnight'] = dong['sgg'].map(overnight)

    OUT.mkdir(parents=True, exist_ok=True)
    for month in ['annual', *MONTHS]:
        write('sigungu', month, score_rows(pick(sgg, month), with_sgg=False))
        write('dong', month, score_rows(pick(dong, month), with_sgg=True))


if __name__ == '__main__':
    if len(sys.argv) != 3:
        sys.exit('usage: python scripts/gen-mock.py <processed_dir> <feature_dir>')
    main(Path(sys.argv[1]), Path(sys.argv[2]))
```
