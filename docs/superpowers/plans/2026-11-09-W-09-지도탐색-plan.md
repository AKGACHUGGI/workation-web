# W-09 지도 탐색 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/explore`에서 태그(최대 3개)를 고르면 해당 동이 지도에 뜨고(①), 동을 누르면 동 중심 태그·장소 그래프가 지도 위에 그려지며(②), 장소를 누르면 정보가 열리는(③) 탐색 페이지를 만든다.

**Architecture:** `GET /api/explore/graph`를 진입 시 1회 받아 `indexGraph`로 조회용 맵을 만들고, 이후 모든 계산(일치 동·화면 밖 개수·범위 요약·가지 배치)은 `features/explore/`의 순수 함수로 한다. URL(`tags`·`match`·`dong`·`place`)이 화면 단계를 정하고, 지도는 W-04의 `components/map/`(Provider·Placeholder·PolygonLayer) 위에 `AdvancedMarker`·`Polyline`·`@googlemaps/markerclusterer`를 얹는다. 지도 키가 없으면 지도만 `MapPlaceholder`로 바뀌고 태그 바·패널은 그대로 동작하므로 Vitest·E2E는 키 없이 패널로 검증한다.

**Tech Stack:** React 19 · TypeScript 6 · TanStack Query 5 · @vis.gl/react-google-maps 1.x · @googlemaps/markerclusterer 2.x · Tailwind v4 토큰 · lucide-react · Vitest · Playwright

## Global Constraints

- LG U+ 기업연계 과제: 지도는 **Google Maps만** (`@vis.gl/react-google-maps`). 카카오맵·네이버맵 금지.
- 웹 데스크톱만. Figma 1440px 기준, 최소 폭 1128px(`min-w-desktop`). 모바일·다크 모드는 범위 밖.
- 본문 폰트는 공통 기반 `--font-sans` 그대로. 폰트 설정을 바꾸지 않는다.
- 색·치수·타이포는 `src/index.css` `@theme` 토큰만. **임의 hex·임의값(`[...]`) 금지.** 묶음 색은 `--color-explore-group-*`, 지도 색은 `--color-explore-map-*` CSS 변수. Maps API에 넘기는 색은 `resolveToken('var(--…)')`로 해석한다(Polygon·Polyline). DOM 마커 안의 색은 `style={{ color: 'var(--…)' }}`로 그대로 쓴다.
- 파일 1개 = 컴포넌트 1개 `export default function`. 컴포넌트 파일에서 상수를 export하지 않는다(상수는 `copy.ts`·`view.ts` 등 `.ts`에).
- `erasableSyntaxOnly`: `enum` 금지, `as const` + 유니온. `verbatimModuleSyntax`: 타입은 `import type`.
- 백엔드 호출은 `lib/api.ts`의 `api<T>()`로만. mock은 `isMock`일 때 `src/mocks/explore`를 동적 import. 정적 GeoJSON은 `lib/staticJson.ts`.
- `pages/`는 다른 `pages/`를 import하지 않는다. `features/explore`는 `features/metric`·`features/dong`(geo 훅·키)만 import한다.
- 태그는 12개. `food`(음식점 많음) 태그와 음식점 장소는 넣지 않는다.
- 장소 출처 "한국관광공사" 표기 필수(③ 출처 박스, 범례 데이터 한계 문구).
- URL: `tags`·`match`는 `replace`, `dong`·`place` 진입·해제는 `push`. 지도 중심·줌은 URL에 넣지 않는다. 패널 접힘도 URL에 넣지 않는다.
- 화면 문자열은 `features/explore/copy.ts`의 `EXPLORE_COPY`에서 가져온다.
- 커밋은 Conventional Commits. 커밋 전 `pnpm lint && pnpm format:check && pnpm build && pnpm test` 통과.

```python
#!/usr/bin/env python3
"""W-09 탐색 mock 기반 자료 생성기.

사용법: python3 scripts/gen-explore-base.py
입력:   public/geo/sigungu.json, public/geo/{시군구코드}.json (12개)
출력:   src/mocks/explore/base.generated.ts

- 시군구: id·이름·도 id(코드 앞 2자리)·중심(labelLat/labelLng)
- 행정동: id·이름·시군구 id·중심(labelLat/labelLng = ST_PointOnSurface)·bbox([west, south, east, north], 소수 5자리)
- 태그·장소·등급은 여기서 만들지 않는다 (src/mocks/explore/table.ts 수작업)
"""
import json
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
GEO = ROOT / 'public' / 'geo'
OUT = ROOT / 'src' / 'mocks' / 'explore' / 'base.generated.ts'

HEADER = """// 자동 생성 — python3 scripts/gen-explore-base.py. 직접 고치지 않는다 (원본: public/geo)
import type { BBox, ExploreSigungu, LatLng } from '@/features/explore/types'

export type DongBase = { id: string; name: string; sigunguId: string; center: LatLng; bbox: BBox }

"""


def points(coords):
    if isinstance(coords[0], (int, float)):
        yield coords
        return
    for c in coords:
        yield from points(c)


def bbox(geometry):
    pts = list(points(geometry['coordinates']))
    xs = [p[0] for p in pts]
    ys = [p[1] for p in pts]
    return [round(min(xs), 5), round(min(ys), 5), round(max(xs), 5), round(max(ys), 5)]


def main():
    sigungu = json.loads((GEO / 'sigungu.json').read_text(encoding='utf-8'))['features']
    sgg_rows, dong_rows = [], []
    for f in sorted(sigungu, key=lambda f: f['properties']['id']):
        p = f['properties']
        sgg_rows.append({
            'id': p['id'], 'name': p['name'], 'provinceId': p['id'][:2],
            'center': {'lat': p['labelLat'], 'lng': p['labelLng']},
        })
        dongs = json.loads((GEO / f"{p['id']}.json").read_text(encoding='utf-8'))['features']
        for d in dongs:
            q = d['properties']
            dong_rows.append({
                'id': q['id'], 'name': q['name'], 'sigunguId': p['id'],
                'center': {'lat': q['labelLat'], 'lng': q['labelLng']},
                'bbox': bbox(d['geometry']),
            })
    dong_rows.sort(key=lambda r: r['id'])
    body = (
        f"export const SIGUNGU_BASE: ExploreSigungu[] = {json.dumps(sgg_rows, ensure_ascii=False)}\n\n"
        f"export const DONG_BASE: DongBase[] = {json.dumps(dong_rows, ensure_ascii=False)}\n"
    )
    OUT.parent.mkdir(parents=True, exist_ok=True)
    OUT.write_text(HEADER + body, encoding='utf-8')
    print(f'{OUT.relative_to(ROOT)}: 시군구 {len(sgg_rows)} · 행정동 {len(dong_rows)}')


if __name__ == '__main__':
    main()
```

```ts
import type {
  DongGrades,

  ExploreDong,
  ExploreGraphResponse,
  ExplorePlace,
} from '@/features/explore/types'
import { GRADES } from '@/features/metric/types'
import { DONG_BASE, SIGUNGU_BASE } from '@/mocks/explore/base.generated'
import type { DongBase } from '@/mocks/explore/base.generated'
import {
  COAST_KM_OVERRIDE,
  GRADE_OVERRIDE,
  PLACE_NAMES,
  PLACE_NOUN,
  PROVINCES,
  SIMILAR_OVERRIDE,
  TAG_TABLE,
} from '@/mocks/explore/table'
import { EXPLORE_TAGS } from '@/mocks/explore/tags'

const round5 = (n: number) => Math.round(n * 1e5) / 1e5

/** 동 중심 주변에 황금각으로 흩뿌린다 (bbox 반폭의 12~30%) */
function spread(d: DongBase, i: number) {
  const [west, south, east, north] = d.bbox
  const angle = i * 2.39996
  const r = 0.12 + 0.06 * (i % 4)
  return {
    lat: round5(d.center.lat + Math.sin(angle) * r * (north - south)),
    lng: round5(d.center.lng + Math.cos(angle) * r * (east - west)),
  }
}

function grades(id: string): DongGrades | null {
  if (id in GRADE_OVERRIDE) return GRADE_OVERRIDE[id]
  const n = Number(id.slice(5, 8))
  return { quiet: GRADES[n % 4], peer: GRADES[(n + 1) % 4], evening: GRADES[(n + 2) % 4] }
}

function coastKm(id: string, hasCoast: boolean): number | null {
  if (!hasCoast) return null
  return COAST_KM_OVERRIDE[id] ?? Number((0.2 + (Number(id.slice(5, 8)) % 8) / 10).toFixed(1))
}

/** 태그를 가장 많이 공유하는 다른 동 상위 5 (덮어쓰기 우선) */
function similarOf(id: string, all: Map<string, Set<string>>): string[] {
  if (SIMILAR_OVERRIDE[id]) return SIMILAR_OVERRIDE[id]
  const mine = all.get(id)
  if (!mine || mine.size === 0) return []
  return [...all.entries()]
    .filter(([other]) => other !== id)
    .map(([other, tags]) => ({ other, shared: [...tags].filter((t) => mine.has(t)).length }))
    .filter((x) => x.shared > 0)
    .sort((a, b) => b.shared - a.shared || a.other.localeCompare(b.other))
    .slice(0, 5)
    .map((x) => x.other)
}

function build(): ExploreGraphResponse {
  const tagSets = new Map(
    Object.entries(TAG_TABLE).map(([id, row]) => [id, new Set(Object.keys(row))] as const),
  )
  const places: ExplorePlace[] = []
  const dongs: ExploreDong[] = DONG_BASE.map((base) => {
    const row = TAG_TABLE[base.id] ?? {}
    const tags: DongTag[] = EXPLORE_TAGS.filter((t) => t.id in row).map((t, ti) => {
      const v = row[t.id]
      if (v === true) return { tagId: t.id, placeCount: null }
      const names = PLACE_NAMES[`${base.id}:${t.id}`] ?? []
      for (let i = 0; i < v; i++) {
        const pos = spread(base, ti * 7 + i)
        places.push({
          id: '',
          name: names[i] ?? `${base.name} ${PLACE_NOUN[t.id]} ${i + 1}`,
          dongId: base.id,
          lat: pos.lat,
          lng: pos.lng,
          tag: t.id,
          image: null,
        })
      }
      return { tagId: t.id, placeCount: v }
    })
    return {
      id: base.id,
      name: base.name,
      sigunguId: base.sigunguId,
      center: base.center,
      bbox: base.bbox,
      grades: grades(base.id),
      tags,
      coastKm: coastKm(base.id, 'coast' in row),
      similar: similarOf(base.id, tagSets),
    }
  })
  // TourAPI contentid 처럼 7자리 숫자 문자열. 같은 길이라 문자열 순 = 생성 순
  places.forEach((p, i) => (p.id = String(2_800_001 + i)))
  return {
    syncedAt: '2026-11-09T00:00:00+09:00',
    tags: EXPLORE_TAGS,
    provinces: PROVINCES,
    sigungu: SIGUNGU_BASE,
    dongs,
    places,
  }
}
```

```ts
import type {
  ExploreDong,
  ExploreGraphResponse,
  ExplorePlace,
  ExploreProvince,
  ExploreSigungu,
  ExploreTag,
} from '@/features/explore/types'

export type GraphIndex = {
  res: ExploreGraphResponse
  tagById: Map<string, ExploreTag>
  provinceById: Map<string, ExploreProvince>
  sigunguById: Map<string, ExploreSigungu>
  dongById: Map<string, ExploreDong>
  placeById: Map<string, ExplorePlace>
  /** tagId → 그 태그가 있는 동 (집계 제외 동 빼고, 응답 순서) */
  dongsByTag: Map<string, ExploreDong[]>
  /** `${dongId}:${tagId}` → 장소 (응답 순서 = id 순) */
  placesByDongTag: Map<string, ExplorePlace[]>
}

const key = (dongId: string, tagId: string) => `${dongId}:${tagId}`

/** 응답을 받은 직후 1회. 이후 계산은 모두 이 맵으로 한다 */
export function indexGraph(res: ExploreGraphResponse): GraphIndex {
  const dongsByTag = new Map<string, ExploreDong[]>(res.tags.map((t) => [t.id, []]))
  for (const d of res.dongs) {
    if (d.excluded) continue
    for (const t of d.tags) dongsByTag.get(t.tagId)?.push(d)
  }
  const placesByDongTag = new Map<string, ExplorePlace[]>()
  for (const p of res.places) {
    const k = key(p.dongId, p.tag)
    const list = placesByDongTag.get(k)
    if (list) list.push(p)
    else placesByDongTag.set(k, [p])
  }
  return {
    res,
    tagById: new Map(res.tags.map((t) => [t.id, t])),
    provinceById: new Map(res.provinces.map((p) => [p.id, p])),
    sigunguById: new Map(res.sigungu.map((s) => [s.id, s])),
    dongById: new Map(res.dongs.map((d) => [d.id, d])),
    placeById: new Map(res.places.map((p) => [p.id, p])),
    dongsByTag,
    placesByDongTag,
  }
}

export function placesOf(index: GraphIndex, dongId: string, tagId: string): ExplorePlace[] {
  return index.placesByDongTag.get(key(dongId, tagId)) ?? []
}

export function hasTag(dong: ExploreDong, tagId: string): boolean {
  return dong.tags.some((t) => t.tagId === tagId)
}

/** branch 태그 장소 수. badge·없는 태그는 0 */
export function tagCount(dong: ExploreDong, tagId: string): number {
  return dong.tags.find((t) => t.tagId === tagId)?.placeCount ?? 0
}

export function provinceOf(index: GraphIndex, dong: ExploreDong): ExploreProvince | undefined {
  const sgg = index.sigunguById.get(dong.sigunguId)
  return sgg ? index.provinceById.get(sgg.provinceId) : undefined
}
```

```ts
export function inBounds(p: LatLng, b: Bounds): boolean {
  return p.lat >= b.south && p.lat <= b.north && p.lng >= b.west && p.lng <= b.east
}

export function bboxIntersects([west, south, east, north]: BBox, b: Bounds): boolean {
  return west <= b.east && east >= b.west && south <= b.north && north >= b.south
}

export function bboxToBoundsOf([west, south, east, north]: BBox): Bounds {
  return { west, south, east, north }

  return {
    west: Math.min(...bboxes.map((b) => b[0])),
    south: Math.min(...bboxes.map((b) => b[1])),
    east: Math.max(...bboxes.map((b) => b[2])),

 * 경로 바 (스펙 §3): 지도 중심이 bbox 안에 드는 동 중 중심이 가장 가까운 것, 없으면 전체에서 가장 가까운 동.
 * (폴리곤 포함 판정 대신 bbox + 중심 거리로 근사한다. 경계 파일 없이 계산하기 위함)
 * 줌 9 이상이면 시군구, 11 이상이면 행정동까지.
 */
export function breadcrumbAt(
  index: GraphIndex,
  center: LatLng,
  zoom: number,
): { province?: ExploreProvince; sigungu?: ExploreSigungu; dong?: ExploreDong } {
  const dongs = index.res.dongs.filter((d) => d.center)
  if (dongs.length === 0) return {}
  const byDistance = (a: ExploreDong, b: ExploreDong) =>
    dist2(center, a.center!) - dist2(center, b.center!)
  const containing = dongs.filter((d) => inBounds(center, bboxToBoundsOf(d.bbox))).sort(byDistance)
  const dong = containing[0] ?? [...dongs].sort(byDistance)[0]
  const sigungu = index.sigunguById.get(dong.sigunguId)
  const province = sigungu ? index.provinceById.get(sigungu.provinceId) : undefined
  return {
    province,
    sigungu: zoom >= 9 ? sigungu : undefined,
    dong: zoom >= 11 && containing.length > 0 ? dong : undefined,
  }
}

export function debounce<A extends unknown[]>(
  fn: (...args: A) => void,
  ms: number,
): ((...args: A) => void) & { cancel: () => void } {
  let timer: ReturnType<typeof setTimeout> | null = null
  const run = (...args: A) => {
    if (timer) clearTimeout(timer)
    timer = setTimeout(() => {
      timer = null
      fn(...args)
    }, ms)
  }
  run.cancel = () => {
    if (timer) clearTimeout(timer)
    timer = null
  }
  return run
}
```

```ts
import { EXPLORE_COPY, PROVINCE_SHORT, TAG_SHORT } from '@/features/explore/copy'
import { hasTag, provinceOf, tagCount } from '@/features/explore/indexGraph'
import type { GraphIndex } from '@/features/explore/indexGraph'
import type { Bounds, ExploreDong, MatchMode } from '@/features/explore/types'
import { inBounds, unionBounds } from '@/features/explore/view'

export type DongMatch = {
  dongId: string
  /** 고른 태그 중 이 동이 가진 것 (응답 tags 순서) */
  matched: string[]
  /** 고른 태그를 모두 가짐 → 검정 표시 */
  all: boolean
  /** 가진 branch 태그 장소 수 합 (정렬용) */
  placeTotal: number
}

export type ProvinceGroup = {
  provinceId: string
  name: string
  short: string
  count: number
  /** 그 도의 해당 동이 모두 보이는 범위 */
  bounds: Bounds
}

/** 고른 태그가 있는 동 (집계 제외 빼고). 장소 많은 순 → 이름 순 */
export function matchDongs(index: GraphIndex, tagIds: string[], mode: MatchMode): DongMatch[] {
  if (tagIds.length === 0) return []
  const ordered = index.res.tags.map((t) => t.id).filter((id) => tagIds.includes(id))
  const result: DongMatch[] = []
  for (const d of index.res.dongs) {
    if (d.excluded) continue
    const matched = ordered.filter((id) => hasTag(d, id))
    if (matched.length === 0) continue
    const all = matched.length === ordered.length
    if (mode === 'all' && !all) continue
    const placeTotal = matched.reduce((s, id) => s + tagCount(d, id), 0)
    result.push({ dongId: d.id, matched, all, placeTotal })
  }
  const nameOf = (id: string) => index.dongById.get(id)!.name
  return result.sort(
    (a, b) => b.placeTotal - a.placeTotal || nameOf(a.dongId).localeCompare(nameOf(b.dongId), 'ko'),
  )
}

/** 동 중심이 화면 안이면 inView. 중심이 없는 동은 어느 쪽에도 넣지 않는다 */
export function splitByView(
  index: GraphIndex,
  matches: DongMatch[],
  bounds: Bounds,
): { inView: DongMatch[]; offscreen: DongMatch[] } {
  const inView: DongMatch[] = []
  const offscreen: DongMatch[] = []
  for (const m of matches) {
    const c = index.dongById.get(m.dongId)?.center
    if (!c) continue
    ;(inBounds(c, bounds) ? inView : offscreen).push(m)
  }
  return { inView, offscreen }
}

/** 도별 개수 (많은 순 → 도 id 순). 줌 ~8 배지와 화면 밖 칩이 쓴다 */
export function groupByProvince(index: GraphIndex, matches: DongMatch[]): ProvinceGroup[] {
  const groups = new Map<string, { dongs: ExploreDong[] }>()
  for (const m of matches) {
    const d = index.dongById.get(m.dongId)
    const p = d ? provinceOf(index, d) : undefined
    if (!d || !p) continue
    const g = groups.get(p.id)
    if (g) g.dongs.push(d)
    else groups.set(p.id, { dongs: [d] })
  }
  return [...groups.entries()]
    .map(([provinceId, g]) => ({
      provinceId,
      name: index.provinceById.get(provinceId)!.name,
      short: PROVINCE_SHORT[provinceId] ?? index.provinceById.get(provinceId)!.name,
      count: g.dongs.length,
      bounds: unionBounds(g.dongs.map((d) => d.bbox)),
    }))
    .sort((a, b) => b.count - a.count || a.provinceId.localeCompare(b.provinceId))
}

/** 화면 밖 해당 동의 도별 개수 (왼쪽 아래 칩) */
export function countOffscreen(
  index: GraphIndex,
  matches: DongMatch[],
  bounds: Bounds,
): ProvinceGroup[] {
  return groupByProvince(index, splitByView(index, matches, bounds).offscreen)
}

/** 동 표시 hover: `{동} · {태그} {n} · …` / `누르면 {동} 중심 그래프로 확대` */
export function markerTooltip(
  index: GraphIndex,
  dong: ExploreDong,
  matched: string[],
): { title: string; hint: string } {
  const parts = matched.map((id) => {
    const short = TAG_SHORT[id] ?? id
    return index.tagById.get(id)?.display === 'badge' ? short : `${short} ${tagCount(dong, id)}`
  })
  return { title: [dong.name, ...parts].join(' · '), hint: EXPLORE_COPY.markerHint(dong.name) }
}
```

```ts
import type { GraphIndex } from '@/features/explore/indexGraph'
import type { Bounds, ExploreDong, ExploreTag } from '@/features/explore/types'
import { inBounds } from '@/features/explore/view'

export type TagSummary = { tag: ExploreTag; count: number }

/** ⓪ 패널·① "태그 더 고르기": 범위 안(동 중심 기준) 태그별 동 수, 태그 순서 */

    count: (index.dongsByTag.get(tag.id) ?? []).filter((d) => d.center && inBounds(d.center, bounds))

  }))

function cafeAndStay(dongs: ExploreDong[]) {
  let cafe = 0
  let stay = 0
  for (const d of dongs) {
    cafe += tagCount(d, 'cafe')
    stay += tagCount(d, 'long_stay') + tagCount(d, 'resort')
  }
  return `카페 ${cafe} · 숙소 ${stay}`
}

/** 태그 선택 전 행정동 라벨: `{이름} · 카페 n · 숙소 n` */

}
```

```ts
import { toLatLngPaths } from '@/components/map/geo'
import type { GeoGeometry } from '@/components/map/geo'
import { EXPLORE_COPY, GROUP_META } from '@/features/explore/copy'
import { hasTag, placesOf } from '@/features/explore/indexGraph'
import type { GraphIndex } from '@/features/explore/indexGraph'
import type { ExploreDong, ExplorePlace, LatLng, TagGroup } from '@/features/explore/types'

/** 가지당 지도에 그리는 장소 수 (나머지는 `+N곳 더`) */
export const BRANCH_PLACE_LIMIT = 5
/** ③ 고르지 않은 가지·핀 (토큰 --opacity-faded 와 같은 값. Maps API 는 숫자만 받는다) */
export const FADED_OPACITY = 0.4

export type Hub = {
  tagId: string
  label: string
  group: TagGroup
  /** 그 동·태그 장소 수 (= placeCount) */
  count: number
  position: LatLng
  /** 중심에서 가까운 순 최대 5 */
  places: ExplorePlace[]
  more: number
}

export type BranchLayout = {
  center: LatLng
  hubs: Hub[]
  /** 고른 badge 태그 중 그 동이 가진 것 → 중심 노드 아래 */
  badges: { tagId: string; text: string }[]
  /** 고른 branch 태그인데 그 동 장소가 0곳 → 패널 "이 동네엔 … 장소가 없어요" */
  missing: string[]
}

export type GraphEdge = {
  key: string
  from: LatLng
  to: LatLng
  color: string
  width: number
  opacity: number
}

const round5 = (n: number) => Math.round(n * 1e5) / 1e5
const at = (p: ExplorePlace): LatLng => ({ lat: p.lat, lng: p.lng })

function dist2(a: LatLng, b: LatLng): number {
  const k = Math.cos((a.lat * Math.PI) / 180)
  return (a.lat - b.lat) ** 2 + ((a.lng - b.lng) * k) ** 2
}

function centerOf(dong: ExploreDong): LatLng {
  if (dong.center) return dong.center
  const [w, s, e, n] = dong.bbox
  return { lat: (s + n) / 2, lng: (w + e) / 2 }
}

/** ② 동 중심 그래프 배치 (스펙 §3-3). 태그 순서는 응답 tags 순서 */
export function layoutBranches(index: GraphIndex, dong: ExploreDong, tagIds: string[]): BranchLayout {
  const center = centerOf(dong)
  const layout: BranchLayout = { center, hubs: [], badges: [], missing: [] }
  for (const tag of index.res.tags) {
    if (!tagIds.includes(tag.id)) continue
    if (tag.display === 'badge') {
      if (!hasTag(dong, tag.id)) continue
      const text =
        tag.id === 'coast' && dong.coastKm !== null
          ? EXPLORE_COPY.coastBadge(tag.label, dong.coastKm)
          : tag.label
      layout.badges.push({ tagId: tag.id, text })
      continue
    }
    const places = placesOf(index, dong.id, tag.id)
    if (places.length === 0) {
      layout.missing.push(tag.id)
      continue
    }
    const sorted = [...places].sort(
      (a, b) => dist2(center, at(a)) - dist2(center, at(b)) || a.id.localeCompare(b.id),
    )
    const meanLat = places.reduce((s, p) => s + p.lat, 0) / places.length
    const meanLng = places.reduce((s, p) => s + p.lng, 0) / places.length
    layout.hubs.push({
      tagId: tag.id,
      label: tag.label,
      group: tag.group,
      count: places.length,
      position: { lat: round5((center.lat + meanLat) / 2), lng: round5((center.lng + meanLng) / 2) },
      places: sorted.slice(0, BRANCH_PLACE_LIMIT),
      more: Math.max(0, places.length - BRANCH_PLACE_LIMIT),
    })
  }
  return layout
}

/** 가지 선. ③ 에서는 고른 장소의 가지만 진하게(4px), 나머지는 흐리게 */
export function graphEdges(layout: BranchLayout, selected: ExplorePlace | null): GraphEdge[] {
  const selectedHub = selected ? layout.hubs.find((h) => h.tagId === selected.tag) : undefined
  return layout.hubs.flatMap((hub) => {
    const color = GROUP_META[hub.group].color
    const active = !selectedHub || selectedHub === hub
    const trunk: GraphEdge = {
      key: `trunk:${hub.tagId}`,
      from: layout.center,
      to: hub.position,
      color,
      width: 5,
      opacity: active ? 1 : FADED_OPACITY,
    }
    const targets =
      selected && selectedHub === hub && !hub.places.some((p) => p.id === selected.id)
        ? [...hub.places, selected]
        : hub.places
    const twigs = targets.map<GraphEdge>((p) => {
      const isSelected = p.id === selected?.id
      return {
        key: `twig:${p.id}`,
        from: hub.position,
        to: at(p),
        color,
        width: isSelected ? 4 : 2,
        opacity: !selected || isSelected ? 1 : FADED_OPACITY,
      }
    })
    return [trunk, ...twigs]
  })
}

/** Maps 폴리곤이 날짜변경선에서 뒤집히지 않도록 ±179.99 로 둔 세계 사각형 (시계 방향) */
const WORLD: LatLng[] = [
  { lat: 85, lng: -179.99 },
  { lat: 85, lng: 0 },
  { lat: 85, lng: 179.99 },
  { lat: -85, lng: 179.99 },
  { lat: -85, lng: 0 },
  { lat: -85, lng: -179.99 },
]

function signedArea(ring: LatLng[]): number {
  let s = 0
  for (let i = 0; i < ring.length; i++) {
    const p = ring[i]
    const q = ring[(i + 1) % ring.length]
    s += p.lng * q.lat - q.lng * p.lat
  }
  return s
}

/** 스포트라이트: 세계를 덮고 선택 동만 구멍으로 뚫는다. 구멍은 바깥과 반대 방향이어야 비워진다 */
export function spotlightPaths(geometry: GeoGeometry): LatLng[][] {
  const outerSign = Math.sign(signedArea(WORLD))
  const holes = toLatLngPaths(geometry).map((ring) =>
    Math.sign(signedArea(ring)) === outerSign ? [...ring].reverse() : ring,
  )
  return [WORLD, ...holes]
}
```

```ts
import { useCallback, useEffect, useMemo } from 'react'
import { useSearchParams } from 'react-router-dom'
import { useToast } from '@/components/ui/toast/useToast'
import { EXPLORE_COPY, MAX_TAGS, TAG_ORDER } from '@/features/explore/copy'
import type { GraphIndex } from '@/features/explore/indexGraph'
import type { MatchMode } from '@/features/explore/types'

const KNOWN_TAGS = new Set<string>(TAG_ORDER)

export type ExploreState = {
  tags: string[]
  match: MatchMode
  dong: string | null
  place: string | null
  toggleTag: (tagId: string) => void
  setMatch: (mode: MatchMode) => void
  openDong: (dongId: string) => void
  openPlace: (placeId: string, dongId: string) => void
  closePlace: () => void
  closeDong: () => void
}

/** 스펙 §5 보정 규칙. 고칠 게 없으면 null */
export function sanitizeExploreParams(
  params: URLSearchParams,
  index?: GraphIndex,
): URLSearchParams | null {
  const next = new URLSearchParams(params)
  const rawTags = params.get('tags')
  if (rawTags !== null) {
    const known = [...new Set(rawTags.split(',').filter((id) => KNOWN_TAGS.has(id)))]
    if (known.length === 0 || known.length > MAX_TAGS) next.delete('tags')
    else if (known.join(',') !== rawTags) next.set('tags', known.join(','))
  }
  const match = params.get('match')
  if (match !== null && match !== 'any' && match !== 'all') next.delete('match')

  const dong = params.get('dong')
  const place = params.get('place')
  if (place !== null && dong === null) next.delete('place')
  if (index && dong !== null) {
    const d = index.dongById.get(dong)
    if (!d || d.excluded) {
      next.delete('dong')
      next.delete('place')
    } else if (place !== null) {
      const p = index.placeById.get(place)
      if (!p || p.dongId !== dong) next.delete('place')
    }
  }
  return next.toString() === params.toString() ? null : next
}

/** 태그 토글. 3개가 찬 상태에서 새 태그면 'limit' */
export function toggleTagList(selected: string[], tagId: string): string[] | 'limit' {
  if (selected.includes(tagId)) return selected.filter((id) => id !== tagId)
  if (selected.length >= MAX_TAGS) return 'limit'
  return [...selected, tagId]
}

/** /explore URL 상태 (tags·match·dong·place). index 는 그래프를 받은 뒤 넘긴다 */
export function useExploreState(index: GraphIndex | undefined): ExploreState {
  const [params, setParams] = useSearchParams()
  const toast = useToast()
  const fixed = useMemo(() => sanitizeExploreParams(params, index), [params, index])

  useEffect(() => {
    if (fixed) setParams(fixed, { replace: true })
  }, [fixed, setParams])

  const effective = fixed ?? params
  const tagsRaw = effective.get('tags')
  const tags = useMemo(() => (tagsRaw ? tagsRaw.split(',') : []), [tagsRaw])
  const match: MatchMode = effective.get('match') === 'all' ? 'all' : 'any'
  const dong = effective.get('dong')
  const place = effective.get('place')

  const update = useCallback(
    (edit: (next: URLSearchParams) => void, replace: boolean) =>
      setParams(
        (prev) => {
          const next = new URLSearchParams(prev)
          edit(next)
          return next
        },
        { replace },
      ),
    [setParams],
  )

  const toggleTag = useCallback(
    (tagId: string) => {
      const next = toggleTagList(tags, tagId)
      if (next === 'limit') {
        toast.show(EXPLORE_COPY.tagLimit)
        return
      }
      update((p) => (next.length > 0 ? p.set('tags', next.join(',')) : p.delete('tags')), true)
    },
    [tags, toast, update],
  )

  const setMatch = useCallback(
    (mode: MatchMode) => update((p) => (mode === 'all' ? p.set('match', 'all') : p.delete('match')), true),
    [update],
  )

  const openDong = useCallback(
    (dongId: string) =>
      update((p) => {
        p.set('dong', dongId)
        p.delete('place')
      }, false),
    [update],
  )

  const openPlace = useCallback(
    (placeId: string, dongId: string) =>
      update((p) => {
        p.set('dong', dongId)
        p.set('place', placeId)
      }, false),
    [update],
  )

  const closePlace = useCallback(() => update((p) => p.delete('place'), false), [update])

  const closeDong = useCallback(
    () =>
      update((p) => {
        p.delete('dong')
        p.delete('place')
      }, false),
    [update],
  )

  return { tags, match, dong, place, toggleTag, setMatch, openDong, openPlace, closePlace, closeDong }
}
```

```tsx
import { ChevronRight, MapPin } from 'lucide-react'
import { EXPLORE_COPY } from '@/features/explore/copy'
import type { breadcrumbAt } from '@/features/explore/view'

type Level = 'province' | 'sigungu' | 'dong'
type Props = {
  crumbs: ReturnType<typeof breadcrumbAt>
  onPick: (level: Level, id: string) => void
}

/** 경로 바 (지도 중심 기준). 항목을 누르면 그 범위로 이동 */
export default function PathBar({ crumbs, onPick }: Props) {

  if (crumbs.province) items.push({ level: 'province', id: crumbs.province.id, name: crumbs.province.name })
  if (crumbs.sigungu) items.push({ level: 'sigungu', id: crumbs.sigungu.id, name: crumbs.sigungu.name })
  if (crumbs.dong) items.push({ level: 'dong', id: crumbs.dong.id, name: crumbs.dong.name })
  return (
    <div className="flex items-center gap-4">
      <nav aria-label="경로" className="text-body-sm flex items-center gap-1">
        <MapPin className="text-text-secondary" size={16} aria-hidden />
        {items.map((item, i) => (
          <Fragment key={item.level}>
            {i > 0 && <ChevronRight className="text-text-tertiary" size={14} aria-hidden />}
            <button
              type="button"
              onClick={() => onPick(item.level, item.id)}
              className={
                i === items.length - 1
                  ? 'text-text-primary font-bold'
                  : 'text-text-secondary underline-offset-2 hover:underline'

              {item.name}
            </button>
          </Fragment>
```

```tsx
const SHADE_OPACITY = 0.22
const OUTLINE_WIDTH = 3

function bboxGeometry([w, s, e, n]: BBox): GeoGeometry {
  return {
    type: 'Polygon',
    coordinates: [
      [
        [w, s],
        [e, s],
        [e, n],
        [w, n],
        [w, s],
      ],
    ],
  }
}

/** ② 선택 동 스포트라이트. 경계 파일이 없으면 bbox 사각형으로 대신한다 */

  const geo = useGeoQuery(dong.sigunguId)
  const geometry = useMemo(
    () => geo.data?.features.find((f) => f.properties.id === dong.id)?.geometry ?? bboxGeometry(dong.bbox),
    [geo.data, dong.id, dong.bbox],
  )

  useEffect(() => {
    if (!map) return
    const ink = resolveToken('var(--color-explore-map-spotlight)')
    const shade = new google.maps.Polygon({
      map,
      paths: spotlightPaths(geometry),
      fillColor: ink,
      fillOpacity: SHADE_OPACITY,
      strokeWeight: 0,
      clickable: false,
    })
    const outline = new google.maps.Polygon({
      map,
      paths: toLatLngPaths(geometry),
      fillOpacity: 0,
      strokeColor: ink,
      strokeWeight: OUTLINE_WIDTH,
      clickable: false,
    })
    return () => {
      shade.setMap(null)
      outline.setMap(null)
    }
  }, [map, geometry])
```

```tsx
  /** 표시 중인 해당 동 id (경계 강조) */
  matchedIds: Set<string>
  provinceGroups: ProvinceGroup[]
  onFitBounds: (bounds: Bounds) => void
}

const BOUNDARY: PolygonStyle = {
  fill: 'var(--color-explore-map-boundary)',
  fillOpacity: 0,
  stroke: 'var(--color-explore-map-boundary)',
  strokeWidth: 1,
}
const MATCHED: PolygonStyle = {
  fill: 'var(--color-selected-bg)',
  fillOpacity: 0.06,
  stroke: 'var(--color-selected-bg)',
  strokeWidth: 2,
}
/** 집계 제외 동 (현재 대상 없음). Maps Polygon 은 점선을 못 그려 회색 채움으로 대신한다 */
const EXCLUDED: PolygonStyle = {
  fill: 'var(--color-explore-map-excluded)',
  fillOpacity: 0.6,
  stroke: 'var(--color-explore-map-boundary)',
  strokeWidth: 1,
}

const centerOf = (b: Bounds) => ({ lat: (b.south + b.north) / 2, lng: (b.west + b.east) / 2 })

/** 동 선택 전 바탕 층: 도 라벨·도별 배지, 시군구/행정동 경계와 라벨 */
export default function AreaLayer({ index, stage, bounds, tagIds, matchedIds, provinceGroups, onFitBounds }: Props) {
  const hasTags = tagIds.length > 0
  const sigunguGeo = useSigunguGeoQuery()
  const sggIds = useMemo(
    () => (stage === 'dong' || stage === 'place' ? visibleSigunguIds(index, bounds) : []),
    [stage, index, bounds],
  )
  const dongGeo = useVisibleDongGeo(sggIds)

  const sigunguStyle = useCallback((): PolygonStyle => BOUNDARY, [])
  const sigunguLabel = useCallback(
    (id: string) => (hasTags ? undefined : sigunguAreaLabel(index, id)),
    [hasTags, index],
  )
  const dongStyle = useCallback(
    (id: string): PolygonStyle => {
      if (index.dongById.get(id)?.excluded) return EXCLUDED
      return matchedIds.has(id) ? MATCHED : BOUNDARY
    },
    [index, matchedIds],
  )
  const dongLabel = useCallback(
    (id: string) => {
      const d = index.dongById.get(id)
      if (!d) return undefined
      if (d.excluded) return `${d.name} · ${EXPLORE_COPY.excluded}`
      return hasTags || stage === 'place' ? undefined : dongAreaLabel(d)
    },
    [hasTags, index, stage],
  )

  if (stage === 'province') {
    if (hasTags) {
      return (
        <>
          {provinceGroups.map((g) => (
            <AdvancedMarker
              key={g.provinceId}
              position={index.provinceById.get(g.provinceId)?.center ?? centerOf(g.bounds)}
              onClick={() => onFitBounds(g.bounds)}
            >
              <span className="bg-selected-bg text-selected-fg text-body-sm shadow-float cursor-pointer rounded-full px-3 py-1 font-bold">
                {EXPLORE_COPY.provinceBadge(g.short, g.count)}
              </span>
            </AdvancedMarker>
          ))}
        </>
      )
    }
    return (
      <>
        {index.res.provinces.map((p) =>
          p.center ? (
            <AdvancedMarker key={p.id} position={p.center}>
              <span className="text-heading-lg text-text-secondary">{p.name}</span>
            </AdvancedMarker>
          ) : null,
        )}
      </>
    )
  }

  if (stage === 'sigungu') {
    if (!sigunguGeo.data) return null
    return <PolygonLayer features={sigunguGeo.data} getStyle={sigunguStyle} getLabel={sigunguLabel} />
  }

  return <PolygonLayer features={dongGeo} getStyle={dongStyle} getLabel={dongLabel} />
}
```

```tsx
      )
    } else if (s.tags.length > 0) {
      panel = (
        <SelectedTagsCard
          index={index}
          tagIds={s.tags}
          anyCount={anyInView.length}
          allMatches={allInView}
          rows={rows}
          onToggle={s.toggleTag}
          onOpenDong={s.openDong}
        />
      )
    } else {
      panel = <RangeSummary rows={rows} selected={s.tags} onToggle={s.toggleTag} />
    }
  }

  return (
    <div className="min-w-desktop h-explore flex flex-col">
      <h1 className="sr-only">{EXPLORE_COPY.pageTitle}</h1>
      <div className="border-border-default flex h-12 shrink-0 items-center justify-between gap-4 border-b px-6">
        {index ? <PathBar crumbs={breadcrumbAt(index, view.center, view.zoom)} onPick={onPickCrumb} /> : <span />}
        <ZoomStage stage={zoomStage(view.zoom)} onPick={onPickStage} />
      </div>
      <div className="flex min-h-0 flex-1">
        <section aria-label={EXPLORE_COPY.mapRegion} className="relative min-w-0 flex-1">
          {graph.isPending ? (
            <ExploreSkeleton part="map" />
          ) : graph.isError || !index ? (
            <div className="bg-bg-subtle flex h-full items-center justify-center">
              <div role="alert" className="bg-bg-surface shadow-float flex flex-col items-center gap-3 rounded-xl px-8 py-6">
                <p className="text-body-base text-text-primary font-medium">{EXPLORE_COPY.loadError}</p>
                <button
                  type="button"
                  onClick={() => graph.refetch()}
                  className="bg-selected-bg text-selected-fg text-body-sm rounded-lg px-4 py-2 font-bold"
                >
                  {EXPLORE_COPY.retry}
                </button>
              </div>
            </div>
          ) : (
            <>
              <GoogleMapProvider
                fallback={<MapPlaceholder title={EXPLORE_COPY.mapNoKey} className="rounded-none border-0" />}
              >
                <ExploreMap
                  index={index}
                  view={view}
                  camera={camera}
                  onViewChange={onViewChange}
                  tagIds={s.tags}
                  shownMatches={shown}
                  inView={inView}
                  selectedDong={selectedDong}
                  layout={layout}
                  selectedPlace={selectedPlace}
                  onOpenDong={s.openDong}
                  onOpenPlace={s.openPlace}
                  onFitBounds={fitBounds}
                  onMore={onMore}
                />
              </GoogleMapProvider>

              <div className="pointer-events-none absolute inset-x-4 top-4 flex flex-col items-start gap-2">
                <div className="pointer-events-auto w-full">
                  <TagBar tags={index.res.tags} selected={s.tags} onToggle={s.toggleTag} />
                </div>
                {selectedDong ? (
                  <button
                    type="button"
                    onClick={s.closeDong}
                    className="bg-bg-surface shadow-float text-caption-xs text-text-primary pointer-events-auto inline-flex items-center gap-1 rounded-full px-3 py-1.5 font-bold"
                  >
                    <ChevronLeft size={14} aria-hidden />
                    {EXPLORE_COPY.backToTags(inView.length)}
                  </button>
                ) : s.tags.length > 1 ? (
                  <div className="pointer-events-auto">
                    <MatchModeToggle
                      mode={s.match}
                      anyCount={anyInView.length}
                      allCount={allInView.length}
                      onChange={s.setMatch}
                    />
                  </div>
                ) : null}
              </div>

              {emptyCombo && (
                <div className="pointer-events-none absolute inset-0 flex items-center justify-center">
                  <div className="bg-bg-surface shadow-float pointer-events-auto flex items-center gap-3 rounded-xl px-5 py-3">
                    <span className="text-body-sm text-text-primary font-medium">{EXPLORE_COPY.emptyCombo}</span>
                    {s.match === 'all' && (
                      <button
                        type="button"
                        onClick={() => s.setMatch('any')}
                        className="text-body-sm text-text-brand font-bold"
                      >
                        {EXPLORE_COPY.showAny}
                      </button>
                    )}
                  </div>
                </div>
              )}

              <div className="pointer-events-none absolute bottom-4 left-4 flex flex-col items-start gap-2">
                {!selectedDong && s.tags.length > 0 && (
                  <div className="pointer-events-auto">
                    <OffscreenChips groups={offscreenGroups} onPick={fitBounds} />
                  </div>
                )}
                <div className="pointer-events-auto">
                  <MapLegend mode={legendMode} tags={selectedTags} />
                </div>
              </div>
            </>
          )}
        </section>
        {!graph.isError && (
          <ExplorePanel collapsed={collapsed} onToggleCollapsed={() => setCollapsed((c) => !c)}>
            {panel}
          </ExplorePanel>
        )}
      </div>
    </div>
  )
}
```
