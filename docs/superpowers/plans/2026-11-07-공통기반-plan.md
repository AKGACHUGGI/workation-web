# 공통 기반 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** W-01~W-08 모든 페이지가 공유하는 레이아웃·공통 UI·지표/점수 로직·URL 상태·데이터 레이어·테스트/CI 기반을 구축한다.

**Architecture:** 기능 단위 폴더 구조(`components/`, `features/`, `hooks/`, `lib/`, `mocks/`, `pages/`). 서버 상태는 TanStack Query, 공유 선택 상태는 URL 쿼리스트링(`useQueryState`), mock 모드는 `VITE_USE_MOCK`으로 API 함수 안에서 분기한다. 점수→등급 계산은 `features/metric`의 순수 함수이며 다른 feature를 import하지 않는다.

**Tech Stack:** React 19 · TypeScript 6 · Vite 8 · Tailwind v4(`@theme` 토큰) · react-router-dom 7 · @tanstack/react-query 5 · lucide-react · @fontsource · Vitest 5 + Testing Library · Playwright(Chromium)

**Spec:** `docs/superpowers/specs/2026-11-06-공통기반-design.md`

## Global Constraints

- 웹 데스크톱만. Figma 1440px 기준, 최소 폭 1128px(`desktop` 브레이크포인트), 그보다 좁으면 가로 스크롤.
- 본문 폰트 맑은 고딕(시스템 폰트, 웹폰트 미포함). `--font-sans: 'Malgun Gothic', '맑은 고딕', 'Apple SD Gothic Neo', ui-sans-serif, system-ui, sans-serif`. 로고 Black Han Sans, 손글씨 Gaegu는 `@fontsource`로 포함(외부 CDN 없음).
- LG U+ 기업연계 과제: 국내 타 기업 API 자제. 지도는 Google Maps(W-04에서 도입), 로그인은 카카오·Google만(W-07).
- 색·폰트·라운드·그림자·타이포는 `src/index.css`의 `@theme` 토큰만 사용. 임의값(`text-[#222]`, `w-[420px]`) 금지. 새 치수가 필요하면 `@theme`에 토큰을 추가한다.
- 파일 1개 = 컴포넌트 1개 `export default function`. 컴포넌트 파일에서 상수를 함께 export하지 않는다(별도 파일).
- `erasableSyntaxOnly`: `enum` 금지. `as const` 배열 + 유니온 타입.
- `verbatimModuleSyntax`: 타입은 `import type`.
- 데이터 호출은 `lib/api.ts`의 `api<T>()`로만. 컴포넌트에서 `fetch` 직접 사용 금지.
- `pages/`는 다른 `pages/`를 import하지 않는다. `features/metric`은 다른 feature를 import하지 않는다. `components/ui`는 도메인을 모른다(예외: `GradeBadge`, `MetricCard`가 `features/metric` 타입만 import).
- 화면 문자열은 `METRIC_LABEL[key]`에서 가져온다. 옛 라벨(비혼잡·한적함·야간 활동·장기체류 적합도)은 쓰지 않는다.
- `METRIC_KEYS` 순서 `['quiet', 'crowd', 'peer', 'overnight', 'vibe']` 고정.
- 커밋은 Conventional Commits(`feat:`, `test:`, `chore:`, `docs:`). 커밋 전 `pnpm lint && pnpm format:check && pnpm build` 통과.
- 패키지 매니저 pnpm 11 (`npm`/`yarn` 차단됨). Node 22+.
- 사진(`public/mock-photos/`)은 저작권 확인 전 배포 환경에 올리지 않는다.

```tsx
import type { ReactElement } from 'react'
import { render } from '@testing-library/react'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { MemoryRouter, Route, Routes, useLocation } from 'react-router-dom'

/** 테스트에서 현재 URL(path+search)을 읽기 위한 프로브 */
function LocationProbe() {
  const location = useLocation()
  return <output data-testid="location">{location.pathname + location.search}</output>
}

type Options = { route?: string; path?: string }

/**
 * MemoryRouter + QueryClient 로 감싸서 렌더한다.
 * route: 초기 URL (예: '/tier?month=2025-10'), path: 매칭할 라우트 패턴 (기본 '*')
 * 화면의 data-testid="location" 으로 현재 URL 을 검증할 수 있다.
 */
export default function renderWithRouter(
  ui: ReactElement,
  { route = '/', path = '*' }: Options = {},
) {
  const client = new QueryClient({ defaultOptions: { queries: { retry: false } } })
  return render(
    <QueryClientProvider client={client}>
      <MemoryRouter initialEntries={[route]}>
        <Routes>
          <Route
            path={path}
            element={
              <>
                {ui}
                <LocationProbe />
              </>
            }
          />
        </Routes>
      </MemoryRouter>
    </QueryClientProvider>,
  )
}
```

```ts
import { METRIC_KEYS } from '@/features/metric/types'
import type { Grade, MetricScores, Weights } from '@/features/metric/types'

/** 가중 평균. 가중치 합이 0 이면 0 (호출부가 "지표를 하나 이상 고르세요" 를 보여준다). */
export function composite(scores: MetricScores, weights: Weights): number {
  let sum = 0
  let total = 0
  for (const key of METRIC_KEYS) {
    sum += scores[key] * weights[key]
    total += weights[key]
  }
  return total === 0 ? 0 : sum / total
}

/**
 * 사분위 등급. 값을 내림차순으로 순위 매긴 뒤 순위 비율(rank / n)로
 * ≤ 0.25 S, ≤ 0.5 A, ≤ 0.75 B, 그 외 C. 동점은 같은(더 높은) 순위를 받아 같은 등급.
 * 결과는 입력 순서를 유지한다.
 */
export function toGrades(values: number[]): Grade[] {
  const n = values.length
  if (n === 0) return []
  const sorted = [...values].sort((a, b) => b - a)
  return values.map((v) => {
    const rank = sorted.indexOf(v) + 1 // 동점이면 가장 높은 순위
    const ratio = (rank - 1) / n // 0 ≤ ratio < 1
    if (ratio < 0.25) return 'S'
    if (ratio < 0.5) return 'A'
    if (ratio < 0.75) return 'B'
    return 'C'
  })
}
```

검산: 12개 → rank 1~3 S(0, .083, .167), 4~6 A(.25, .333, .417), 7~9 B(.5, .583, .667), 10~12 C. 8개 → 1~2 S, 3~4 A, 5~6 B, 7~8 C. 3개 → rank1 S, rank2(.333) A, rank3(.667) B. 1개 → S. 4개 동점 `[100,50,50,10]` → rank 1 S, rank 2(둘 다, .25) A, rank 4(.75) C. 모두 테스트와 일치한다.

```ts
import { METRIC_KEYS, PRESET_KEYS } from '@/features/metric/types'
import type { MetricKey, PresetKey } from '@/features/metric/types'

export const DEFAULT_PRESET: PresetKey = 'quiet'

export function parsePreset(raw: string | null): PresetKey | null {
  if (raw === null) return null
  return (PRESET_KEYS as readonly string[]).includes(raw) ? (raw as PresetKey) : null
}

function isMetricKey(v: string): v is MetricKey {
  return (METRIC_KEYS as readonly string[]).includes(v)
}

/** METRIC_KEYS 순서로 정렬 + 중복 제거 */
export function normalizeMetrics(keys: readonly MetricKey[]): MetricKey[] {
  return METRIC_KEYS.filter((k) => keys.includes(k))
}

/** 'vibe,quiet,quiet' → ['quiet','vibe']. 모르는 키가 있거나 비어 있으면 null */
export function parseMetrics(raw: string | null): MetricKey[] | null {
  if (!raw) return null
  const parts = raw.split(',').filter(Boolean)
  if (parts.length === 0 || !parts.every(isMetricKey)) return null
  return normalizeMetrics(parts)
}

export function serializeMetrics(keys: readonly MetricKey[]): string {
  return normalizeMetrics(keys).join(',')
}
```

```ts
import { useCallback, useEffect, useRef } from 'react'
import { useSearchParams } from 'react-router-dom'
import { DEFAULT_MONTH, parseMonth } from '@/features/metric/month'
import type { MonthParam } from '@/features/metric/month'
import { DEFAULT_PRESET, parsePreset } from '@/features/metric/params'
import type { PresetKey } from '@/features/metric/types'

export type SetQueryState<T> = (value: T, opts?: { replace?: boolean }) => void

/**
 * URL 쿼리 하나를 상태처럼 쓴다.
 * - 키가 없으면 defaultValue (URL 은 그대로)
 * - 파싱 실패(null)면 defaultValue 로 바꾸고 replace 로 URL 보정 (뒤로가기 기록 없음)
 * - setter 는 push 가 기본, 슬라이더처럼 연속 변경은 { replace: true }
 */
export function useQueryState<T>(
  key: string,
  parse: (raw: string | null) => T | null,
  defaultValue: T,
  serialize: (v: T) => string = String,
): [T, SetQueryState<T>] {
  const [searchParams, setSearchParams] = useSearchParams()
  const serializeRef = useRef(serialize)
  serializeRef.current = serialize

  const raw = searchParams.get(key)
  const parsed = raw === null ? null : parse(raw)
  const invalid = raw !== null && parsed === null
  const value = parsed ?? defaultValue

  useEffect(() => {
    if (!invalid) return
    setSearchParams(
      (prev) => {
        const next = new URLSearchParams(prev)
        next.set(key, serializeRef.current(defaultValue))
        return next
      },
      { replace: true },
    )
    // searchParams 를 의존성에 둬서, 같은 커밋의 다른 보정이 이 보정을 덮어써도 다음 렌더에서 다시 고친다
  }, [invalid, key, defaultValue, searchParams, setSearchParams])

  const set = useCallback<SetQueryState<T>>(
    (v, opts) => {
      setSearchParams(
        (prev) => {
          const next = new URLSearchParams(prev)
          next.set(key, serializeRef.current(v))
          return next
        },
        { replace: opts?.replace ?? false },
      )
    },
    [key, setSearchParams],
  )

  return [value, set]
}

/** 공통 키 month */
export function useMonthParam(): [MonthParam, SetQueryState<MonthParam>] {
  return useQueryState<MonthParam>('month', parseMonth, DEFAULT_MONTH)
}

/** 공통 키 preset */
export function usePresetParam(): [PresetKey, SetQueryState<PresetKey>] {
  return useQueryState<PresetKey>('preset', parsePreset, DEFAULT_PRESET)
}
```

```ts
/** 페이지 이동 시 유지하는 공유 쿼리. metrics 는 preset=custom 일 때만. */
export const SHARED_QUERY_KEYS = ['month', 'preset', 'metrics'] as const

/** `to` 경로에 현재 URL 의 공유 쿼리를 붙인다. to 에 이미 있는 키는 유지한다. */
export function carryQuery(to: string, current: URLSearchParams): string {
  const [path, search = ''] = to.split('?')
  const next = new URLSearchParams(search)
  const isCustom = current.get('preset') === 'custom'
  for (const key of SHARED_QUERY_KEYS) {
    if (next.has(key)) continue
    if (key === 'metrics' && !isCustom) continue
    const v = current.get(key)
    if (v !== null) next.set(key, v)
  }
  const qs = next.toString()
  return qs ? `${path}?${qs}` : path
}
```

```tsx
export type SegmentedOption<T extends string> = {
  value: T
  label: string
  disabled?: boolean
  /** disabled 사유 툴팁 */
  title?: string
}

type Props<T extends string> = {
  options: SegmentedOption<T>[]
  /** null 이면 아무것도 선택 표시 없음 (두 Segmented 가 한 값을 공유할 때) */
  value: T | null
  onChange: (value: T) => void
  ariaLabel?: string
  size?: 'sm' | 'md'
  className?: string
}

/** 탭·월·범위 선택 UI. role=tablist / tab + aria-selected */
export default function Segmented<T extends string>({
  options,
  value,
  onChange,
  ariaLabel,
  size = 'md',
  className = '',
}: Props<T>) {
  const h = size === 'sm' ? 'h-7 px-3' : 'h-9 px-4'
  return (
    <div
      role="tablist"
      aria-label={ariaLabel}
      className={`bg-bg-surface-strong inline-flex items-center gap-1 rounded-lg p-1 ${className}`}
    >
      {options.map((opt) => {
        const selected = opt.value === value
        const tone = selected
          ? 'bg-selected-bg text-selected-fg'
          : 'text-text-secondary hover:text-text-primary'
        const dim = opt.disabled ? 'cursor-not-allowed opacity-dim' : 'cursor-pointer'
        return (
          <button
            key={opt.value}
            type="button"
            role="tab"
            aria-selected={selected}
            aria-disabled={opt.disabled || undefined}
            title={opt.title}
            onClick={opt.disabled ? undefined : () => onChange(opt.value)}
            className={`text-caption-segment inline-flex items-center rounded-md whitespace-nowrap ${h} ${tone} ${dim}`}
          >
            {opt.label}
          </button>
        )
      })}
    </div>
  )
}
```

```ts
import { expect, test } from '@playwright/test'

test.describe('공통 기반', () => {
  test('네비게이션으로 각 페이지에 들어가면 페이지 제목이 보인다', async ({ page }) => {
    await page.goto('/')

    await page.getByRole('link', { name: '티어리스트' }).click()
    await expect(page).toHaveURL(/\/tier$/)
    await expect(page.getByRole('heading', { level: 1 })).toHaveText('티어리스트')

    await page.getByRole('link', { name: '동네 비교' }).click()
    await expect(page).toHaveURL(/\/compare$/)
    await expect(page.getByRole('heading', { level: 1 })).toHaveText('동네 비교')
  })

  test('month 쿼리는 페이지를 옮겨도 유지된다', async ({ page }) => {
```
