# 다크모드 · 쫀득한 세그먼트 토글 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 시스템 설정을 따르는 다크모드(내비바 해/달 버튼으로 전환, 지도 영역은 라이트 고정)와, 세그먼트 토글의 움직이는 칸에 쫀득한 모션을 넣는다.

**Architecture:** `<html data-theme>` 하나로 테마를 정하고, `src/index.css`에서 의미 토큰만 다크 값으로 다시 정의한다. 지도는 `data-theme="light"` 범위로 감싸 라이트 값으로 되돌린다. 세그먼트 토글은 선택 표시를 별도 칸(thumb)으로 분리하고, 공통 훅 `useSlidingThumb`이 위치를 재서 앞끝·뒤끝 전환 + Web Animations API 움츠림으로 움직인다.

**Tech Stack:** React 19, Vite, Tailwind v4 (`@theme`), vitest + Testing Library (jsdom), Playwright, lucide-react, Figma MCP

**스펙:** `docs/superpowers/specs/2026-11-19-다크모드-쫀득토글-design.md`

## Global Constraints

- 답변·커밋 메시지·주석은 한국어
- 컴포넌트에서 hex 직접 사용 금지. 색은 `src/index.css` 토큰만 쓴다
- 순수 검정(#000)·순수 흰색(#fff)을 다크 바탕·본문 글자에 쓰지 않는다
- 그대로 두는 것: `scrim`, `brand-kakao`, `brand-kakao-fg`, `brand-google-border`, `heat-*`, `explore-map-*`, 지도 타일
- 저장 키: `workation.theme` (값 `'light' | 'dark'`). `localStorage` 읽기·쓰기는 모두 try/catch
- 해/달 버튼 라벨: 라이트 `다크 모드로 전환`, 다크 `라이트 모드로 전환`
- 모션 전체 450ms 안쪽, `prefers-reduced-motion`이면 움츠림·출렁임 없이 바로 이동
- 세그먼트 글자 굵기는 선택 여부로 바꾸지 않는다
- 커밋 메시지 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`

```ts
const CSS = readFileSync(join(SRC, 'index.css'), 'utf8')

/** 선택자로 시작하는 줄부터 그 줄 맨 앞 `}` 까지 */
function block(selector: string): string {
  const start = CSS.indexOf(`\n${selector} {`)
  if (start < 0) throw new Error(`${selector} 블록이 없다`)
  return CSS.slice(start, CSS.indexOf('\n}', start + 1))
}
const declared = (s: string) => [...s.matchAll(/^\s*(--[\w-]+):/gm)].map((m) => m[1])
const referenced = (s: string) => [...s.matchAll(/var\((--[\w-]+)\)/g)].map((m) => m[1])
```

```ts
it('다크 블록과 라이트 범위 블록은 같은 토큰을 같은 순서로 정의한다', () => {
  const dark = declared(block(":root[data-theme='dark']"))
  const light = declared(block("[data-theme='light']"))
  expect(dark.length).toBeGreaterThan(40)
  expect(light).toEqual(dark)
})
it('다크·라이트 블록이 고치는 토큰과 참조하는 원시 색은 모두 @theme 에 있다', () => {
  const theme = new Set(declared(block('@theme')))
  for (const sel of [":root[data-theme='dark']", "[data-theme='light']"]) {
    const b = block(sel)
    for (const name of [...declared(b), ...referenced(b)])
      expect(theme, `${sel} ${name}`).toContain(name)
  }
})
it('다크 블록은 제공자 색·scrim·히트맵·지도 토큰을 건드리지 않는다', () => {
  const dark = declared(block(":root[data-theme='dark']"))
  expect(dark.filter((n) => /kakao|google|scrim|heat-|explore-map-|skeleton-map/.test(n))).toEqual(
    [],
  )
})
```

```ts
export type Theme = 'light' | 'dark'

/** index.html 의 화면 그리기 전 스크립트와 같은 키 */
export const THEME_STORAGE_KEY = 'workation.theme'

const DARK_QUERY = '(prefers-color-scheme: dark)'

/** 저장값. 없거나 읽지 못하면(사생활 보호 모드 등) null */
export function readStoredTheme(): Theme | null {
  try {
    const v = localStorage.getItem(THEME_STORAGE_KEY)
    return v === 'light' || v === 'dark' ? v : null
  } catch {
    return null
  }
}

export function storeTheme(theme: Theme) {
  try {
    localStorage.setItem(THEME_STORAGE_KEY, theme)
  } catch {
    // 저장에 실패해도 지금 화면은 바뀐다
  }
}

export function systemTheme(): Theme {
  return window.matchMedia?.(DARK_QUERY).matches ? 'dark' : 'light'
}

export function initialTheme(): Theme {
  return readStoredTheme() ?? systemTheme()
}

/** <html data-theme> 교체. 바뀌는 프레임 동안 전환을 꺼 색이 한 번에 바뀌게 한다 (스펙 §4-4) */
export function applyTheme(theme: Theme) {
  const root = document.documentElement
  if (root.dataset.theme === theme) return
  root.classList.add('theme-switching')
  root.dataset.theme = theme
  // 새 색이 그려진 다음 프레임에 전환을 되살린다
  requestAnimationFrame(() => requestAnimationFrame(() => root.classList.remove('theme-switching')))
}

export function watchSystemTheme(onChange: (theme: Theme) => void): () => void {
  const mq = window.matchMedia?.(DARK_QUERY)
  if (!mq?.addEventListener) return () => {}
  const handler = (e: MediaQueryListEvent) => onChange(e.matches ? 'dark' : 'light')
  mq.addEventListener('change', handler)
  return () => mq.removeEventListener('change', handler)
}
```

```ts
import { useCallback, useEffect, useState } from 'react'
import {
  applyTheme,
  initialTheme,
  readStoredTheme,
  storeTheme,
  watchSystemTheme,
} from '@/hooks/theme'
import type { Theme } from '@/hooks/theme'

/**
 * 다크모드 상태 (스펙 §4-2). 저장값이 없으면 시스템 설정을 실시간으로 따르고,
 * toggle 하면 저장해서 이후엔 저장값이 우선한다
 */
export default function useTheme() {
  const [theme, setTheme] = useState<Theme>(initialTheme)

  useEffect(() => applyTheme(theme), [theme])

  useEffect(
    () =>
      watchSystemTheme((next) => {
        if (!readStoredTheme()) setTheme(next)
      }),
    [],
  )

  const toggle = useCallback(() => {
    const next: Theme = theme === 'dark' ? 'light' : 'dark'
    storeTheme(next)
    setTheme(next)
  }, [theme])

  return { theme, toggle }
}
```

 * Maps JS 는 'var(--color-x)' 를 색으로 못 읽는다.
 * 지도 범위(다크에서도 라이트, 다크모드 스펙 §5)에서 토큰 값을 읽어 실제 색 문자열로 바꾼다.

export function resolveToken(cssVar: string): string {
  const name = cssVar.replace(/^var\((--[^)]+)\)$/, '$1')

}

```ts
import { useLayoutEffect, useRef, useState } from 'react'

/** animate: 첫 배치는 제자리에 바로 놓고 이후 이동만 움직인다 */
export type Thumb = {
  left: number
  right: number
  top: number
  height: number
  dir: 1 | -1
  animate: boolean
}

/** 전체 모션 길이. 움츠림 70ms → 앞끝 → 뒤끝 도착이 이 안에 끝난다 (스펙 §6-3, 450ms 안쪽) */
export const THUMB_MS = 440
const LEAD = '250ms var(--ease-spring) 70ms'
const TRAIL = '320ms var(--ease-spring) 120ms'

/** 진행 방향 앞끝은 빨리, 뒤끝은 늦게 따라와 늘어났다 스프링으로 붙는다 (Navbar TabIndicator 와 같은 방식) */
export function thumbTransition(thumb: Thumb | null): string {
  if (!thumb?.animate) return 'none'
  const [lead, trail] = thumb.dir === 1 ? ['right', 'left'] : ['left', 'right']
  return `${lead} ${LEAD}, ${trail} ${TRAIL}, top ${LEAD}, height ${LEAD}`
}

const reduceMotion = () => window.matchMedia?.('(prefers-reduced-motion: reduce)').matches ?? false

/** 1단계 움츠림과 3단계 크기 복귀. 위치는 transition 이 맡는다. jsdom 에는 animate 가 없다 */
function squeeze(el: HTMLElement | null) {
  el?.animate?.(
    [
      { transform: 'scale(1)' },
      { transform: 'scale(0.92, 0.9)', offset: 0.16 },
      { transform: 'scale(0.97, 0.95)', offset: 0.6 },
      { transform: 'scale(1)' },
    ],
    { duration: THUMB_MS, easing: 'ease-out' },
  )
}

/**
 * 세그먼트 토글의 움직이는 칸 (다크모드·쫀득토글 스펙 §6).
 * listRef 안의 [aria-selected="true"] 위치를 재고, selectedKey 가 바뀌면
 * 움츠림 → 앞끝 먼저 늘어남 → 스프링 도착 순서로 옮긴다. 선택이 없으면 thumb 는 null
 */
export default function useSlidingThumb(selectedKey: string | null) {
  const listRef = useRef<HTMLDivElement>(null)
  const thumbRef = useRef<HTMLSpanElement>(null)
  const prevKey = useRef<string | null>(null)
  const [thumb, setThumb] = useState<Thumb | null>(null)

  useLayoutEffect(() => {
    const el = listRef.current
    if (!el) return
    const measure = () => {
      const active = el.querySelector<HTMLElement>('[aria-selected="true"]')
      if (!active) return setThumb(null)
      const left = active.offsetLeft
      setThumb((prev) => ({
        left,
        right: el.clientWidth - left - active.offsetWidth,
        top: active.offsetTop,
        height: active.offsetHeight,
        dir: prev && left < prev.left ? -1 : 1,
        animate: prev !== null && !reduceMotion(),
      }))
    }
    measure()
    const moved =
      prevKey.current !== null && selectedKey !== null && prevKey.current !== selectedKey
    if (moved && !reduceMotion()) squeeze(thumbRef.current)
    prevKey.current = selectedKey
    document.fonts?.ready.then(measure)
    // 웹폰트 로드·창 크기 변화로 버튼 폭이 바뀌면 다시 잰다
    if (typeof ResizeObserver === 'undefined') return
    const ro = new ResizeObserver(measure)
    ro.observe(el)
    return () => ro.disconnect()
  }, [selectedKey])

  return { listRef, thumbRef, thumb }
}
```
