# W-04 동네 프로필 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/dongs/:dongId`에서 행정동 하나의 24시간 보행 곡선·동네 성격(활동 유형 비중)·지표 4종·위치(Google Maps)·비슷한데 더 조용한 동네 3곳·커뮤니티(읽기)를 보여준다.

**Architecture:** 점수·등급·순위는 W-02의 `GET /api/tier?scope=dong` 응답을 W-03의 `rankIn`으로 재계산하고, 하루 리듬·활동 비중·유사 동네는 새 API `GET /api/dongs/{id}?month=`에서 받는다. 차트는 Recharts(W-03에서 설치), 지도는 `@vis.gl/react-google-maps` 위에 `components/map/`(Provider·Placeholder·PolygonLayer)을 얹어 W-01 히트맵과 공유한다. 키가 없으면 플레이스홀더로 돌아가므로 mock·CI·E2E는 키 없이 실행된다.

**Tech Stack:** React 19 · TypeScript 6 · TanStack Query 5 · Recharts 3 · @vis.gl/react-google-maps 1.x · Tailwind v4 토큰 · Vitest · Playwright

**Spec:** `docs/superpowers/specs/2026-11-07-W-04-동네프로필-design.md`
**선행 플랜:** `2026-11-07-공통기반-plan.md`, `2026-11-07-W-02-티어리스트-plan.md`, `2026-11-07-W-03-지역상세-plan.md`

## Global Constraints

- LG U+ 기업연계 과제: 지도는 **Google Maps만**. 카카오맵·네이버맵 등 국내 타 기업 API는 쓰지 않는다.
- 웹 데스크톱만. Figma 1440px 기준, 최소 폭 1128px(`min-w-desktop`), 그보다 좁으면 가로 스크롤.
- 본문 폰트 맑은 고딕(시스템 폰트, 공통 기반 `--font-sans`). 폰트 관련 설정을 이 플랜에서 바꾸지 않는다.
- 색·치수·타이포는 `src/index.css` `@theme` 토큰만. 임의값 금지. Recharts·Google Maps 폴리곤 색은 `var(--color-chart-*)`, `var(--color-brand-primary)` 같은 CSS 변수 문자열로 넘긴다. 이 플랜에서 `--color-chart-1`~`--color-chart-4`를 `@theme`에 추가한다.
- 파일 1개 = 컴포넌트 1개 `export default function`. 컴포넌트 파일에서 상수를 함께 export하지 않는다.
- `erasableSyntaxOnly`: `enum` 금지. `as const` + 유니온. `verbatimModuleSyntax`: 타입은 `import type`.
- 백엔드 호출은 `lib/api.ts`의 `api<T>()`로만. 정적 자산(`/geo/*.json`)은 예외로 `lib/staticJson.ts`를 통해 읽는다(이 플랜에서 정의).
- `pages/`는 다른 `pages/`를 import하지 않는다. `features/dong`은 `features/metric`·`features/tier`·`features/region`·`features/auth`를 import할 수 있다(역방향 금지).
- 화면 문자열은 `METRIC_LABEL`·`METRIC_SHORT_LABEL`·`ACTIVITY_LABEL`·`DONG_KIND_LABEL` 사전에서 가져온다.
- Google Maps 키는 `VITE_GOOGLE_MAPS_KEY`. `.env.example`에는 **빈 값**으로 자리만 둔다. 키가 없으면 `MapPlaceholder`.
- 커밋은 Conventional Commits. 커밋 전 `pnpm lint && pnpm format:check && pnpm build && pnpm test` 통과.
- 사진(`public/mock-photos/`)은 저작권 확인 전 배포 환경에 올리지 않는다.

```ts
/** Google Maps 키가 설정되어 있는지. 빈 문자열은 없는 것으로 본다. */
export function hasMapsKey(): boolean {
  const key = import.meta.env.VITE_GOOGLE_MAPS_KEY
  return typeof key === 'string' && key.trim().length > 0
}

export function mapsKey(): string {
  return import.meta.env.VITE_GOOGLE_MAPS_KEY ?? ''
}

/** AdvancedMarker 는 Map ID 가 있어야 그려진다. 운영 ID 가 없으면 Google 의 개발용 ID */
export function mapsMapId(): string {
  return import.meta.env.VITE_GOOGLE_MAPS_MAP_ID?.trim() || 'DEMO_MAP_ID'
}
```

```ts
import type { MonthParam } from '@/features/metric/month'
import type { DongKind, SeasonType } from '@/features/region/types'

export const ACTIVITY_KEYS = [
  'eveningDowntown',
  'weekendTourist',
  'weekdayWork',
  'dawnResidential',
] as const
export type ActivityKey = (typeof ACTIVITY_KEYS)[number]

export type DayGroup = 'weekday' | 'weekend'

export type QuieterTwin = {
  id: string
  name: string
  sigunguId: string
  sigunguName: string
  similarity: number // 0~1, 소수 2자리
  visitorRatio: number // 대상 방문객 ÷ 현재 방문객, 소수 2자리 (< 1)
  photoUrl: string
}

/** GET /api/dongs/{dongId}?month= — 백엔드와의 계약 (스펙 §5-2) */
export type DongDetailResponse = {
  id: string
  name: string // 거진읍
  sigungu: { id: string; name: string }
  province: string
  kind: DongKind
  tags: string[] // ['해안']
  photos: { url: string; credit?: string }[]
  landmarks: string[] // 수동
  accessNote: string // 수동
  month: MonthParam
  stats: {
    dayInflow: number // 평일 낮 체류 ÷ 새벽 체류
    localLife: number // (거주+근무) ÷ 전체 × 100, 정수
    peerShare: number // 20~40대 방문 비율 %, 정수
    eveningVibe: number // 평일 저녁 보행 ÷ 평일 저녁 체류, 소수 2자리
    eveningSurplus: number // 실제 ÷ 예측 저녁 보행, 소수 2자리
  }
  hourly: Record<DayGroup, number[]> // 길이 24, 0~100, 두 배열 중 최대 = 100
  peaks: Record<DayGroup, { peakHour: number; lowHour: number; lowValue: number }>
  activityMix: Record<ActivityKey, number> // 정수, 합 100
  seasonType: SeasonType
  quieterTwins: QuieterTwin[] // 최대 3, 유사도 내림차순
  bbox: [number, number, number, number] // [minLng, minLat, maxLng, maxLat]
```

```ts
export const ACTIVITY_LABEL: Record<ActivityKey, string> = {
  eveningDowntown: '저녁 상권형',
  weekendTourist: '주말 관광형',
  weekdayWork: '평일 업무형',
  dawnResidential: '새벽 주거형',
}

/** Recharts·인라인 스타일용 CSS 변수. 순서는 ACTIVITY_KEYS = chart-1..4 */
export const ACTIVITY_COLOR: Record<ActivityKey, string> = {
  eveningDowntown: 'var(--color-chart-1)',
  weekendTourist: 'var(--color-chart-2)',
  weekdayWork: 'var(--color-chart-3)',
  dawnResidential: 'var(--color-chart-4)',
}

/** Tailwind 배경 클래스 (범례 점·막대 조각) */
export const ACTIVITY_BG_CLASS: Record<ActivityKey, string> = {
  eveningDowntown: 'bg-chart-1',
  weekendTourist: 'bg-chart-2',
  weekdayWork: 'bg-chart-3',
  dawnResidential: 'bg-chart-4',
}

/** 최대 비중 키. 동점이면 ACTIVITY_KEYS 앞쪽 */
export function dominantActivity(mix: Record<ActivityKey, number>): ActivityKey {
  let best: ActivityKey = ACTIVITY_KEYS[0]
  for (const key of ACTIVITY_KEYS) if (mix[key] > mix[best]) best = key
  return best
}

/** 비중을 합 100 정수로. 반올림 오차는 최대 항목에서 보정 */
export function normalizeActivityMix(
  raw: Record<ActivityKey, number>,
): Record<ActivityKey, number> {
  const total = ACTIVITY_KEYS.reduce((s, k) => s + raw[k], 0)
  if (total <= 0) {
    return { eveningDowntown: 25, weekendTourist: 25, weekdayWork: 25, dawnResidential: 25 }
  }
  const out = { eveningDowntown: 0, weekendTourist: 0, weekdayWork: 0, dawnResidential: 0 }
  for (const k of ACTIVITY_KEYS) out[k] = Math.round((raw[k] / total) * 100)
  const sum = ACTIVITY_KEYS.reduce((s, k) => s + out[k], 0)
  if (sum !== 100) out[dominantActivity(out)] += 100 - sum
  return out
}

/** 내림차순 정렬. 동점은 ACTIVITY_KEYS 순서 유지 */
export function sortedActivities(
  mix: Record<ActivityKey, number>,
): { key: ActivityKey; value: number }[] {
  return ACTIVITY_KEYS.map((key) => ({ key, value: mix[key] })).sort((a, b) => b.value - a.value)
}
```

```ts
import { MONTHS } from '@/features/metric/month'
import type { MonthParam } from '@/features/metric/month'

/** 곡선 섹션 월 칩: 선택 월 ±1 (양끝은 안쪽으로 밀어 3개 유지). 연간은 최근 3개월 */
export function monthWindow(month: MonthParam): MonthParam[] {
  const months = MONTHS.filter((m) => m !== 'annual') // 2025-01 .. 2025-12
  const last = months.length - 1
  let i = month === 'annual' ? last : months.indexOf(month)
  if (i < 0) i = last
  const start = Math.min(Math.max(i - 1, 0), last - 2)
  return months.slice(start, start + 3)
}
```

```ts
function monthShift(month: MonthParam): number {
  const n = monthNumber(month)
  if (n === null || n === 10) return 0
  return ((n * 5) % 7) - 3
}

/** 코사인 모양의 24시간 곡선. peak = 100, low = lowValue */
function curve(peak: number, low: number, lowValue: number): number[] {
  const out: number[] = []
  for (let h = 0; h < 24; h++) {
    // low → peak 로 가는 거리(0~12)를 0~π 로 매핑
    const d = Math.min(Math.abs(h - peak), 24 - Math.abs(h - peak)) // 0(피크)~12
    const t = d / 12 // 0~1
    const v = lowValue + (100 - lowValue) * (0.5 + 0.5 * Math.cos(Math.PI * t))
    out.push(Math.round(v))
  }
  out[peak] = 100
  out[low] = Math.min(out[low], lowValue)
  return out
}
```

```ts
/** 좌표는 GeoJSON 규약대로 [lng, lat] */
export type Ring = [number, number][]
export type PolygonGeometry = { type: 'Polygon'; coordinates: Ring[] }
export type MultiPolygonGeometry = { type: 'MultiPolygon'; coordinates: Ring[][] }
export type GeoGeometry = PolygonGeometry | MultiPolygonGeometry

export type GeoFeature = {
  type: 'Feature'
  properties: { id: string; name: string }
  geometry: GeoGeometry
}

export type GeoFeatureCollection = { type: 'FeatureCollection'; features: GeoFeature[] }

export const EMPTY_GEO: GeoFeatureCollection = { type: 'FeatureCollection', features: [] }

export type LatLng = { lat: number; lng: number }

export type PolygonStyle = {
  fill: string // CSS 색 문자열 (토큰: 'var(--color-brand-primary)' 는 Maps 가 못 읽으므로 getComputedStyle 로 해석한 값)
  stroke: string
  strokeWidth: number
  fillOpacity: number
}

/** 폴리곤마다 외곽 링(구멍 제외)만 {lat,lng}[] 로 */
export function toLatLngPaths(geometry: GeoGeometry): LatLng[][] {
  const polygons = geometry.type === 'Polygon' ? [geometry.coordinates] : geometry.coordinates
  return polygons.map((rings) => rings[0].map(([lng, lat]) => ({ lat, lng })))
}

/** 첫 폴리곤 외곽 링 꼭짓점 평균 (마커 위치용, 소수 2자리) */
export function centroid(geometry: GeoGeometry): LatLng {
  const ring = toLatLngPaths(geometry)[0]
  const n = ring.length
  const lat = ring.reduce((s, p) => s + p.lat, 0) / n
  const lng = ring.reduce((s, p) => s + p.lng, 0) / n
  return { lat: Math.round(lat * 100) / 100, lng: Math.round(lng * 100) / 100 }
}

export function bboxToBounds([west, south, east, north]: [number, number, number, number]) {
  return { west, south, east, north }
}

/**
 * Maps JS 는 'var(--color-x)' 를 색으로 못 읽는다.
 * document 에서 토큰 값을 읽어 실제 색 문자열로 바꾼다 (SSR 없음).
 */
export function resolveToken(cssVar: string): string {
  const name = cssVar.replace(/^var\((--[^)]+)\)$/, '$1')
  if (!name.startsWith('--')) return cssVar
  return getComputedStyle(document.documentElement).getPropertyValue(name).trim() || cssVar
}
```

```ts
import { NotFoundError } from '@/lib/errors'

/**
 * public/ 아래 정적 자산(JSON)을 읽는다. 백엔드 API 가 아니므로 api<T>() 를 쓰지 않는 유일한 예외.
 * 404 는 NotFoundError 로 던져 호출부가 빈 값으로 대체할 수 있게 한다.
 */
export async function loadStaticJson<T>(path: string): Promise<T> {
  const res = await fetch(path, { headers: { Accept: 'application/json' } })
  if (res.status === 404) throw new NotFoundError(path)
  if (!res.ok) throw new Error(`static ${res.status}: ${path}`)
  return res.json() as Promise<T>
}
```

```tsx
import { useEffect } from 'react'
import { useMap } from '@vis.gl/react-google-maps'
import { centroid, resolveToken, toLatLngPaths } from '@/components/map/geo'
import type { GeoFeatureCollection, PolygonStyle } from '@/components/map/geo'

type Props = {
  features: GeoFeatureCollection
  /** 호출부는 useCallback 으로 고정한다. 참조가 바뀌면 폴리곤을 다시 그린다 (시군구당 ≤ 30개) */
  getStyle: (id: string) => PolygonStyle
  onClick?: (id: string) => void
  onHover?: (id: string | null) => void
  /** 폴리곤 중심에 표시할 라벨 (W-01 히트맵). undefined 면 라벨 없음 */
  getLabel?: (id: string) => string | undefined
}

/** GeoJSON FeatureCollection 을 google.maps.Polygon 으로 그린다. 색은 CSS 변수(토큰)도 받는다 */
export default function PolygonLayer({ features, getStyle, onClick, onHover, getLabel }: Props) {
  const map = useMap()

  useEffect(() => {
    if (!map) return
    const overlays: { setMap(m: google.maps.Map | null): void }[] = []
    for (const f of features.features) {
      const id = f.properties.id
      const style = getStyle(id)
      const polygon = new google.maps.Polygon({
        paths: toLatLngPaths(f.geometry),
        map,
        fillColor: resolveToken(style.fill),
        fillOpacity: style.fillOpacity,
        strokeColor: resolveToken(style.stroke),
        strokeWeight: style.strokeWidth,
        clickable: Boolean(onClick || onHover),
      })
      if (onClick) polygon.addListener('click', () => onClick(id))
      if (onHover) {
        polygon.addListener('mouseover', () => onHover(id))
        polygon.addListener('mouseout', () => onHover(null))
      }
      overlays.push(polygon)

      const text = getLabel?.(id)
      if (text) {
        // mapId 가 필요한 AdvancedMarker 대신 투명 아이콘 + 라벨 Marker 를 쓴다
        const label = new google.maps.Marker({
          position: centroid(f.geometry),
          map,
          clickable: false,
          icon: { path: google.maps.SymbolPath.CIRCLE, scale: 0 },
          label: {
            text,
            fontSize: '12px',
            fontWeight: '700',
            color: resolveToken('var(--color-text-primary)'),
          },
        })
        overlays.push(label)
      }
    }
    return () => overlays.forEach((o) => o.setMap(null))
  }, [map, features, getStyle, onClick, onHover, getLabel])

  return null
}
```

`google` 전역 타입은 `@vis.gl/react-google-maps`가 의존하는 `@types/google.maps`에서 온다. 타입 에러가 나면 `pnpm add -D @types/google.maps`.

```python
#!/usr/bin/env python3
"""행정동 경계(shp) → 시군구별 단순화 GeoJSON (public/geo/{sggId}.json)

사용법:
  python scripts/gen-geo.py <경계 shp 또는 geojson> <출력 디렉터리> [--tolerance 20]

- 원본 경계(통계청 SGIS 또는 공공데이터포털)는 저장소에 넣지 않는다.
- 허용 오차 기본 20m (EPSG:5179 로 투영해 simplify 후 EPSG:4326 으로 되돌린다).
- 시군구당 파일 1개, properties 는 { id, name } 만 남긴다. 목표 ≤ 100KB.
- 입력 컬럼명(ADM_CD, ADM_NM 등)은 --id-col / --name-col 로 지정한다.
의존성: geopandas, shapely  (pip install geopandas shapely)
"""
import argparse
import json
from pathlib import Path

import geopandas as gpd

# W-02 SIGUNGU 12곳과 같은 목록 (src/mocks/sigungu.ts)
TARGET_SGG = ['51820', '51830', '51210', '51150', '51170', '52110', '52140', '52800', '46150', '46770', '50110', '50130']


def main() -> None:
    p = argparse.ArgumentParser()
    p.add_argument('source')
    p.add_argument('out_dir')
    p.add_argument('--tolerance', type=float, default=20.0, help='단순화 허용 오차 (m)')
    p.add_argument('--id-col', default='ADM_CD')
    p.add_argument('--name-col', default='ADM_NM')
    args = p.parse_args()

    gdf = gpd.read_file(args.source)
    gdf = gdf.to_crs(epsg=5179)
    gdf['geometry'] = gdf.geometry.simplify(args.tolerance, preserve_topology=True)
    gdf = gdf.to_crs(epsg=4326)

    out = Path(args.out_dir)
    out.mkdir(parents=True, exist_ok=True)
    for sgg in TARGET_SGG:
        part = gdf[gdf[args.id_col].astype(str).str.startswith(sgg)]
        if part.empty:
            print(f'skip {sgg}: no features')
            continue
        fc = {
            'type': 'FeatureCollection',
            'features': [
                {
                    'type': 'Feature',
                    'properties': {'id': str(row[args.id_col]), 'name': str(row[args.name_col])},
                    'geometry': json.loads(gpd.GeoSeries([row.geometry]).to_json())['features'][0]['geometry'],
                }
                for _, row in part.iterrows()
            ],
        }
        path = out / f'{sgg}.json'
        path.write_text(json.dumps(fc, ensure_ascii=False, separators=(',', ':')), encoding='utf-8')
        print(f'{path} {path.stat().st_size // 1024}KB {len(fc["features"])} features')


if __name__ == '__main__':
    main()
```

```tsx
import { CartesianGrid, Line, LineChart, Tooltip, XAxis, YAxis } from 'recharts'
import { DONG_COPY } from '@/features/dong/copy'
import type { DayGroup } from '@/features/dong/types'

type Props = {
  hourly: Record<DayGroup, number[]>
  /** 강조할 선 */
  day: DayGroup
  /** W-05 열용: 높이 160, 축 라벨 최소화 */
  compact?: boolean
  height?: number
  /** 고정 폭 (기본 760 = 본문 열 폭 - 패딩). W-05 열은 300 */
  width?: number
  /** 테스트에서 false */
  animate?: boolean
}

const TICKS = [0, 3, 6, 9, 12, 15, 18, 21, 23]

function strokeOf(selected: boolean) {
  return selected ? 'var(--color-chart-line-strong)' : 'var(--color-chart-line-muted)'
}

/** 24시간 보행 곡선. 주중·주말 선 2개, 선택한 날은 진하게 */
export default function HourlyCurveChart({
  hourly,
  day,
  compact = false,
  height,
  width = 760,
  animate = true,
}: Props) {
  const data = Array.from({ length: 24 }, (_, h) => ({
    h,
    weekday: hourly.weekday[h],
    weekend: hourly.weekend[h],
  }))
  const h = height ?? (compact ? 160 : 240)
  return (
    <LineChart
      width={width}
      height={h}
      data={data}
      margin={{ top: 8, right: 8, bottom: 0, left: 0 }}
    >
      <CartesianGrid vertical={false} stroke="var(--color-chart-grid)" />
      <XAxis
        dataKey="h"
        ticks={TICKS}
        tickFormatter={(v: number) => `${v}시`}
        tickLine={false}
        axisLine={false}
        tick={{ fontSize: compact ? 10 : 12, fill: 'var(--color-text-tertiary)' }}
      />
      <YAxis hide domain={[0, 100]} />
      <Tooltip
        content={({ active, label }) =>
          active && typeof label === 'number' ? (
            <div className="bg-bg-surface border-border-default text-caption-xs text-text-primary shadow-float rounded-lg border px-3 py-2">
              {DONG_COPY.curveTooltip(label, hourly.weekday[label], hourly.weekend[label])}
            </div>
          ) : null
        }
      />
      {(['weekend', 'weekday'] as DayGroup[])
        .sort((a) => (a === day ? 1 : -1)) // 선택한 선을 마지막(위)에
        .map((key) => (
          <Line
            key={key}
            className={`curve-${key}`}
            type="monotone"
            dataKey={key}
            name={key}
            stroke={strokeOf(key === day)}
            strokeWidth={key === day ? 3 : 1.5}
            dot={false}
            activeDot={{ r: 4 }}
            isAnimationActive={animate}
            animationDuration={300}
          />
        ))}
    </LineChart>
  )
}
```

```tsx
import { useCallback, useState } from 'react'
import { AdvancedMarker, Map as GoogleMap } from '@vis.gl/react-google-maps'
import { MapPin } from 'lucide-react'
import { useNavigate } from 'react-router-dom'
import { bboxToBounds, centroid } from '@/components/map/geo'
import type { GeoFeatureCollection, PolygonStyle } from '@/components/map/geo'
import GoogleMapProvider from '@/components/map/GoogleMapProvider'
import { mapsMapId } from '@/components/map/mapsKey'
import MapPlaceholder from '@/components/map/MapPlaceholder'
import PolygonLayer from '@/components/map/PolygonLayer'
import { DONG_COPY } from '@/features/dong/copy'
import type { DongDetailResponse } from '@/features/dong/types'
import { METRIC_LABEL } from '@/features/metric/constants'
import type { Grade } from '@/features/metric/types'
import { carryQuery } from '@/hooks/carryQuery'

type Props = {
  detail: DongDetailResponse
  geo: GeoFeatureCollection | undefined
  quietGrade: Grade | null
}

const CURRENT: PolygonStyle = {
  fill: 'var(--color-brand-primary)',
  stroke: 'var(--color-brand-hover)',
  strokeWidth: 2,
  fillOpacity: 0.35,
}
const OTHER: PolygonStyle = {
  fill: 'var(--color-gray-300)',
  stroke: 'var(--color-border-strong)',
  strokeWidth: 1,
  fillOpacity: 0,
}

/**
 * 스펙 §3-6 위치. 키 없음·로드 실패는 GoogleMapProvider 가 MapPlaceholder 로 바꾼다.
 * 폴리곤 파일이 없으면(빈 컬렉션) 폴리곤 없이 마커만 그린다.
 */
export default function DongMap({ detail, geo, quietGrade }: Props) {
  const navigate = useNavigate()
  const [hoverCurrent, setHoverCurrent] = useState(false)
  const landmarks = detail.landmarks.join(' · ')
  const feature = geo?.features.find((f) => f.properties.id === detail.id)
  const center = feature
    ? centroid(feature.geometry)
    : { lat: (detail.bbox[1] + detail.bbox[3]) / 2, lng: (detail.bbox[0] + detail.bbox[2]) / 2 }
  // 스펙 §3-6: 현재 동 hover 툴팁 `{name} · 동네 조용함 {grade}`
  const tooltip = quietGrade ? `${detail.name} · ${METRIC_LABEL.quiet} ${quietGrade}` : detail.name

  const getStyle = useCallback((id: string) => (id === detail.id ? CURRENT : OTHER), [detail.id])
  const onClick = useCallback(
    (id: string) => {
      if (id !== detail.id)
        navigate(carryQuery(`/dongs/${id}`, new URLSearchParams(window.location.search)))
    },
    [detail.id, navigate],
  )
  const onHover = useCallback((id: string | null) => setHoverCurrent(id === detail.id), [detail.id])

  return (
    <section aria-labelledby="map-title" className="flex flex-col gap-4">
      <div className="flex items-center justify-between">
        <h2 id="map-title" className="text-heading-lg text-text-primary">
          {DONG_COPY.mapTitle}
        </h2>
        <span className="text-caption-xs text-text-tertiary">{detail.accessNote}</span>
      </div>
      <div className="relative h-80 w-full overflow-hidden rounded-xl">
        <GoogleMapProvider
          fallback={<MapPlaceholder title={DONG_COPY.mapNoKey}>{landmarks}</MapPlaceholder>}
        >
          <GoogleMap
            mapId={mapsMapId()}
            defaultBounds={bboxToBounds(detail.bbox)}
            gestureHandling="cooperative"
            disableDefaultUI
            zoomControl
            style={{ width: '100%', height: '100%' }}
          >
            {geo && geo.features.length > 0 && (
              <PolygonLayer
                features={geo}
                getStyle={getStyle}
                onClick={onClick}
                onHover={onHover}
              />
            )}
            <AdvancedMarker position={center} title={tooltip}>
              <span className="text-text-primary flex flex-col items-center">
                <span className="bg-bg-surface text-caption-xs shadow-float rounded-md px-2 py-0.5 font-bold">
                  {detail.name}
                </span>
                <MapPin className="text-brand-primary" size={28} aria-hidden />
              </span>
            </AdvancedMarker>
          </GoogleMap>
          {hoverCurrent && (
            <div
              role="tooltip"
              className="bg-bg-surface text-caption-xs text-text-primary shadow-float pointer-events-none absolute top-3 left-3 rounded-lg px-3 py-2"
            >
              {tooltip}
            </div>
          )}
        </GoogleMapProvider>
      </div>
      <p className="text-body-sm text-text-secondary">{landmarks}</p>
    </section>
  )
}
```

`Map` 컴포넌트의 `style`은 컨테이너 채우기용 100%이며 디자인 치수가 아니다. 지도 높이는 `h-80`(320px, 기본 spacing 토큰). 마커는 스펙대로 `MapPin` + 이름을 그리기 위해 `AdvancedMarker`를 쓰며, 이 마커는 Map ID가 있어야 그려지므로 `mapsMapId()`(미설정 시 `DEMO_MAP_ID`)를 넘긴다. hover 툴팁은 폴리곤 파일이 있을 때만 뜬다(없으면 마커 `title`이 같은 문구를 보여준다).
