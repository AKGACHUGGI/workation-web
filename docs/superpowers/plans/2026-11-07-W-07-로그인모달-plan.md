# W-07 로그인 모달 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 쓰기 동작(즐겨찾기·팁·투표·사진)에서 뜨는 로그인 모달(카카오·Google), 첫 로그인 온보딩 모달, Navbar 로그인 상태 분기, 세션 조회 훅을 구현한다. 인증 자체는 백엔드 OAuth 리다이렉트이며 프론트는 `GET /api/auth/me`로 상태만 읽는다.

**Architecture:** `features/auth/`에 세션 쿼리(`useAuth`, 키 `['auth','me']`)와 모달 열림 상태·보류 동작(`AuthProvider` 컨텍스트)을 둔다. W-03이 스텁으로 만든 `useRequireLogin()`의 내부를 교체해 호출부(W-03·W-04·W-05)는 바꾸지 않는다. mock 모드(`VITE_USE_MOCK=true`)는 리다이렉트 대신 `mockLogin()`이 모듈 메모리 세션을 채우고, 온보딩 후 보류 동작을 재개한다. 쿠키는 HttpOnly라 프론트는 토큰을 저장하지 않으며, 개발 서버는 Vite proxy로 `/api`를 같은 origin에 둔다.

**Tech Stack:** React 19 · TanStack Query 5 · react-router-dom 7 · lucide-react · Vitest + Testing Library · Playwright

**Spec:** `docs/superpowers/specs/2026-11-07-W-07-로그인모달-design.md`

## Global Constraints

- LG U+ 기업연계 과제: 로그인 제공자는 **카카오·Google** 2개만. Apple·네이버 등 없음.
- OAuth 앱 키는 프론트에 두지 않는다. 인증은 백엔드 리다이렉트(`GET /api/auth/{provider}/start`). 프론트는 세션 쿠키(HttpOnly; Secure; SameSite=Lax)를 읽지도 저장하지도 않는다.
- 쓰기 요청은 `credentials: 'include'` + 커스텀 헤더 `X-Requested-With: workation-web`(CSRF). 모두 `lib/api.ts`의 `api<T>()`로만 호출한다.
- `redirect` 파라미터는 path+query만 보낸다(백엔드가 같은 origin만 허용).
- 웹 데스크톱 1440 기준. 본문 맑은 고딕(공통 기반). 색·치수는 `@theme` 토큰만. 제공자 브랜드 색(카카오 `#FEE500`, 글자 `#191919`, Google 흰 배경·회색 테두리)은 각사 규정이므로 **`@theme`에 토큰으로 등록**해 쓴다(컴포넌트에 hex 금지는 유지).
- 제공자 심볼 SVG는 각사 공식 가이드에서 받은 파일만 쓴다(손으로 그리지 않음).
- 파일 1개 = 컴포넌트 1개 `export default function`. 컴포넌트 파일에서 상수·훅을 함께 export하지 않는다. `enum` 금지, 타입은 `import type`.
- `pages/`는 다른 `pages/`를 import하지 않는다. `features/auth`는 `features/metric` 외 다른 feature를 import하지 않는다.
- 접근성: 모달 `role="dialog"` + `aria-labelledby`, 포커스 트랩, 열릴 때 첫 버튼 포커스, 닫히면 열었던 요소로 복귀(공통 `Modal`이 담당).
- Conventional Commits. 커밋 전 `pnpm lint && pnpm format:check && pnpm build && pnpm test`.

`src/lib/api.ts` 전체 교체(W-03 최종본 기준. W-03의 404 → `NotFoundError`는 그대로 두고, `BASE_URL`은 `API_BASE_URL`로 이름을 바꿔 export한다. W-03은 `headers` 뒤에 `...init`을 펼쳐 호출부가 `headers`를 주면 기본 헤더가 통째로 사라졌는데, 여기서는 `...init`을 먼저 펼치고 헤더를 병합한다):

```ts
import { NotFoundError, UnauthorizedError } from '@/lib/errors'

/**
 * 개발 서버는 Vite proxy(/api → VITE_API_BASE_URL)로 같은 origin 을 유지해
 * 세션 쿠키(SameSite=Lax)가 붙는다. 빌드 결과는 VITE_API_BASE_URL 을 직접 호출한다.
 */
export const API_BASE_URL: string = import.meta.env.DEV ? '' : import.meta.env.VITE_API_BASE_URL

export async function api<T>(path: string, init?: RequestInit): Promise<T> {
  const res = await fetch(`${API_BASE_URL}${path}`, {
    ...init,
    credentials: 'include',
    headers: {
      'Content-Type': 'application/json',
      // CSRF: 백엔드가 쓰기 요청에서 이 헤더를 요구한다
      'X-Requested-With': 'workation-web',
      ...init?.headers,
    },
  })
  if (res.status === 401) throw new UnauthorizedError(path)
  if (res.status === 404) throw new NotFoundError(path)
  if (!res.ok) throw new Error(`API ${res.status} ${res.statusText}: ${path}`)
  // 본문 없는 응답(로그아웃·탈퇴·즐겨찾기 삭제)은 JSON 을 파싱하지 않는다
```

```ts
import { API_BASE_URL } from '@/lib/api'
import type { AuthProvider } from '@/features/auth/types'

/** 로그인 후 돌아올 곳. path+query 만 (origin 없음 — 백엔드가 같은 origin 만 허용). login=1 로 복귀를 표시 */
export function buildReturnTo(pathname: string, search: string): string {
  const params = new URLSearchParams(search)
  params.delete('login')
  params.delete('reason')
  params.set('login', '1')
  return `${pathname}?${params.toString()}`
}

/** 백엔드 OAuth 시작 URL. 앱 키는 프론트에 없다 */
export function startUrl(provider: AuthProvider, returnTo: string): string {
  return `${API_BASE_URL}/api/auth/${provider}/start?redirect=${encodeURIComponent(returnTo)}`
}
```

```tsx
import { useCallback, useEffect, useMemo, useRef, useState } from 'react'
import type { ReactNode } from 'react'
import { useQueryClient } from '@tanstack/react-query'
import { useToast } from '@/components/ui/toast/useToast'
import { AuthContext } from '@/features/auth/authContext'
import type { AuthContextValue, LoginOptions } from '@/features/auth/authContext'
import LoginModal from '@/features/auth/components/LoginModal'
import LoginReturnWatcher from '@/features/auth/components/LoginReturnWatcher'
import OnboardingModal from '@/features/auth/components/OnboardingModal'
import { authKeys } from '@/features/auth/queryKeys'
import { useAuth } from '@/features/auth/useAuth'
import { UnauthorizedError } from '@/lib/errors'

/**
 * 로그인 모달 열림 상태와 보류 동작(pendingAction)을 관리한다. RootLayout(ToastProvider 안쪽)에서 한 번 감싼다.
 * - 로그인 완료(me 있고 온보딩 불필요) → 모달 닫기, 보류 동작 실행 (onDismiss 는 버림)
 * - 사용자가 닫음(closeLogin) → 보류 동작 버림, onDismiss 호출
 * - me.needsOnboarding → OnboardingModal
 * - 조회·뮤테이션이 401 → 세션 만료로 보고 me 를 null 로, 모달 열기 (['auth','me'] 조회는 fetchMe 가 401 을 null 로 바꾸므로 제외)
 */
export default function AuthProvider({ children }: { children: ReactNode }) {
  const queryClient = useQueryClient()
  const { show } = useToast()
  const { me } = useAuth()
  const [isOpen, setOpen] = useState(false)
  const [returned, setReturned] = useState(false)
  const pendingRef = useRef<(() => void) | null>(null)
  const dismissRef = useRef<(() => void) | null>(null)

  const openLogin = useCallback((pending?: () => void, opts?: LoginOptions) => {
    pendingRef.current = pending ?? null
    dismissRef.current = opts?.onDismiss ?? null
    setOpen(true)
  }, [])
  const closeLogin = useCallback(() => {
    const onDismiss = dismissRef.current
    pendingRef.current = null
    dismissRef.current = null
    setOpen(false)
    onDismiss?.()
  }, [])
  const markReturned = useCallback(() => setReturned(true), [])

  const isOnboardingOpen = !!me?.needsOnboarding

  // 로그인 완료 → 모달 닫기, 복귀 토스트, 보류 동작 재개
  useEffect(() => {
    if (!me || me.needsOnboarding) return
    setOpen(false)
    dismissRef.current = null
    if (returned) {
      show('로그인했습니다')
      setReturned(false)
    }
    const pending = pendingRef.current
    pendingRef.current = null
    pending?.()
  }, [me, returned, show])

  // 세션 만료: 조회·쓰기 요청 401 → me=null + 모달
  useEffect(() => {
    const expire = () => {
      queryClient.setQueryData(authKeys.me, null)
      pendingRef.current = null
      dismissRef.current = null
      setOpen(true)
    }
    const unsubQueries = queryClient.getQueryCache().subscribe((event) => {
      if (
        event.type === 'updated' &&
        event.action.type === 'error' &&
        event.action.error instanceof UnauthorizedError &&
        event.query.queryKey[0] !== authKeys.me[0]
      ) {
        expire()
      }
    })
    const unsubMutations = queryClient.getMutationCache().subscribe((event) => {
      if (
        event.type === 'updated' &&
        event.action.type === 'error' &&
        event.action.error instanceof UnauthorizedError
      ) {
        expire()
      }
    })
    return () => {
      unsubQueries()
      unsubMutations()
    }
  }, [queryClient])

  const value = useMemo<AuthContextValue>(
    () => ({ isOpen, openLogin, closeLogin, isOnboardingOpen, markReturned }),
    [isOpen, openLogin, closeLogin, isOnboardingOpen, markReturned],
  )

  return (
    <AuthContext.Provider value={value}>
      {children}
      <LoginReturnWatcher />
      <LoginModal open={isOpen && !me} onClose={closeLogin} />
      {me?.needsOnboarding && <OnboardingModal me={me} />}
    </AuthContext.Provider>
  )
}
```

```ts
import { useCallback } from 'react'
import { useAuthContext } from '@/features/auth/authContext'
import { useAuth } from '@/features/auth/useAuth'

/**
 * 쓰기 동작 앞에 건다. 로그인 상태면 즉시 실행, 아니면 로그인 모달을 열고 동작을 보류한다.
 * 보류 동작은 같은 페이지에서 로그인이 끝나면(mock·온보딩) 재개되고, OAuth 리다이렉트로
 * 페이지가 다시 로드되면 사라진다(사용자가 다시 클릭).
 */
export function useRequireLogin(): (action: () => void) => void {
  const { isLoggedIn } = useAuth()
  const { openLogin } = useAuthContext()
  return useCallback(
    (action: () => void) => {
      if (isLoggedIn) action()
      else openLogin(action)
    },
    [isLoggedIn, openLogin],
  )
}
```

```tsx
        id={id}
        type="text"
        value={value}
        maxLength={maxLength}
        autoFocus={autoFocus}
        aria-invalid={error ? true : undefined}
        aria-describedby={describedBy}

        </span>

        </span>
      ) : null}
```

```ts
export const NICKNAME_MIN = 2
export const NICKNAME_MAX = 12

/** 공백을 다듬은 길이가 2~12자면 null, 아니면 에러 문구 */
export function validateNickname(value: string): string | null {
  const len = value.trim().length
  if (len < NICKNAME_MIN || len > NICKNAME_MAX)
    return `닉네임은 ${NICKNAME_MIN}~${NICKNAME_MAX}자로 입력해 주세요`
  return null
}
```

```tsx
export default function OnboardingModal({ me }: Props) {
  const queryClient = useQueryClient()
  const { show } = useToast()
  const { closeLogin } = useAuthContext()
  const [nickname, setNickname] = useState(me.nickname)
  const [terms, setTerms] = useState(false)
  const [privacy, setPrivacy] = useState(false)
  const error = validateNickname(nickname)
  const canSubmit = !error && terms && privacy

    mutationFn: () => patchMe({ nickname: nickname.trim(), agreedAt: new Date().toISOString() }),
    onSuccess: (next) => queryClient.setQueryData(authKeys.me, next),
    onError: () => show('저장하지 못했습니다. 다시 시도해 주세요'),

    mutationFn: logout,

      closeLogin()
      queryClient.setQueryData(authKeys.me, null)
      show('약관에 동의해야 이용할 수 있어요')

          id="onboarding-nickname"
          label="닉네임"
          value={nickname}
          onChange={setNickname}
          maxLength={NICKNAME_MAX}
          error={error ?? undefined}
          hint="2~12자 · 공개"
          autoFocus
        />
      </div>
      <div className="mt-4 flex flex-col gap-2">
        <Checkbox
          id="onboarding-terms"
          checked={terms}
          onChange={setTerms}
          label={
            <>
              <a href="/terms" target="_blank" rel="noopener" className="underline">
                이용약관
              </a>
              에 동의합니다
            </>
          }
        />
```

```ts
 * 백엔드 콜백이 `?login=1` 또는 `?login=error&reason=…` 로 돌려보낸 것을 처리한다.
 * - login=1: 세션 재검증 → AuthProvider 가 온보딩 또는 "로그인했습니다" 토스트
 * - login=error: 실패 토스트 + 모달 다시 열기
 * 두 경우 모두 쿼리를 replace 로 지운다(뒤로가기 기록 없음).
 */
export function useLoginReturn(): void {
  const [params, setParams] = useSearchParams()
  const queryClient = useQueryClient()
  const { show } = useToast()
  const { markReturned, openLogin } = useAuthContext()
  const login = params.get('login')

  useEffect(() => {
    if (!login) return
    if (login === '1') {
      void queryClient.invalidateQueries({ queryKey: authKeys.me })
      markReturned()
    } else if (login === 'error') {
      show('로그인에 실패했습니다. 다시 시도해 주세요')
      openLogin()
    }
    setParams(
      (prev) => {
        const next = new URLSearchParams(prev)
        next.delete('login')
        next.delete('reason')
        return next
      },
      { replace: true },
    )
  }, [login, queryClient, markReturned, openLogin, show, setParams])
}
```

```tsx
import { useEffect, useRef, useState } from 'react'
import { useMutation, useQueryClient } from '@tanstack/react-query'
import { Link, useNavigate } from 'react-router-dom'
import Avatar from '@/components/ui/Avatar'
import { useToast } from '@/components/ui/toast/useToast'
import { logout } from '@/features/auth/api'
import { useAuthContext } from '@/features/auth/authContext'
import { authKeys } from '@/features/auth/queryKeys'
import { useAuth } from '@/features/auth/useAuth'

/** Navbar 우측. 비로그인: 로그인 버튼 → 모달. 로그인: 아바타 → 마이페이지 · 로그아웃 */
export default function AuthMenu() {
  const { me, isPending } = useAuth()
  const { openLogin } = useAuthContext()
  const queryClient = useQueryClient()
  const navigate = useNavigate()
  const { show } = useToast()
  const [open, setOpen] = useState(false)
  const root = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!open) return
    const onDown = (e: MouseEvent) => {
      if (!root.current?.contains(e.target as Node)) setOpen(false)
    }
    const onKey = (e: KeyboardEvent) => {
      if (e.key === 'Escape') setOpen(false)
    }
    document.addEventListener('mousedown', onDown)
    document.addEventListener('keydown', onKey)
    return () => {
      document.removeEventListener('mousedown', onDown)
      document.removeEventListener('keydown', onKey)
    }
  }, [open])

  const signOut = useMutation({
    mutationFn: logout,
    onSettled: () => {
      setOpen(false)
      // /me 에서 로그아웃할 때 MyPage 가 비로그인으로 재렌더되기 전에 먼저 떠난다
      navigate('/')
      queryClient.setQueryData(authKeys.me, null)
      // W-08 meKeys.all(['me']) 캐시 비우기. features/auth 는 features/me 를 import 하지 않으므로 키를 직접 쓴다
      queryClient.removeQueries({ queryKey: ['me'] })
      show('로그아웃했습니다')
    },
  })

  if (isPending) return <div aria-hidden="true" className="h-10 w-20" />

  if (!me) {
    return (
      <button
        type="button"
        onClick={() => openLogin()}
        className="border-border-default text-body-sm text-text-primary hover:border-border-strong rounded-lg border px-4 py-2"
      >
        로그인
      </button>
    )
  }

  return (
    <div ref={root} className="relative">
      <button
        type="button"
        aria-label={`${me.nickname} 메뉴`}
        aria-haspopup="menu"
        aria-expanded={open}
        onClick={() => setOpen((v) => !v)}
        className="rounded-full"
      >
        <Avatar initial={me.initial} />
      </button>
      {open && (
        <div
          role="menu"
          className="border-border-default bg-bg-surface shadow-float absolute top-12 right-0 flex w-40 flex-col rounded-xl border p-1"
        >
          <Link
            role="menuitem"
            to="/me"
            onClick={() => setOpen(false)}
            className="text-body-sm text-text-primary hover:bg-bg-subtle rounded-lg px-3 py-2"
          >
            마이페이지
          </Link>
          <button
            type="button"
            role="menuitem"
            disabled={signOut.isPending}
            onClick={() => signOut.mutate()}
            className="text-body-sm text-text-primary hover:bg-bg-subtle rounded-lg px-3 py-2 text-left"
          >
            로그아웃
          </button>
        </div>
      )}
    </div>
  )
}
```
