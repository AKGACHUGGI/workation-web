## 1. 목적

홈은 "지금 어디가 어떤지"를 지도 한 장으로 보여주는 탐색 화면이다. 추천 지역 카드 목록은 **팀 결정으로 제외**했고(순위는 W-02가 담당), 검색창과 전체 폭 히트맵만 남긴다. 검색 문장 파싱은 백엔드 API다.

### 3-1. 검색 영역 (`SearchSection`)

- 제목·설명 문구는 Figma v2. "13개" → "12개".
- `SearchBar`: 입력 + 돋보기 버튼. Enter/클릭 → `POST /api/search/parse`. 로딩 중 버튼 스피너. 결과 `tags.length === 0`이면 입력 아래 "조건을 찾지 못했어요. 예시처럼 시기 · 분위기 · 동네를 적어보세요".
- `ExampleChips`: 예시 3개(`Chip`). 클릭 → 입력에 채우고 바로 파싱.
- `IntentTags`: 파싱 결과 `tags[]`를 `Tag` 칩 + `×`. 개별 삭제 시 해당 축만 URL에서 제거. "조건 지우기" → `q` 및 파싱 유래 값 모두 제거.
- 파싱 결과 적용 규칙: `month` → `month`, `preset` → `preset`(+`metrics`), `terrain` → `terrain`, `stay`·`peer`는 태그로만 표시(1차 동작 없음; `peer`는 2차에 `metrics`에 추가 검토).

### 3-2. 조작 줄 (`HeatmapControls`)

| 조작            | 컴포넌트                                                                                                                              | URL                             |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| 시군구 / 행정동 | `Segmented`                                                                                                                           | `scope`                         |
| 지표            | `Chip` ×6: 종합 · 동네 조용함 · 시기 여유 · 또래 밀도 · 저녁 활기 · 숙박 성향                                                         | `metric` (`value` \| MetricKey) |
| 지형            | `Chip` 토글 ×3: 해안 · 산간 · 도시 (복수 선택, 없으면 전체)                                                                           | `terrain`                       |
| 프리셋          | 드롭다운 `조용한 곳 · 활기 있는 한 달 · 직접 설정`. `metric=value`일 때만 활성. 직접 설정이면 아래에 `CustomMetricToggles`(W-02) 펼침 | `preset`, `metrics`             |
| 월              | 월 칩(W-02 §3-2 동일)                                                                                                                 | `month`                         |

- 행정동 모드에서 `숙박 성향`은 비활성 + 툴팁(W-02 §3-3과 동일 문구).
- 행정동 모드는 **시군구를 먼저 골라야** 동 폴리곤을 표시한다(Figma 문구 "행정동 레벨은 선택한 시군구 안에서만 표시됩니다"). 시군구 미선택 시 시군구 폴리곤을 옅게 그리고 "시군구를 클릭하면 행정동을 표시합니다" 안내. 클릭 → `sgg` 설정.

### 3-3. 지도 (`RegionHeatmap`)

- `GoogleMapProvider` + `PolygonLayer`. 초기 뷰는 12개 시군구 bbox(강원·전북·전남·제주) fit. 행정동 모드는 선택 시군구 bbox fit.
- 색: `colorScale(score)` → `heat-100…700` 7단계(0~14, 15~28, …, 86~100). 지형 필터에 안 맞거나 데이터 없는 단위는 `gray-200` + 외곽선만.
- hover: 폴리곤 외곽선 굵게 + 툴팁 `{name} · {score}점 · {grade}` (종합이면 `{프리셋 라벨} {score}점 · {grade}`).
- click: 시군구 모드 → `/regions/{id}`; 행정동 모드 → 시군구 미선택이면 `sgg` 설정, 선택됨이면 `/dongs/{id}`. `useCarryLink`로 `month`·`preset`·`metrics` 유지.
- 지역 이름 라벨: 폴리곤 중심에 `{name} {score}`(Figma 라벨 핀 스타일). 행정동 모드는 hover 시만.
- 범례 `HeatLegend`(Figma 컴포넌트): 낮음 0 ─ 100 높음.
- 키 없음: `MapPlaceholder`(720px) 안에 단위별 `{name} {score} {grade}` 칩 목록을 색칠해 나열(E2E·데모 대체).

### 3-4. 하단 안내

"등급은 같은 단위 안 백분위 사분위입니다. 수동면 등 특수시설 패턴 행정동은 집계에서 제외됩니다. 지역을 클릭하면 상세 화면으로 이동합니다."

## 4. URL 상태

| 키                  | 값                                                               | 기본값                     |
| ------------------- | ---------------------------------------------------------------- | -------------------------- |
| `scope`             | `sigungu` \| `dong`                                              | `sigungu`                  |
| `sgg`               | 시군구 id                                                        | 없음 (`scope=dong`일 때만) |
| `metric`            | `value` \| `quiet` \| `crowd` \| `peer` \| `overnight` \| `vibe` | `value`                    |
| `preset`, `metrics` | 공통                                                             | `quiet`                    |
| `terrain`           | `coast`,`mountain`,`city` 쉼표 복수                              | 없음(전체)                 |
| `month`             | 공통                                                             | `2025-12`                  |
| `q`                 | 검색 문장                                                        | 없음                       |

보정(`replace`): `scope=dong&metric=overnight` → `quiet`; `terrain` 중복·무효 제거; `q`가 있으면 진입 시 파싱을 한 번 실행해 태그 복원(결과는 URL의 다른 키와 충돌 시 **URL 값 우선**).

## 5. API 계약

### 5-1. 재사용 `GET /api/tier?month&scope` (W-02 §5) — 계약 갱신

`TierItem`에 필드 추가:

```ts
terrain: ('coast' | 'mountain' | 'city')[]   // 수동 데이터. 시군구: 복수 가능(속초 coast,city). 행정동: 소속 시군구 값 상속 또는 개별
```

`scope=dong` 응답에는 `sigungu.id`가 있으므로 `sgg` 필터는 프론트에서 한다.

### 5-2. `POST /api/search/parse`

```ts
// features/search/types.ts
export type SearchParseRequest = { text: string }
export type SearchIntent = {
  month?: MonthParam // '2025-10' | 'annual'
  monthRange?: number[] // '가을' 같은 범위면 [9,10,11], month는 첫 달
  preset?: PresetKey // 'quiet' | 'lively'
  terrain?: ('coast' | 'mountain' | 'city')[]
  stay?: 'week' | 'two_weeks' | 'month'
  peer?: boolean
  tags: { axis: 'month' | 'preset' | 'terrain' | 'stay' | 'peer'; label: string }[] // 화면 표시용, 순서 유지
}
```

- 빈 결과는 `{ tags: [] }` (200). 실패(5xx·타임아웃 5초)는 토스트 "검색을 처리하지 못했습니다".
- mock: 예시 문장 3개 + "10월에 조용한 바닷가에서 한 달 정도 일하고 싶어요" 고정 응답, 그 외 `{ tags: [] }`.
- 쿼리 키 `['search', text]`, `useMutation` 대신 `useQuery({ enabled: !!q })`로 두어 `q` 복원과 통일.

### 5-3. 폴리곤

- `public/geo/sigungu.json`(12개 시군구, ≤ 150KB) + `public/geo/{sggId}.json`(W-04 §5-3 공유).

## 6. 계산 (`features/heatmap/`)

- `heatValue(item, { metric, preset, metrics })` → 숫자. `metric=value`면 `composite(scores, weights)`.
- `heatGrades(items)` → `toGrades`로 Map<id, Grade>.
- `colorScale(score) → 'heat-100' … 'heat-700'`.
- `terrainMatch(item, terrain[])`.
- `applyIntentToParams(intent, current)` → URL 패치(URL 값 우선 규칙).
