## 1. 목적

홈은 검색창 + **인기 지역 카드 목록**(즐겨찾기 많은 순 · 조회 많은 순 · 종합 점수순) + 오른쪽 **지도 히트맵**이다. 기존 "추천 지역(점수순)"을 **사용자 행동 기반 인기순**으로 바꿔 티어리스트(점수 순위)와 역할을 나눈다. 검색 문장 파싱은 백엔드 API다.

### 3-1. 검색 영역 (`SearchSection`)

- `SearchBar`, `ExampleChips`, `IntentTags` — 동작은 §5-2. 파싱 결과의 `month`·`preset`·`terrain`은 URL에 반영(URL 값 우선). 결과 0건이면 "조건을 찾지 못했어요. 예시처럼 시기 · 분위기 · 동네를 적어보세요".

### 3-2. 카테고리 스트립 (`CategoryStrip`)

| 카테고리              | 동작                                                                       |
| --------------------- | -------------------------------------------------------------------------- |
| 해안 · 산간 · 도시    | `terrain` 토글(복수). 선택 시 카드 목록 필터 + 히트맵에서 비해당 지역 회색 |
| 조용한 곳             | `preset=quiet`                                                             |
| 또래 · 저녁 활기      | `preset=lively`                                                            |
| 한 달 살기 · 워케이션 | 동작 없음(장식). 2차에 `stay` 필터 검토                                    |

- 활성 상태는 URL에서 유도(해안 선택 → 해안 탭 밑줄).

### 3-3. 인기 지역 목록 (`PopularRegions`)

- 제목 `인기 지역 {n}곳`. 우측 `Dropdown` 2개: 프리셋(조용한 곳 · 활기 있는 한 달 · 직접 설정) · 정렬(**즐겨찾기 많은 순** · 조회 많은 순 · 종합 점수순). 직접 설정이면 아래에 `CustomMetricToggles`(W-02) 펼침.
- `ListingCard`(W-08에서 공통 정의) 3열 × 4행:

| 요소  | 값                                                                |
| ----- | ----------------------------------------------------------------- |
| 사진  | `photoUrl`                                                        |
| 배지  | 정렬 기준 상위 3개: `즐겨찾기 1위`/`조회 1위`/`종합 1위` … 3위    |
| 제목  | `{name}, {province}`                                              |
| 점수  | 프리셋 종합 점수(`composite`, 월 기준) — 정렬이 인기순이어도 표시 |
| Meta1 | `tags.join(' · ')`(해안 · 속초시 인접 …)                          |
| Meta2 | `즐겨찾기 {favoriteCount} · 조회 {viewCount 축약} · {month 라벨}` |
| 칩 3  | 조용 · 또래 · 숙박 `metricGrade`                                  |
| 하트  | `useFavorites()`(W-08). 비로그인 → 로그인 모달                    |

- 클릭 → `/regions/{id}`(쿼리 유지). 지형 필터로 0개면 "조건에 맞는 지역이 없어요 · 필터 지우기".
- 안내 문구(하단): "카드는 즐겨찾기 수 · 조회수 · 종합 점수 중 선택한 기준으로 정렬됩니다. 종합 점수는 선택한 프리셋 가중치의 가중 평균(0~100), 등급은 같은 달 12곳 안에서 백분위 사분위. 수동면 등 특수시설 패턴 행정동은 제외."
- 조회수 축약 `formatCount`: 1,000 미만 그대로, 이상 `8.2천`, 10,000 이상 `1.2만`.

### 3-4. 지도 히트맵 (`HeatmapRail`, 420px)

- 헤더 `지도 히트맵` + `Segmented` `시군구|행정동`.
- 지표 칩: **종합 · 동네 조용함 · 시기 여유 · 또래 밀도**(Figma 4개 유지. 저녁 활기·숙박 성향은 W-02에서). `metric` 쿼리.
- `RegionHeatmap`: Google Maps + 시군구 폴리곤(`public/geo/sigungu.json`), 색 `colorScale(score)`(heat 7단계), 라벨 핀 `{name} {score}`. hover 툴팁 `{name} · {score}점 · {grade}`, 클릭 → W-03. 행정동 모드는 시군구를 먼저 클릭(`sgg`) → 그 안의 동 폴리곤(`public/geo/{sggId}.json`), 클릭 → W-04. 지형 필터 비해당은 회색.
- 범례 `HeatLegend`. 하단 안내 "지역을 클릭하면 상세(W-03)로 이동 · 행정동 레벨은 선택한 시군구 안에서만 표시됩니다".
- 키 없음: `MapPlaceholder` 안에 단위별 색칠 칩 목록.
- 카드 hover ↔ 지도 폴리곤 강조 연동(같은 `hoverId` 상태).

## 4. URL 상태

| 키                         | 값                                | 기본값                   |
| -------------------------- | --------------------------------- | ------------------------ |
| `sort`                     | `favorites` \| `views` \| `score` | `favorites`              |
| `preset`, `metrics`        | 공통                              | `quiet`                  |
| `terrain`                  | `coast`,`mountain`,`city` 복수    | 없음                     |
| `month`                    | 공통                              | `2025-12`                |
| `scope` / `sgg` / `metric` | 히트맵: `sigungu                  | dong`/ 시군구 id /`value | quiet | crowd | peer` | `sigungu` / 없음 / `value` |
| `q`                        | 검색 문장                         | 없음                     |

보정(`replace`): 무효 값 기본값, `metric`이 히트맵 칩 4개 밖이면 `value`, `terrain` 중복 제거. `q`가 있으면 진입 시 파싱 1회(URL 값 우선).

## 5. API 계약

### 5-1. `GET /api/regions/popular?month={month}`

```ts
// features/popular/types.ts
export type PopularRegion = {
  id: string
  name: string
  province: string
  photoUrl: string
  tags: string[] // Meta1
  terrain: ('coast' | 'mountain' | 'city')[] // 수동
  scores: MetricScores // month 기준 백분위 (tier와 동일 규칙)
  favoriteCount: number // 누적 즐겨찾기 수 (해제 반영)
  viewCount: number // 최근 30일 W-03 조회수 (백엔드 중복 제거 규칙)
}
export type PopularResponse = { month: MonthParam; asOf: string; items: PopularRegion[] } // 12개 전부, 정렬 없음
```

- 정렬·필터·종합 점수·등급은 프론트(`sortPopular`, `terrainMatch`, `composite`, `toGrades`). `sort=score`는 `composite` 내림차순, 동점은 `favoriteCount`.
- 캐시 `staleTime` 5분. 쿼리 키 `['popular', { month }]`.
- 조회수 기록: W-03 진입 시 `POST /api/regions/{id}/view`(beacon, 실패 무시). W-03 스펙 §5에 추가(이 문서가 계약 출처).

### 5-2. `POST /api/search/parse`

```ts
export type SearchParseRequest = { text: string }
export type SearchIntent = {
  month?: MonthParam
  monthRange?: number[]
  preset?: PresetKey
  terrain?: ('coast' | 'mountain' | 'city')[]
  stay?: 'week' | 'two_weeks' | 'month'
  peer?: boolean
  tags: { axis: 'month' | 'preset' | 'terrain' | 'stay' | 'peer'; label: string }[]
}
```

- 빈 결과 `{ tags: [] }`(200). 5xx·타임아웃 5초 → 토스트. mock: 예시 3문장 + 시연 문장 고정 응답.

### 5-3. 재사용

- `GET /api/tier?month&scope` — 히트맵 색칠 값(종합은 `composite`, 나머지 `scores[metric]`). `TierItem.terrain` 필드 추가(W-02 계약 갱신).
- 폴리곤 `public/geo/`(W-04 §5-3).
