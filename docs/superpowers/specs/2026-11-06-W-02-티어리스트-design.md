## 1. 목적

12개 시군구(또는 행정동)를 S / A / B / C 등급으로 나눠, 사용자가 "이번 달 어디가 나에게 맞는지"를 한눈에 고르게 한다. 등급의 기준은 두 가지다.

- **워케이션 밸류 탭**: 프리셋(또는 직접 설정)의 종합 점수
- **개별 지표 탭**: 지표 하나의 점수

5개 지표는 A군(동네 조용함·또래 밀도·저녁 활기)과 B군(시기 여유·숙박 성향)이 서로 반대로 움직이므로, 하나의 고정 가중치로 묶지 않고 프리셋별 종합 점수로 정의한다(공통 기반 §5).

## 2. 결정 요약

| 항목               | 결정                                                                             |
| ------------------ | -------------------------------------------------------------------------------- |
| 직접 설정 입력     | 지표 토글 5개, 선택한 지표만 같은 가중치. 최소 1개                               |
| 행정동 범위 표시   | 시군구 필터 칩 + 등급별 6개까지 표시, `+ N개 더보기`                             |
| 행정동 등급 기준   | 전체 행정동 기준으로 계산한 뒤 필터. 필터는 등급을 바꾸지 않는다                 |
| 행정동의 숙박 성향 | 시군구 값을 물려받는다. 개별 지표 탭에서는 행정동 범위일 때 비활성               |
| 연간               | 12개월 집계 점수(§5)                                                             |
| 재계산             | 탭·프리셋·지표·필터 변경은 프론트 계산. API 재호출은 `month`, `scope` 변경 시만  |

### 3-1. 머리 영역

- 제목: "티어리스트" (`heading-2xl` 계열, Figma 기준)
- 설명: "프리셋 종합 점수(워케이션 밸류) 또는 지표 하나로 {N}개 {시군구|행정동}을 S / A / B / C 등급으로 봅니다. 등급은 같은 단위 안에서 백분위 사분위." — `{N}`은 응답 `items.length`. (Figma의 "13개"는 오기이며 데이터는 12개 시군구)
- 오른쪽: `Segmented` `시군구 | 행정동` (`scope`)

### 3-2. 조작 줄

- 왼쪽: `Segmented` `워케이션 밸류 | 개별 지표` (`tab`)
- 가운데(밸류 탭에서만): 라벨 "프리셋" + `Chip` 3개 — `조용한 곳`(`quiet`), `활기 있는 한 달`(`lively`), `직접 설정`(`custom`)
- 오른쪽: 라벨 "월" + `Chip` 13개 — `연간`, `1월`~`12월`. 가로 스크롤 영역이며 선택된 칩이 보이도록 처음 렌더 시 `scrollIntoView({ inline: 'center' })`

### 3-3. 두 번째 줄 (조건부, 여러 개가 동시에 나올 수 있음)

| 조건               | 내용                                                                                                                                                                                                                     |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 밸류 탭 + `custom` | 라벨 "포함 지표" + 토글 `Chip` 5개(동네 조용함·시기 여유·또래 밀도·숙박 성향·저녁 활기) + 안내 "선택한 지표만 같은 가중치로 평균합니다 · {n}개 선택"                                                                     |
| 개별 지표 탭       | 그룹 라벨 "동네 성격" + `Segmented` [동네 조용함·또래 밀도·저녁 활기], 그룹 라벨 "시기 · 체류" + `Segmented` [시기 여유·숙박 성향]. 두 Segmented는 하나의 값(`metric`)을 공유하며, 선택되지 않은 그룹은 선택 표시가 없다 |
| `scope=dong`       | 라벨 "시군구" + `Chip` `전체` + 12개 시군구 (`sgg`)                                                                                                                                                                      |

- 직접 설정에서 선택된 지표가 1개일 때 그 칩은 `aria-disabled`이고 툴팁 "최소 1개 지표가 필요합니다".
- 행정동 범위의 `숙박 성향` 탭은 `aria-disabled`이고 툴팁 "숙박 성향은 시군구 단위로 산출되는 지표로, 행정동 간 비교는 제공하지 않습니다."

### 3-4. 등급 섹션 (`TierSection` × 4)

- 바깥 테두리 박스 안에 왼쪽 등급 패널(고정 폭) + 오른쪽 카드 3열 그리드.
- 등급 패널: 등급 글자, 범위("상위 25%", "상위 25~50%", "하위 25~50%", "하위 25%"), 설명(§6 문구 사전), "{n}개 지역". 배경은 `grade-{s|a|b|c}-bg`, 글자는 `grade-{s|a|b|c}-fg`.
- 행정동 범위: 카드 6개(2줄)까지 표시, 나머지는 `+ {n}개 더보기` 버튼으로 펼침/접기. 펼침 상태는 URL에 넣지 않는다(로컬 상태).
- 해당 등급이 0개(필터 결과)면 카드 영역에 "이 등급에 해당하는 동네가 없습니다".

### 3-5. 카드 (`TierCard`)

| 요소         | 밸류 탭                                                                 | 개별 지표 탭              |
| ------------ | ----------------------------------------------------------------------- | ------------------------- |
| 사진         | `PhotoThumb` + 월 라벨("10월" / "연간")                                 | 동일                      |
| 이름 + `›`   | 시군구명 또는 행정동명                                                  | 동일                      |
| 보조 텍스트  | 도 이름. 행정동이면 "{도} · {시군구}"                                   | 동일                      |
| 점수         | 종합 점수(정수) + "점", 등급 색                                         | 지표 점수 + "점", 등급 색 |
| 세부 등급 칩 | `SubGradeChips`: 조용·시기·또래·숙박·활기 순서, 각 `metricGrade(score)` | 없음                      |

- `SubGradeChips`: 짧은 라벨(`METRIC_SHORT_LABEL`: 조용/시기/또래/숙박/활기) + `GradeBadge size="sm"`. 직접 설정에서 선택되지 않은 지표는 `opacity` 토큰으로 흐리게(Figma 0.35). `inherited`에 포함된 지표는 툴팁 "시군구 산출값".
- 카드 전체가 링크(`<a>`)다. 시군구 → `/regions/:id`, 행정동 → `/dongs/:id`, `useCarryLink`로 `month`, `preset`, `metrics` 유지.
- 1440 폭 기준 3열. 세부 칩이 2줄로 넘어가는 것은 Figma와 같이 허용.

### 3-6. 하단 주석

| 상황               | 문구                                                                                                                                                                                                                                            |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 밸류 탭(프리셋)    | 등급은 선택한 프리셋의 종합 점수를 같은 단위 안에서 사분위로 나눈 것입니다. 카드의 세부 등급은 조용 = 동네 조용함, 시기 = 시기 여유, 또래 = 또래 밀도, 숙박 = 숙박 성향, 활기 = 저녁 활기. 마스킹 비율 30% 초과 행정동은 비공개.                |
| 밸류 탭(직접 설정) | 직접 설정에서는 고른 지표만 같은 가중치로 평균해 등급을 나눕니다. 고르지 않은 지표의 세부 등급은 흐리게 표시. (이하 약어 설명·마스킹 동일)                                                                                                      |
| 개별 지표 탭       | 개별 지표 탭은 선택한 지표 하나의 백분위로 등급을 나눕니다. {지표 정의}. 동네 성격 그룹(동네 조용함 · 또래 밀도 · 저녁 활기)은 행정동 단위가 기본, 시기 · 체류 그룹(시기 여유 · 숙박 성향)은 시군구 단위. 마스킹 비율 30% 초과 행정동은 비공개. |

`{지표 정의}`는 `METRIC_DEFINITION[metric]`(예: "동네 조용함 = 평일 낮 체류 ÷ 새벽 체류, 낮을수록 조용").

## 4. URL 상태

| 키        | 값                              | 기본값                  | 비고                                                      |
| --------- | ------------------------------- | ----------------------- | --------------------------------------------------------- |
| `tab`     | `value` \| `metric`             | `value`                 |                                                           |
| `preset`  | `quiet` \| `lively` \| `custom` | `quiet`                 | 공통 키                                                   |
| `metrics` | 쉼표 구분 `MetricKey`           | `quiet,crowd,overnight` | `preset=custom`일 때만 읽음. 빈 값·모르는 키는 기본값으로 |
| `metric`  | `MetricKey`                     | `quiet`                 | `tab=metric`일 때만 읽음                                  |
| `scope`   | `sigungu` \| `dong`             | `sigungu`               |                                                           |
| `sgg`     | `all` \| 시군구 id              | `all`                   | `scope=dong`일 때만 읽음. 응답에 없는 id면 `all`          |
| `month`   | `annual` \| `2025-01`~`2025-12` | `2025-12`               | 공통 키                                                   |

보정 규칙(모두 `replace`):

- `scope=dong` 이고 `metric=overnight` → `metric=quiet`
- `metrics`에서 중복 제거, `METRIC_KEYS` 순서로 정렬해 직렬화(같은 선택이 같은 URL이 되도록)

변경 규칙: 탭·프리셋·지표·범위·월·필터 변경은 `push`. 토글은 클릭 단위이므로 `push`.

## 5. API 계약

### `GET /api/tier?month={month}&scope={scope}`

```ts
// features/tier/types.ts
import type { MetricKey, MetricScores } from '@/features/metric/types'

export type TierScope = 'sigungu' | 'dong'
export type MonthParam =
  | `2025-${'01' | '02' | '03' | '04' | '05' | '06' | '07' | '08' | '09' | '10' | '11' | '12'}`
  | 'annual'

export type TierResponse = {
  month: MonthParam
  scope: TierScope
  items: TierItem[]
}

export type TierItem = {
  id: string // 시군구코드(5자리) 또는 행정동코드(10자리)
  name: string // "양양군" / "거진읍"
  province: string // "강원특별자치도"
  sigungu?: { id: string; name: string } // scope=dong 일 때 필수
  photoUrl: string
  scores: MetricScores // 0~100 정수, 같은 month·scope 안의 백분위
  inherited: MetricKey[] // 상위 단위 값을 물려받은 지표. scope=dong → ['overnight'], sigungu → []
}
```

백엔드 산출 규칙(계약의 일부):

| 지표        | 원천 값                                          | 방향               | 행정동         | 연간(`annual`)     |
| ----------- | ------------------------------------------------ | ------------------ | -------------- | ------------------ |
| `quiet`     | `day_inflow` (평일 낮 체류 ÷ 새벽 체류)          | 낮을수록 높은 점수 | 동 값          | 12개월 평균        |
| `crowd`     | 해당 월 혼잡도 (`crowd_dong` / 시군구 혼잡도)    | 낮을수록 높은 점수 | 동 값          | 12개월 평균 혼잡도 |
| `peer`      | 또래(20~40대) 비중                               | 높을수록           | 동 값          | 12개월 평균        |
| `overnight` | 시군구 숙박 계수                                 | 높을수록           | 시군구 값 상속 | 연중 상수          |
| `vibe`      | `evening_vibe` (평일 저녁 유동 ÷ 평일 저녁 체류) | 높을수록           | 동 값          | 12개월 평균        |

- 백분위는 같은 `month`·`scope` 안의 모든 응답 단위를 모집단으로 하고 0~100 정수로 반올림한다. 행정동의 `overnight`도 행정동 모집단 기준 백분위로 다시 계산한다(값은 같은 시군구끼리 같음).
- 마스킹 비율 30% 초과 행정동은 응답에서 제외한다(백분위 모집단에서도 제외).
- 캐시: 데이터가 월 단위 정적이므로 `Cache-Control: max-age=3600` 권장.

### 쿼리 키

`['tier', { month, scope }]` — 탭·프리셋 등은 키에 넣지 않는다.

## 6. 계산 (`features/tier/`)

```ts
type TierMode =
  | { tab: 'value'; weights: Weights; selected?: MetricKey[] } // selected: custom일 때 흐리게 표시용
  | { tab: 'metric'; metric: MetricKey }

type TierEntry = { item: TierItem; score: number; grade: Grade }
type TierGroup = { grade: Grade; entries: TierEntry[] }

function buildTiers(items: TierItem[], mode: TierMode): TierGroup[] // 항상 S, A, B, C 4개
function filterTiers(groups: TierGroup[], sgg: string | 'all'): TierGroup[]
function customWeights(selected: MetricKey[]): Weights // 선택 1, 나머지 0
```

- 점수: 밸류 탭은 `composite(item.scores, weights)`, 개별 지표 탭은 `item.scores[metric]`. 표시는 `Math.round`.
- 등급: `toGrades(점수 배열)` (공통 기반 §5, 사분위·동점 같은 등급).
- 정렬: 등급 안에서 점수 내림차순, 동점은 `name` 가나다순(`localeCompare('ko')`).
- `filterTiers`는 등급 계산 뒤 `item.sigungu.id === sgg`만 남긴다.
- 프리셋 가중치는 `features/metric`의 `PRESET_WEIGHTS`를 쓴다(조용한 곳 3,3,1,1,0 / 활기 0,1,3,2,3, 순서 quiet·crowd·peer·overnight·vibe).

### 등급 패널 문구 사전 (`TIER_COPY`)

| 모드             | S                                                  | A         | B         | C                                |
| ---------------- | -------------------------------------------------- | --------- | --------- | -------------------------------- |
| 프리셋 `quiet`   | 조용한 곳 프리셋 종합 점수                         | 평균 이상 | 평균 이하 | 조용한 곳 조건과 거리 있음       |
| 프리셋 `lively`  | 활기 있는 한 달 프리셋 종합 점수                   | 평균 이상 | 평균 이하 | 활기 있는 한 달 조건과 거리 있음 |
| `custom`         | 직접 설정 종합 점수 ({선택 지표 짧은 라벨 · 구분}) | 평균 이상 | 평균 이하 | 선택한 조건과 거리 있음          |
| 지표 `quiet`     | 동네 조용함 · 낮 유입 지수 낮음                    | 평균 이상 | 평균 이하 | 낮에 사람이 몰리는 지역          |
| 지표 `crowd`     | 시기 여유 · 이 달 혼잡도 낮음                      | 평균 이상 | 평균 이하 | 이 달 사람이 몰리는 지역         |
| 지표 `peer`      | 또래 밀도 · 20~40대 비중 높음                      | 평균 이상 | 평균 이하 | 또래 비중이 낮은 지역            |
| 지표 `overnight` | 숙박 성향 · 머무는 방문객 많음                     | 평균 이상 | 평균 이하 | 당일 방문 위주 지역              |
| 지표 `vibe`      | 저녁 활기 · 저녁 유동 많음                         | 평균 이상 | 평균 이하 | 저녁이 한산한 지역               |

Figma에 있는 문구(프리셋 quiet, custom, 지표 quiet)는 그대로이고, 나머지는 같은 형식으로 새로 쓴 것이다. 디자인 검수 대상.

### `features/metric` 추가 항목

- `METRIC_SHORT_LABEL`: quiet 조용, crowd 시기, peer 또래, overnight 숙박, vibe 활기
- `METRIC_DEFINITION`: 하단 주석용 한 줄 정의
- `PRESET_LABEL`: quiet 조용한 곳, lively 활기 있는 한 달, custom 직접 설정

## 10. 테스트

### Vitest

- `buildTiers`
  - 조용한 곳 10월 픽스처 → S = 양양·전주·고성, C = 정읍·동해·고흥
  - 활기 프리셋 → 1위 전주
  - 직접 설정(quiet, crowd, overnight) → 1위 양양 67
  - 개별 지표 `quiet` → 점수 = `scores.quiet`
  - 동점 처리, 이름순 정렬
- `filterTiers`: 필터 후 각 항목의 등급이 필터 전과 같다
- `customWeights`: 선택 1 / 나머지 0
- `CustomMetricToggles`: 토글 시 onChange, 1개 남으면 해제 불가(`aria-disabled`)
- URL 보정: `scope=dong&metric=overnight` → `metric=quiet`, `metrics=vibe,quiet,quiet` → `quiet,vibe`

### Playwright E2E

1. **프리셋 전환**: `/tier?month=2025-10` 진입 → S 섹션 첫 카드 "양양군" → `활기 있는 한 달` 클릭 → 첫 카드 "전주시", URL에 `preset=lively`.
2. **직접 설정 유지**: `직접 설정` → `또래 밀도`·`저녁 활기` 끄기 → 카드의 또래·활기 칩이 흐림 → 새로고침 후 같은 상태, URL `metrics=quiet,crowd,overnight`.
3. **행정동 범위**: `행정동` 클릭 → `개별 지표` 탭에서 `숙박 성향`이 비활성 → 시군구 필터 `고성군` → 모든 카드 보조 텍스트에 "고성군" → `+ N개 더보기`로 카드 증가.
