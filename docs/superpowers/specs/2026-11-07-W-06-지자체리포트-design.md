## 1. 목적

지자체 담당자용 한 장 요약. 시군구 하나의 성수기 집중도, 숙박 성향, 대상 지역 대비 위치, 월별 방문 지수, 진단 요약을 연간 기준으로 보여주고 PDF로 내려받는다. 명세상 2차 기능이지만 화면은 1차에 구현한다(데이터가 이미 있음). PDF는 백엔드가 생성한다.

## 2. 결정 요약

| 항목           | 결정                                                                                                     |
| -------------- | -------------------------------------------------------------------------------------------------------- |
| 범위           | 화면 1차 구현. "2차 기능" 태그는 유지(명세 분류)                                                         |
| PDF            | **백엔드 생성** `GET /api/reports/{sggId}/pdf?year=2025`. 프론트는 다운로드만. 브라우저 인쇄는 쓰지 않음 |
| 진단 요약 문장 | **백엔드 응답**에 포함(`diagnosis`). 화면과 PDF가 같은 문장을 쓰기 위해. 규칙 템플릿/LLM은 백엔드 결정   |
| 기준           | 연간(2025) 고정. `preset` 쿼리로 연간 순위의 프리셋만 바꿀 수 있음                                       |
| 차트           | Recharts `BarChart` (W-03 월별 막대와 같은 컴포넌트)                                                     |
| 순위 계산      | 연간 순위는 **백엔드 응답**(`ranking`). 월별 tier를 평균하는 규칙이 프론트에 없어도 되게                 |

### 3-1. 머리 영역

- 제목 + `Tag` "2차 기능". 설명 문구는 Figma.
- 시군구 `Dropdown`(12개) → `/reports/{id}` 이동(`preset` 유지).
- `PDF 내보내기` 버튼 → §5-2. 생성 중 스피너 + 비활성, 완료 시 파일 다운로드.

### 3-2. 요약 카드 3개

| 카드                | 값                                  | 부제                                                                                 |
| ------------------- | ----------------------------------- | ------------------------------------------------------------------------------------ |
| 성수기 집중도       | `peakConcentration.value`%          | `상위 3개월({months})방문인구 ÷ 연간 방문인구. 12곳 평균 {avg}%보다 집중도 {높음     | 낮음} ({rank}위)` |
| 숙박 성향           | `overnight.score`점 + `GradeBadge`  | `숙박 계수 {coef} · 방문객 1명당 밤 체류 증가분 · 연간 기준. {OVERNIGHT_COPY}`       |
| 대상 지역 대비 위치 | `ranking.rank` 위 / `ranking.total` | `{프리셋 라벨} 프리셋 연간 순위. {strongest 지표} {n}위 · {weakest 지표} {rankCopy}` |

### 3-3. 월별 방문인구 지수 (`AnnualCrowdChart`)

- Recharts `BarChart`, `months[12].crowd`(연중 최대 = 100). 상위 3개월은 `brand` 색, 나머지 `gray-300`. 값 라벨 막대 위. 범례 "방문 지수 · 성수기 상위 3개월".
- 아래 문장 `seasonNarrative`(백엔드 응답, 예: "7·8월 여름 성수기 뒤 10월에 다시 오르는 하반기 상승형입니다. 2~4월·12월은 연중 최대의 절반 이하로, 비수기 체류 지원에 적합합니다.").

### 3-4. 순위표 (`RankingTable`)

- 12행: 순위 · 이름 · 점수 막대(최대 = 100 기준 폭) · 점수. 현재 시군구 행은 `selected-*` 배경 + `brand` 막대. 캡션 `종합 점수 · {프리셋 라벨} 프리셋 · 연간`. 행 클릭 → `/reports/{id}`.

### 3-5. 진단 요약 (`DiagnosisSection`)

- 열 3개: 강점(`GradeBadge` S) · 약점(C) · 제안(S 아이콘 대신 `sparkles`). 문장은 `diagnosis.strength / weakness / suggestion`(백엔드). 캡션 "규칙 기반 템플릿 (2차: LLM 문장)".

### 3-6. 출처

- 고정 문구(Figma). 인쇄용이 아니므로 화면 전용.

## 5. API 계약

### 5-1. `GET /api/reports/{sggId}?year=2025&preset=quiet`

```ts
// features/report/types.ts
export type ReportResponse = {
  id: string
  name: string
  province: string
  year: number
  preset: 'quiet' | 'lively'
  peakConcentration: {
    value: number
    topMonths: number[]
    average: number
    rank: number
    total: number
  } // % 정수, 상위 3개월
  overnight: { coef: number; score: number; grade: Grade } // 연간 백분위 점수·등급
  ranking: { rank: number; total: number; items: { id: string; name: string; score: number }[] } // 프리셋 연간 종합(월별 점수 평균), 내림차순
  metricRanks: Record<MetricKey, { rank: number; score: number }> // 연간 지표별 순위·점수 (요약 카드 부제·진단 입력)
  months: { month: number; crowd: number }[] // 12개, 연중 최대 = 100
  seasonType: SeasonType
  seasonNarrative: string
  diagnosis: { strength: string; weakness: string; suggestion: string }
  generatedAt: string
}
```

산출 규칙(계약): `ranking`은 월별 프리셋 종합 점수의 12개월 평균을 반올림(W-02 §5 백분위 규칙, 수동면 제외). `peakConcentration.average`는 12곳 평균. `diagnosis`는 백엔드 규칙 템플릿(입력: metricRanks, overnight, peakConcentration, seasonType, 조용한 동네 상위 2곳). 고성군 기대 문장은 Figma v2.

### 5-2. `GET /api/reports/{sggId}/pdf?year=2025&preset=quiet`

- 응답 `application/pdf`, `Content-Disposition: attachment; filename="{name}_진단리포트_{year}.pdf"`. 생성에 수 초 걸릴 수 있으므로 타임아웃 30초.
- 프론트: `fetch` → `blob` → `URL.createObjectURL` → `<a download>` 클릭. 실패 시 토스트 "PDF를 만들지 못했습니다. 잠시 후 다시 시도해 주세요".
- PDF 레이아웃은 백엔드 책임(Figma v2와 같은 구성, A4 1장). 화면과 같은 `ReportResponse`를 입력으로 쓴다.
- mock: `public/mock-pdf/sample.pdf` 반환.

### 쿼리 키

`['report', id, { year, preset }]`. 재사용 없음(연간 집계는 백엔드).
