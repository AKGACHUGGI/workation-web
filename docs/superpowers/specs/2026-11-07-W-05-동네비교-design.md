## 1. 목적

행정동 2~3개의 24시간 곡선·동네 성격·지표 4종을 나란히 놓고 고른다. W-04의 "비슷한데 더 조용한 동네" 카드와 "다른 동네와 비교" 버튼에서 들어오는 것이 주 경로다. 웹 전용(F-07, 모바일 미제공).

## 2. 결정 요약

| 항목           | 결정                                                                                                                                 |

### 3-1. 머리 영역

- 제목 "동네 비교", 설명 "행정동 2~3개의 24시간 곡선과 지표를 나란히 봅니다. 즐겨찾기나 동네 프로필에서 추가할 수 있습니다."
- 우측 월 칩(W-02 §3-2와 동일 컴포넌트, `month` 쿼리).

### 3-2. 비교 중 줄 (`CompareChips`)

- `Chip selected` `{name} · {sigunguName}` + `×`(제거). 순서는 `dongs` 쿼리 순서.
- `+ 행정동 추가` 칩(`Chip default`) → `DongPickerModal`. 3개면 `aria-disabled` + 툴팁.
- 우측 캡션 "최대 3개".

### 3-3. 열 (`CompareColumn`, 최대 3, 항상 3칸 그리드)

| 영역      | 내용                                                                                                                                                                                    |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 헤더      | 이름(제목) · `Tag` kind · `×` 제거 버튼. 보조 `{province} {sigunguName}`. 이름 클릭 → `/dongs/{id}`                                                                                     |
| 곡선      | `HourlyCurveChart` compact 모드(월 칩 없음, 주중/주말 범례만, 높이 160). 3열의 Y 기준은 각 동 자체 최대 = 100(동마다 정규화, W-04와 동일)                                               |
| 동네 성격 | `ActivityMixBar` compact(막대 + 상위 2개 라벨)                                                                                                                                          |
| 지표 4종  | 동네 조용함 / 저녁 활기 / 또래 밀도 / 생활권 지수 — W-04 §3-5와 같은 값·등급. 부제는 짧은 버전: `고성군 내 3위 · 낮 유입 0.79`, `저녁 유동 ÷ 체류 0.18`, `20~40대 39%`, `거주+근무 75%` |
| 요약      | `buildDongSummary` 한 줄                                                                                                                                                                |

- 빈 열(동이 3개 미만): 점선 테두리 박스 + "비교할 동네를 추가하세요" + `+ 추가` 버튼(모달).
- 열 로딩: 열 단위 스켈레톤. 열 에러: 열 안에 "불러오지 못했습니다 · 다시 시도".
- 시군구 내 순위(`고성군 내 3위`)는 tier dong 응답에서 같은 `sigungu.id` 항목을 `quiet` 내림차순으로 세어 계산(`rankInSigungu`).

### 3-4. 동 추가 모달 (`DongPickerModal`)

- 탭 2개: **찾기** / **비슷한 동네 추천**.
- 찾기: 상단 검색 입력(이름 부분 일치, 한글 초성 미지원) + 시군구 `Segmented`(12개) → 동 목록(이름 · kind 태그 · 동네 조용함 `GradeBadge`). 이미 비교 중인 동은 체크 표시 + 비활성. 목록 출처는 `GET /api/tier?month&scope=dong` 응답(이름·시군구·점수 모두 있음) — 새 API 불필요.
- 비슷한 동네 추천: 첫 번째 열 동의 `quieterTwins`(W-04 응답) 카드 3개. 첫 열이 없으면 탭 비활성.
- 선택 즉시 추가되고 모달 닫힘. `Esc`·바깥 클릭 닫힘, 포커스 트랩.

### 3-5. 하단 안내

"모바일에서는 제공하지 않는 웹 전용 화면(F-07). 마지막 비교 목록은 이 기기에 저장됩니다. 링크를 공유하면 같은 비교를 볼 수 있습니다."

## 4. URL 상태

| 키      | 값                                  | 기본값                                           |
| ------- | ----------------------------------- | ------------------------------------------------ |
| `dongs` | 쉼표 구분 `dongId` 1~3개, 순서 유지 | 없음 → localStorage 복원 → 그래도 없으면 빈 화면 |
| `month` | 공통                                | `2025-12`                                        |

보정(모두 `replace`): 중복 제거, 4개 이상이면 앞 3개, tier dong 응답에 없는 id(마스킹·특수시설·오타)는 제거하고 토스트 "일부 동네는 비교할 수 없어 제외했습니다".

변경: 추가·제거는 `push`. localStorage 키 `workation.compare.dongs`(JSON 배열), 쓰기는 URL 변경 후.

## 5. API

새 엔드포인트 없음.

- `GET /api/dongs/{id}?month=` × N (`useQueries`, 키 `['dong', id, { month }]`) — W-04 §5-2
- `GET /api/tier?month&scope=dong` — 모달 목록, 등급, 시군구 내 순위
- 응답 타입은 `features/dong/types.ts` 재사용.

## 6. 계산·문구 (`features/compare/`)

- `parseDongsParam(raw, validIds) → { ids, dropped }`
- `rankInSigungu(items, dongId) → { rank, total }`
- `shortMetricCopy(detail, rank)` → 지표 카드 4종 짧은 부제
- `useCompareList()` → `{ ids, add, remove, canAdd }` (URL + localStorage 동기화)

## 10. 테스트

### Vitest

- `parseDongsParam`: 중복·4개 초과·무효 id 처리
- `useCompareList`: 쿼리 없을 때 localStorage 복원(`replace`), 추가 시 URL+storage 갱신, 3개 초과 거부
- `rankInSigungu`: 거진읍 3/5
- `DongPickerModal`: 검색 필터, 이미 추가된 동 비활성, 선택 시 콜백·닫힘, Esc

### Playwright E2E

1. **링크 진입**: `/compare?dongs={거진읍},{금호동}&month=2025-10` → 열 2개 제목 "거진읍", "금호동", 빈 열 1개.
2. **추가·제거**: `+ 행정동 추가` → 모달에서 "연동" 검색·선택 → 열 3개, URL `dongs=…,…,…`, 추가 버튼 비활성 → 첫 열 `×` → 열 2개.
3. **복원**: 위 상태에서 `/compare`로 이동(쿼리 없음) → 마지막 목록이 복원되어 URL에 `dongs=`가 채워짐.
