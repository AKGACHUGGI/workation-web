## 1. 목적

로그인한 사용자의 즐겨찾기(지역·동네), 팁, 사진을 한곳에서 관리한다. 즐겨찾기는 **로그인 필수**다(비로그인 기기 저장·병합 없음). 즐겨찾기 토글은 W-03·W-04에서 일어나고, 이 화면은 목록·삭제·비교 담기·계정 관리를 맡는다.

## 2. 결정 요약

| 항목           | 결정                                                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 즐겨찾기 저장  | **로그인 필수.** 비로그인 하트 클릭 → `useRequireLogin()` → 로그인 모달. localStorage 저장·병합 없음. Figma의 "기기 즐겨찾기 자동 병합" 안내 박스 제거 |
| 즐겨찾기 상태  | 서버가 진실. `['me','favorites']` 쿼리, 토글은 낙관적 업데이트                                                                                         |
| 탭             | `내 즐겨찾기 / 내 팁 / 내 사진` — `tab` 쿼리                                                                                                           |
| 알림 설정      | 토글 3개 UI + `PATCH /api/me/settings` 저장까지. 발송은 범위 밖                                                                                        |
| 계정 삭제      | 확인 모달 1단계 후 `DELETE /api/auth/me`                                                                                                               |
| 프로필 편집    | 닉네임만 인라인 편집(`PATCH /api/auth/me`)                                                                                                             |
| 비로그인 `/me` | 로그인 모달 + 뒤에 빈 레이아웃. 닫으면 `/`로                                                                                                           |

## 3. 화면 구성 (Figma 251:4679)

```
Navbar
┌ 프로필 헤더 ───────────────────────────────────────────────┐
│ (두) 두이 [카카오 연결됨]                         [프로필 편집] │
│ 강릉 2회 · 고성 1회 체류 · 팁 7개 · 사진 12장 · 2025.03 가입    │
└────────────────────────────────────────────────────────────┘
[내 즐겨찾기 | 내 팁 7 | 내 사진 12]
┌ 본문 (탭별) ──────────────────────────┐ ┌ 사이드 ────────────┐
│ 즐겨찾기 지역 N곳   웹·앱 동기화 · 10월 기준 │ │ 알림 설정 (토글 3)    │
│ [ListingCard ×N]                       │ │ 계정                 │
│ 즐겨찾기 동네 N곳        [선택해서 비교]   │ │  로그인 방식 · 이메일  │
│ [DongRow ×N]                           │ │  닉네임 · 데이터      │
│                                        │ │  [로그아웃][계정 삭제] │
└────────────────────────────────────────┘ └────────────────────┘
Footer
```

### 3-1. 프로필 헤더

- 아바타 `Avatar`(이니셜) · 닉네임 · `Tag` `{provider 라벨} 연결됨` · 요약 문장 `buildActivitySummary(summary)`: `{stays를 "강릉 2회 · 고성 1회 체류"로} · 팁 {n}개 · 사진 {n}장 · {YYYY.MM} 가입`. stays가 없으면 "아직 체류 기록 없음".
- `프로필 편집` → 닉네임 인라인 입력(2~12자) + 저장/취소. 저장 → `PATCH /api/auth/me`, `['auth','me']` 무효화.

### 3-2. 탭

- `Segmented` `내 즐겨찾기 | 내 팁 {tipCount} | 내 사진 {photoCount}`. `tab` 쿼리(`favorites|tips|photos`), `push`.

### 3-3. 내 즐겨찾기

- **지역** `즐겨찾기 지역 {n}곳`, 캡션 `웹·앱 동기화 · {month 라벨} 기준`. `ListingCard`(사진·이름, 도·종합 점수·Meta1 태그·Meta2 메모·칩 조용/또래/숙박 등급) 3열. 카드 하트 → 즐겨찾기 해제(낙관적, 토스트 "즐겨찾기에서 뺐어요 · 되돌리기" 5초). 카드 클릭 → `/regions/{id}`.
  - 종합 점수는 `preset` 쿼리 기준 `composite`. Meta2는 `note`(사용자 메모, 없으면 `{visitMonth} 방문 예정` 또는 `{month} 시기 여유 {g} · 혼잡 {c}`). 메모 편집은 2차.
- **동네** `즐겨찾기 동네 {n}곳`, `DongRow` 목록(이름 · kind 태그 · `{sigungu} · 저녁 활기 {g} · 또래 {g}` · 동네 조용함 `GradeBadge` · ›). 행 클릭 → `/dongs/{id}`.
  - `선택해서 비교` 버튼 → 체크박스 모드, 2~3개 선택 → `비교하기` → `/compare?dongs=…`(W-05).
- 둘 다 0개면 빈 상태: "아직 즐겨찾기가 없어요. 지역 상세·동네 프로필의 하트를 눌러 담아보세요" + `탐색하기` 링크.

### 3-4. 내 팁

- 제목 `내 팁 {n}개`, 캡션 `도움돼요 합계 {sum}`. `TipCard`(W-03) + 우측 `삭제`(확인 없이 즉시, 토스트 되돌리기 5초). 카드의 지역명 클릭 → 해당 W-03/W-04. 커서 페이지네이션 `더 보기`.

### 3-5. 내 사진

- 제목 `내 사진 {n}장`, 캡션 `검수 완료 {a} · 대기 {p}`. `UserPhotoTile`(사진 · `{month} · {regionName}` · 대기면 반투명 + "검수 대기" 배지) + `이달의 사진 올리기` 타일(업로드는 W-03 투표 섹션과 같은 플로우, 2차에 정의 — 1차는 "준비 중" 토스트).

### 3-6. 사이드 · 알림 설정

- 토글 3개: `가기 좋은 달 알림`(즐겨찾기 지역의 추천 월이 다가오면), `내 팁 반응 알림`, `이달의 사진 선정 알림`. 변경 즉시 `PATCH /api/me/settings`(낙관적, 실패 시 롤백 + 토스트).

### 3-7. 사이드 · 계정

| 항목        | 값                                                                                                                                                                   |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 로그인 방식 | `{provider 라벨} (연결됨)`                                                                                                                                           |
| 이메일      | `{emailMasked} · 비공개`                                                                                                                                             |
| 닉네임      | `{nickname} · 공개`                                                                                                                                                  |
| 데이터      | `즐겨찾기 {n} · 팁 {n} · 사진 {n} · 투표 {n}`                                                                                                                        |
| 로그아웃    | `POST /api/auth/logout` → `/`로 이동 + 토스트                                                                                                                        |
| 계정 삭제   | `ConfirmModal` "계정을 삭제하면 즐겨찾기·팁·사진·투표가 모두 지워지고 되돌릴 수 없습니다." [취소][삭제] → `DELETE /api/auth/me` → `/` + 토스트 "계정을 삭제했습니다" |

- Figma의 "앱에서도 같은 즐겨찾기를 볼 수 있어요 / 기기 즐겨찾기 병합" 박스는 **"앱에서도 같은 즐겨찾기를 볼 수 있어요 · 같은 계정으로 로그인하면 웹·앱이 동기화됩니다"** 한 줄 안내로 교체.

## 5. API 계약

```ts
// features/me/types.ts
export type MeSummary = {
  stays: { regionName: string; count: number }[]
  tipCount: number
  photoCount: number
  favoriteCount: number
  voteCount: number
  createdAt: string
}
export type FavoriteRegion = {
  id: string
  name: string
  province: string
  photoUrl: string
  scores: MetricScores // month 기준 (백엔드가 넣음)
  tags: string[] // Meta1
  note?: string
  visitMonth?: MonthParam
  addedAt: string
}
export type FavoriteDong = {
  id: string
  name: string
  kind: DongKind
  sigungu: { id: string; name: string }
  scores: MetricScores
  addedAt: string
}
export type FavoritesResponse = {
  month: MonthParam
  regions: FavoriteRegion[]
  dongs: FavoriteDong[]
}
export type MyTip = Note & { target: { kind: 'region' | 'dong'; id: string; name: string } }
export type MyPhoto = {
  id: string
  url: string
  month: MonthParam
  regionName: string
  status: 'approved' | 'pending'
}
export type MeSettings = {
  notifyBestMonth: boolean
  notifyTipReaction: boolean
  notifyPhotoSelected: boolean
}
```

| 엔드포인트                                                           | 설명                                                                                               |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `GET /api/me/summary`                                                | `MeSummary`                                                                                        |
| `GET /api/me/favorites?month=`                                       | `FavoritesResponse`. 점수는 해당 월 백분위(W-02 §5 규칙). 상한 각 50개                             |
| `PUT /api/me/favorites/{kind}/{id}`                                  | 추가(멱등). `kind` = `regions` \| `dongs`. 상한 초과 409 → 토스트 "최대 50개까지 저장할 수 있어요" |
| `DELETE /api/me/favorites/{kind}/{id}`                               | 해제                                                                                               |
| `GET /api/me/favorites/ids`                                          | `{ regions: string[]; dongs: string[] }` — W-03·W-04 하트 표시용(가벼운 응답)                      |
| `GET /api/me/tips?cursor=`                                           | `{ items: MyTip[]; nextCursor?; helpfulSum }`                                                      |
| `DELETE /api/me/tips/{id}`                                           | 204                                                                                                |
| `GET /api/me/photos`                                                 | `{ items: MyPhoto[] }`                                                                             |
| `GET` / `PATCH /api/me/settings`                                     | `MeSettings`                                                                                       |
| `PATCH /api/auth/me`, `POST /api/auth/logout`, `DELETE /api/auth/me` | W-07                                                                                               |

- 모든 `/api/me/*`는 401 시 `useAuth` 캐시 무효화 + 로그인 모달(W-07 §7).

### 쿼리 키

`['me','summary']`, `['me','favorites',{month}]`, `['me','favorites','ids']`, `['me','tips']`, `['me','photos']`, `['me','settings']`.

## 6. 훅 (`features/me/`)

- `useFavorites()` → `{ isFavorite(kind,id), toggle(kind,id), isPending }`. 비로그인이면 `toggle`은 `useRequireLogin`으로 모달. 로그인 상태면 `['me','favorites','ids']`를 낙관적으로 갱신하고 `PUT/DELETE` 호출, 실패 시 롤백. W-03·W-04의 하트 버튼이 이 훅만 쓴다.
- `useMeSummary`, `useMyFavorites(month)`, `useMyTips`, `useMyPhotos`, `useMeSettings`.
- `buildActivitySummary(summary)`.

## 10. 테스트

### Vitest

- `useFavorites`: 비로그인 toggle → 모달·API 미호출; 로그인 toggle → 낙관적 갱신 + API, 실패 롤백; 409 토스트
