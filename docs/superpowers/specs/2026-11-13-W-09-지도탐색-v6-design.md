## 1. 목적

지도에서 동네를 고르면, 그 동네가 **어떤 사실들로 이어져 있는지**를 오른쪽 패널에 그래프로 보여준다. 사실은 LG U+ 유동인구 지표에서 만든 것만 쓴다.

- 이 동은 어떤 워케이션 유형에 맞는지(유형 4개 점수와 이유)
- 하루 중 언제 한산한지(평일·주말 24시간)
- 1년 중 언제 한산한지(시군구 월별)
- 숫자 사실만으로 만든 3문장 브리핑
- 비슷한 동네와, 왜 비슷한지(공통으로 이어진 사실)

패널 그래프는 백엔드 Neo4j 그래프(동 주변 1단계)를 그대로 그린 것이다. 그래프가 보여주기용 그림이 아니라 실제 저장 구조와 같다는 것이 v6의 요점이다.

### 3-1. ⓪ 축소 (387:8601)

- 12개 시군구 경계를 홈(W-01) 히트맵과 같은 색 규칙으로 칠한다. 데이터는 `features/heatmap`의 `useHeatEntries`를 재사용한다.
- 시군구를 누르면 그 경계로 확대하고 ①로 간다.
- 패널: 제목 `지역을 골라 보세요` + 안내 상자 "지도에서 시군구를 눌러 보세요. 누르면 그 시군구의 동네들이 유형별로 이어진 그래프가 열려요." 데이터가 없어 로딩이 없다. (Figma ⓪의 "이 범위의 태그" 막대는 쓰지 않는다.)

### 3-2. ① 확대 (388:8695)

- 지도: 그 시군구의 행정동 이름 핀(`pins` API). 핀 = 동 이름 + 태그 아이콘 최대 2개(응답 `tags` 앞 2개). 범례에 아이콘 뜻과 "출처: 한국관광공사".
- 패널: **시군구 지식그래프** (Figma ①의 태그 막대 대신, 새 프레임 §15). 시험용: https://claude.ai/artifact/EsTknW5qYUNhpcAzeX2VuH

```
   (주문진읍)────────▶(장기체류형)◀────────(연곡면)
       │                                      │
       └──────────▶(바닷가)◀──────────────────┤
                                              │
   (경포동)────────▶(관광지)◀─────────────────┘
```

- 헤더: `강릉시` · `강원특별자치도 · 행정동 21곳`. 시군구 노드는 그리지 않는다(모든 동이 같은 시군구라 선이 정보를 주지 않음).
- 노드: 동(시군구의 동 전부) + 사실 노드. 사실 노드 종류마다 색이 다르다.
  | 관계 (칩 이름) | 사실 노드                               | 색                     | 기본 |
  | -------------- | --------------------------------------- | ---------------------- | ---- |
  | 1위 유형       | 장기체류형·로컬살이형·네트워킹형·몰입형 | `primitive/arches/500` | 켬   |
  | 가까움         | 바닷가 (`coastal`)                      | `primitive/babu/600`   | 켬   |
  | 생활           | 생활권 / 관광지 (생활권 지수 0.7 기준)  | `primitive/green/600`  | 켬   |
  | 조용함         | 조용함 S·A·B·C                          | `text/secondary`       | 끔   |
  | 저녁 활기      | 저녁 활기 S·A·B·C                       | `text/secondary`       | 끔   |
- 위에 관계 칩 5개(켜기·끄기). 켜진 관계의 선과, 이어진 동이 없는 사실 노드는 그리지 않는다.
- 배치: **힘 기반 배치**(이어진 노드는 당기고 나머지는 밀어냄, d3-force). 미리 정한 모양이 없다. 같은 사실을 많이 공유하는 동끼리 저절로 모인다. 노드는 끌어서 옮길 수 있다.
- 동 노드: 흰 원 + `brand/primary` 테두리, 지름 = 1위 유형 점수. 사실 노드: 색 채운 원 + 흰 글자, 크기 고정.
- 선 위에 관계 이름(1위 유형·가까움 등)을 쓰지 않는다. 관계 종류는 사실 노드 색과 위 칩으로 구분한다.
- 동 노드 클릭 → **그래프 안에서 강조**(그 동과 이어진 노드·선만 진하게, 나머지 18%) + 패널 아래 선택 카드:
  `연곡면 · 장기체류형 61` / 이어진 사실 칩 / `공통 3: 강동면 · 사천면 · 옥계면`(켜진 관계 기준 공통 사실이 많은 동, 최대 3) / **[동네 자세히 보기]** → ②.
- 사실 노드 클릭 → 그 사실을 가진 동만 진하게 + 카드에 `바닷가 · 이어진 동 10곳` 목록.
- 빈 곳 클릭 → 선택 해제.
- 지도 핀에 마우스를 올리면 그래프에서 그 동을 미리 강조(카드는 열지 않음). 그래프 노드에 마우스를 올리면 지도 핀 강조.
- 그래프 아래 범례(노드 종류 색) + 맨 아래 출처 줄.
- 공통 사실 수는 **탐색용**이다. ②의 '비슷한 동'은 지표 거리(L2)로 고르고 공통 사실은 이유로만 쓴다(백엔드 §2와 같음).
- 지도 핀 클릭 → 바로 ②. 그래프 노드 클릭 → 그래프 안 탐색(위). 둘을 나눈다.

### 3-3. ② 상세 패널 (390:8845, 값은 396:9226)

위에서 아래 순서. 예시는 주문진읍 실측값이다.

1. **헤더**: `주문진읍` · `강원 강릉시` · 바닷가 칩(`바닷가 0.0km`, `coastKm`가 1 이하일 때만).
2. **유형 막대 4개**: 점수 높은 순. 1위 강조. 막대 아래 이유 한 줄.
   - 장기체류형 61 — `숙박 성향 64 · 한산한 달 7개(성수기보다 20% 이상 적은 달)`
   - 문구는 백엔드 `types[].reason`을 그대로 쓴다.
3. **그래프** (Figma ② 링 그래프):
   - 가운데 동 이름, 둘레에 24칸 링(시각별 차량 수, 색 진하기 §2).
   - 링 주변 칩: 등급 칩 3개(조용함·또래 밀도·저녁 활기), 시간대 칩(`도로 한산 · 평일 9시`), 한산한 달 칩(`한산한 달 · 2·4·9월`).
   - 오른쪽 위 `[평일 | 주말]` 토글. 바꾸면 링 색, 시간대 칩 글자(`주말 4시`), 상세 막대가 함께 바뀐다.
   - 링 옆 작은 글씨 `이 동 하루 기준`.
4. **상세 칸** (고정 높이, §4):
   - 시간대 칩 선택 → 24시간 차량 막대. 한산한 시각 막대 강조, 가장 붐비는 시각 표시.
   - 한산한 달 칩 선택 → 12개월 막대(`months.raw`). 한산한 3개월 강조. 제목 옆 `강릉시 기준`. 값이 `null`인 달은 회색 빈 막대.
   - 처음 열 때는 시간대 칩이 선택된 상태(24시간 막대).
5. **이 동네에서 일하는 하루**: `briefing` 3문장을 그대로 문단으로. 칩·번호·링크 없음.
6. **비슷한 바닷가 동** (내륙 동이면 `비슷한 동`): 3행.
   - 행: `속초시 노학동` · `공통 5` · 공통 사실 최대 3개(`저녁 활기 A`, `평일 9시 한산`, `바닷가`) · 점수 차(`조용함 +8 · 또래 +13 · 저녁 −15`).
   - 점수 차 = 상대 − 이 동. 양수는 "상대가 더 높음".
   - 행을 누르면 그 동이 선택된다(그 시군구로 이동 + 패널 교체).
7. **출처 줄**: `LG U+ 유동인구 2025 · 갱신 {syncedAt 날짜}`.

## 4. 상세 칸 — 틀을 미리 잡는 방식

칩을 눌렀을 때 아래 내용(브리핑·비슷한 동)이 밀려 내려가지 않게 한다.

- 상세 칸 높이는 24시간 막대와 12개월 막대 중 큰 쪽으로 **고정**한다(CSS 고정 높이, 내용은 그 안에서 교체).
- 칩 선택은 패널 상태 `detail: 'hour' | 'month'` 하나. 등급 칩은 선택 대상이 아니다(커서 기본, 누름 효과 없음).
- 내용 교체는 페이드(150ms)만 쓴다. 높이 애니메이션 없음.
- 로딩 중에도 같은 높이의 스켈레톤을 둔다.

| 비슷한 동 행                   | 그 동의 시군구로 이동 + 패널 교체       | 필요하면 `pins`, `dongs/{id}` |
| 패널 닫기                      | ①로 (시군구 유지)                       | 없음                          |

- ② 헤더 왼쪽 위에 `← {시군구} 그래프` 링크를 둔다.

### URL 상태

| 키     | 값                        | 기본값   |
| ------ | ------------------------- | -------- |
| `sgg`  | 시군구 id (①)             | 없음 (⓪) |
| `dong` | 행정동 id (②, `sgg` 필요) | 없음     |

- 공통 기반 `useQueryState`. 진입은 `push`(뒤로 가기 = 한 단계 위).
- 평일·주말, 상세 칸 선택, ① 관계 칩·그래프 선택은 URL에 넣지 않는다(동을 바꾸면 평일·시간대로 돌아간다).
- 없는 id, `sgg` 없는 `dong`, 다른 시군구의 `dong` → 그 값을 지우고 한 단계 위로.

## 6. API 계약

백엔드 짝 문서 §6과 같다. 숫자는 주문진읍 예시다.

### 6-1. `GET /api/explore/sigungu/{sigunguId}/pins`

```json
{
  "sigunguId": "51150",
  "dongs": [
    {
      "id": "5115025000",
      "name": "주문진읍",
      "center": { "lat": 37.89, "lng": 128.82 },
      "tags": ["beach", "cafe"],
      "topType": "장기체류형",
      "topScore": 61,
      "coastal": true,
      "life": "생활권",
      "grades": { "quiet": "B", "evening": "A" }
    }
  ]
}
```

- `tags`: 관광공사 동 태그 id, 백엔드 태그 순서. 아이콘은 앞 2개만 쓴다. 없으면 `[]`.
- `topType`·`topScore`: 1위 유형 이름과 점수(시군구 그래프용). `coastal`: 바닷가 여부(`coastKm ≤ 1`).
- `life`: `생활권`(생활권 지수 ≥ 0.7) 또는 `관광지`. `grades`: 조용함·저녁 활기 등급(없으면 `null`). 모두 ① 지식그래프의 사실 노드를 만드는 데 쓴다.
- 시군구 이름·시도 이름은 웹의 시군구 목록(히트맵 데이터)에 이미 있어 이 응답에 넣지 않는다.
- 404 `SIGUNGU_NOT_FOUND`.

### 6-2. `GET /api/explore/dongs/{dongId}`

```json
{
  "id": "5115025000",
  "name": "주문진읍",
  "sigungu": { "id": "51150", "name": "강릉시" },
  "sido": "강원특별자치도",
  "coastKm": 0.0,
  "types": [
    {
      "name": "장기체류형",
      "score": 61,
      "reason": "숙박 성향 64 · 한산한 달 7개(성수기보다 20% 이상 적은 달)"
    },
    { "name": "로컬살이형", "score": 60, "reason": "생활권 지수 0.74" },
    { "name": "네트워킹형", "score": 50, "reason": "또래 밀도 39 · 저녁 활기 62" },
    { "name": "몰입형", "score": 36, "reason": "조용함 31 · 오전 한산 44" }
  ],
  "grades": {
    "quiet": { "grade": "B", "score": 31 },
    "peer": { "grade": "B", "score": 39 },
    "evening": { "grade": "A", "score": 62 }
  },
  "hourly": {
    "weekday": { "driv": [471, "… 24개"], "peakHour": 12, "quietHour": 9 },
    "weekend": { "driv": ["… 24개"], "peakHour": 14, "quietHour": 4 }
  },
  "months": { "raw": [70, "… 12개"], "quiet": [2, 4, 9], "basis": "강릉시" },
  "briefing": ["문장 1", "문장 2", "문장 3"],
  "similar": [
    {
      "id": "5121055000",
      "name": "노학동",
      "sigungu": "속초시",
      "common": 5,
      "commonTop": ["저녁 활기 A", "평일 9시 한산", "바닷가"],
      "diff": { "quiet": 8, "peer": 13, "evening": -15 }
    }
  ],
  "syncedAt": "2026-11-13T10:00:00+09:00"
}
```

(`"… 24개"`는 줄임 표시다. 실제로는 숫자 배열. 유형·등급·평일 시각·한산한 달·비슷한 동 이름과 점수 차는 실측값, 주말 시각·id·`common` 수는 형식 예시다.)

- `types`: 4개, 점수 높은 순. 첫째가 1위.
- `grades.*`: 값이 없으면 그 지표만 `null`. 칩을 숨긴다.
- `hourly.*.driv`: 길이 24, 0~23시, 2025년 월·요일 평균 차량 이동 인구(명). 값 없는 시각은 `null`.
- `quietHour`: 평일은 9~17시 중 최소, 주말은 하루 전체 중 최소. `peakHour`: 하루 전체 중 최대.
- `months.raw`: 1~12월 시군구 ease 원값(그 달 방문 ÷ 연중 최대 월 × 100). `quiet`: 원값 낮은 3개월, 달 순으로 정렬.
- `briefing`: 0개 또는 3개. 0개면 "준비 중"(§9).
- `similar`: 0~3개, 순위순. `commonTop`은 드문 사실부터.
- 404 `DONG_NOT_FOUND`, 503 `GRAPH_UNAVAILABLE`.

## 7. 계산 (`features/explore/`)

- `ringCells(hourly, dayGroup)` → 24칸 `{hour, value, intensity}`. `intensity` = 값 ÷ (평일·주말 48칸 최대). `null`은 0, 회색 표시.
- `hourChipLabel(hourly, dayGroup)` → `도로 한산 · 평일 9시`.
- `monthChipLabel(months)` → `한산한 달 · 2·4·9월`.
- `gradeChipLabel(key, grade)` → `저녁 활기 A / 62점`.
- `diffLabel(diff)` → `조용함 +8 · 또래 +13 · 저녁 −15` (0은 `±0`).
- `buildSigunguGraph(pins, relsOn)` → `{nodes, links}`. 동 노드 + 켜진 관계의 사실 노드(이어진 동이 있는 것만)와 선.
- `sharedFacts(graph, dongId)` → 공통 사실이 많은 동 순 `{dongId, common: factLabel[]}`, 같으면 이름 순.
- 배치는 d3-force(`forceManyBody -260`, `forceLink distance 80`, `forceCollide 반지름+14`, 가운데로 약하게). 처음 위치는 동 id로 정한 고정 씨앗이라 같은 데이터면 같은 모양으로 열린다.
- `pinSkeletons(geo)` → 동 경계 파일에서 동마다 내부 점(폴리곤 중심이 밖이면 가장 큰 고리의 내부 점)과 이름 길이 대신 고정 폭.
- 모두 순수 함수, 각각 `.test.ts`.

### 9-1. 로딩 화면

실제 화면과 **같은 자리·같은 크기**의 회색 상자(스켈레톤)를 둔다. 글자는 넣지 않는다. 데이터가 오면 그 자리에 내용만 채워져 화면이 움직이지 않는다.

| 상황                     | 지도                                                                                           | 패널                                                                                                                         |
| ------------------------ | ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 처음 진입, 지도 SDK 로딩 | 지도 자리 전체를 지도 땅 색에 가까운 회색으로 + 반짝임. 확대·축소 버튼과 범례 자리에 회색 상자 | ⓪ 안내 (로딩 없음)                                                                                                           |
| ⓪ 히트맵 데이터 로딩     | 시군구 경계는 그리고 안을 회색으로. 오면 색이 채워짐                                           | ⓪ 안내                                                                                                                       |
| 시군구 클릭 → 핀 로딩    | 동 경계 파일로 구한 동 위치(`pinSkeletons`)에 회색 알약 핀. 오면 진짜 핀으로 교체              | 헤더 막대 2줄 + 칩 자리 5개 + 그래프 자리에 회색 원(동 수만큼, 경계 파일에서 앎) 흩어 놓기, 선 없음. 오면 원이 제자리로 퍼짐 |
| 동 클릭 → 동 상세 로딩   | 핀은 그대로, 누른 핀만 선택 표시                                                               | 헤더 막대 2줄 → 유형 막대 4줄 → 회색 도넛 링 + 칩 자리 5개 → 상세 칸 상자(고정 높이) → 문장 3줄 → 비슷한 동 3행              |

- 0.2초 안에 끝나면 스켈레톤을 띄우지 않는다(깜빡임 방지). 한 번 띄우면 최소 0.4초 유지.
- 반짝임: 왼쪽 → 오른쪽 1.5초 주기. `prefers-reduced-motion: reduce`면 반짝임 없이 회색만.
- 색: Figma 변수와 같은 이름의 CSS 변수. `explore/skeleton/base`(패널, gray/100), `explore/skeleton/map`(지도 위 — 땅 색 위에서 보이도록 gray/300), `explore/skeleton/shine`(반짝임, gray/50).
- Figma 컴포넌트: `Explore/Skeleton/Block`(429:9357), `Explore/Skeleton/MapBlock`(429:9358).
- 스크린 리더: 로딩 영역에 `aria-busy="true"`, 패널에 숨김 문구 "불러오는 중".
