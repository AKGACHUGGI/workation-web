## 1. 목적

시군구 하나를 골랐을 때 "이 달, 이 프리셋으로 여기가 어떤 곳인지"를 한 페이지에서 설명한다. W-02 티어리스트 카드에서 들어오는 것이 주 경로이며, 점수·순위·등급은 **W-02와 같은 함수·같은 데이터**로 계산해 두 화면의 숫자가 항상 일치한다.

### 3-1. 히어로

- 브레드크럼: `탐색(/)` › `{province}` › `{name}`. province는 링크 없음.
- 제목: `{name}, {province}`.
- 메타 줄: `{tags.join(' · ')} · {month 라벨} · 2025 LG U+ 유동·서비스인구`.
- 태그 칩(`Tag` 컴포넌트, Figma Tag): `tags[]`(해안 등) + **계절 유형**(`SEASON_LABEL[seasonType]`) + **프리셋 순위** `"{프리셋 라벨} {rank}위 · {grade}"`(선택 색).
- 우측 `공유`(URL 복사, 토스트 "링크를 복사했습니다") · `저장`(즐겨찾기 = 로그인 필요 → W-07 모달).
- 갤러리: `photos[0]` 크게, `photos[1..4]` 2×2. `사진 모두 보기 · {photos.length}장` → 모달 그리드.

### 3-2. ScoreCard (`features/region/components/ScoreCard`)

| 요소     | 값                                                                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 큰 숫자  | 프리셋 종합 점수 `Math.round(composite)`                                                                                                                                   |
| 한 줄    | `{프리셋 라벨} 프리셋 · {N}곳 중 {rank}위 · {grade}`                                                                                                                       |
| 세부     | `{month 라벨} 기준 · 조용 {g} · 시기 {g} · 또래 {g} · 숙박 {g} · 활기 {g}` (`metricGrade`, `METRIC_SHORT_LABEL` 순서)                                                      |
| 요약 4칸 | ① `시기 여유` 등급 + "{month} 혼잡 {crowdIndex}" ② `낮 유입 지수 {dayInflow}` + "{N}곳 중 {quietRank}위" ③ `숙박 계수 {overnightCoef}` ④ `주말 ÷ 주중 낮 {weekendRatio}배` |

- `preset=custom`이면 한 줄은 `직접 설정 ({선택 지표 짧은 라벨 · 구분}) · …`, 세부 줄에서 고르지 않은 지표는 흐리게(W-02 §3-5와 동일).

### 3-3. 핵심 지표 5종 (`MetricCard` ×5)

| 지표        | 점수               | 부제                                                       |
| ----------- | ------------------ | ---------------------------------------------------------- |
| 시기 여유   | `scores.crowd`     | `{month} 혼잡 {crowdIndex} · 연중 최대 대비 {crowdIndex}%` |
| 동네 조용함 | `scores.quiet`     | `낮 유입 지수 {dayInflow} · {N}곳 중 {quietRank}위`        |
| 또래 밀도   | `scores.peer`      | `20~40대 방문 비율 {peerShare}%`                           |
| 숙박 성향   | `scores.overnight` | `숙박 계수 {overnightCoef} · {OVERNIGHT_COPY}`             |
| 저녁 활기   | `scores.vibe`      | `저녁 유동 ÷ 저녁 체류 · {RANK_COPY}`                      |

- `OVERNIGHT_COPY`: 계수 ≥ 0.9 "방문객 대부분 숙박", ≥ 0.7 "숙박·당일 혼합", 그 외 "당일 방문 위주".
- `RANK_COPY`: 백분위 ≥ 75 "상위권", ≥ 50 "중상위", ≥ 25 "중하위", 그 외 "하위권".
- 섹션 우측 캡션: `{month 라벨} · 시군구 {N}곳 백분위`. 등급 배지는 `metricGrade(score)`.

### 3-4. 월별 혼잡 지수 (`MonthlyCrowdChart`)

- 막대 12개 높이 = `months[i].crowd`(0~100). 색: `bestMonths` 초록(`signal-*` 토큰), `avoidMonths` 빨강, 나머지 회색. 선택한 `month`는 라벨 굵게. 범례 "시기 여유 · 가기 좋은 달 · 피할 달".
- 막대 hover 툴팁: `{m}월 · 혼잡 {crowd}`.
- 우측 3줄: `가기 좋은 달 {bestMonths}` / `피할 달 {avoidMonths}` / `또래 많고 덜 붐비는 달 {peerOffpeakMonths} (또래 비중 ↑ · 혼잡 ↓)`. 달 목록은 `"2 · 3월"` 형식(`formatMonths`).
- 막대 클릭 → `month` 쿼리 변경(`push`). 2차: 연령대 토글.

### 3-5. 주중·주말 차이

- 큰 숫자 `weekendRatio`(소수 2자리) + `WEEKEND_COPY`: < 0.9 "주중형", < 1.15 "균형형", 그 외 "주말형".
- 막대 2개: 주중 낮 = 기준 길이, 주말 낮 = 기준 × ratio (최대 폭 넘으면 둘 다 비례 축소).
- 문장: 균형형 "주말에 낮 체류인구가 {±p}% {늘어나는|줄어드는} 수준으로 주중·주말 차이가 작습니다. 요일과 상관없이 비슷한 밀도를 기대할 수 있습니다." / 주말형 "주말에 낮 체류인구가 {p}% 늘어납니다. 조용한 체류가 목적이면 주중 도착·주말 외곽 동네 이동을 권합니다." / 주중형 "주말에 낮 체류인구가 {p}% 줄어듭니다. 주말이 오히려 한산한 지역입니다."

### 3-6. 추천 사유 (`buildReason`)

입력 `ReasonInput = { presetLabel, composite, rank, total, grade, overnightCoef, dayInflow, crowdIndex, crowdGrade, bestMonths, peerOffpeakMonths }` → 문장 4개를 이어 붙인다.

1. `{month} {presetLabel} 프리셋 종합 {composite}점으로 {total}곳 중 {rank}위({grade})입니다.`
2. 숙박: 계수 ≥ 0.9 `숙박 계수 {c}로 방문객 대부분이 밤에도 머무는 숙박형 지역이고,` / ≥ 0.7 `숙박 계수 {c}로 숙박과 당일 방문이 섞여 있고,` / 그 외 `숙박 계수 {c}로 당일 방문 비중이 큰 지역이고,`
3. 조용함: dayInflow < 0.8 `낮 유입 지수 {d}로 근무 시간에 사람이 몰리지 않습니다.` / ≤ 1.0 `낮 유입 지수 {d}로 낮 인구 변화가 크지 않습니다.` / 그 외 `낮 유입 지수 {d}로 낮에 사람이 몰리는 편입니다.`
4. 시기: crowdGrade가 S·A `{month}은 연중 최대의 {crowdIndex}%로 한산한 편입니다.` / 그 외 `다만 {month} 혼잡은 연중 최대의 {crowdIndex}%로 시기 여유는 {crowdGrade}입니다. 더 한산한 때를 원하면 {bestMonths}, 또래가 많으면서 덜 붐비는 때는 {peerOffpeakMonths}입니다.`

캡션 "규칙 기반 템플릿(MVP) → 2차 LLM 문장"은 그대로 둔다. `buildReason`은 순수 함수로 테스트한다.

### 3-7. 행정동 N곳 (`DongRow` ×N)

- 제목 `행정동 {dongs.length}곳`, 캡션 `동네 조용함순{excludedNote}` — 제외 동이 있으면 ` · {이름}은 특수시설 패턴으로 제외`.
- 정렬: `quietScore` 내림차순.
- 행: 이름(16px) · 종류 태그(`생활권`/`관광지`) · 부제 `{landmark} · {peakMonth}월 피크 · {month}은 피크의 {crowdOfPeak}%`(peakMonth === 선택 월이면 `{month}이 자체 피크`) · 우측 `동네 조용함 {GradeBadge}` + `›`.
- 클릭 → `/dongs/{dong.id}` (`useCarryLink`).
- 2차: 성수기 피난처·동네 고유 피크 열.

### 3-8. 워케이션 노트 (읽기)

- 제목 `워케이션 노트 · {name}`, 캡션 `로그인 사용자 {total}명의 팁 · 도움순`.
- 작성창(`TipComposer`): 클릭/포커스 시 로그인 필요 → W-07 모달. 로그인 상태 UI는 W-07 스펙 이후.
- `TipCard`: 아바타(이니셜) · 닉네임 · `{relativeTime} · {dongName} · {stayLabel}` · 방문 월 태그 · 본문 · `도움돼요 {n}` `답글 {n}` · `신고`. 버튼은 로그인 필요 동작.
- 처음 3개 표시, `더 보기`로 10개씩.

### 3-9. 체감 투표 · 이달의 사진 (읽기)

- `ReactionPoll`: 질문 `{month} {name}, 실제로 조용했나요?` (프리셋 quiet) / `…활기 있었나요?` (lively) / custom은 `…어땠나요?`. 비율 막대 + `그래요 {p}%` `아니요 {q}%` + `{n}명 참여 · 지표 검증에 반영돼요`. 투표 클릭 → 로그인 필요.
- 사진 타일 3개 + `이달의 사진 올리기`(로그인 필요).

### 3-10. 지원사업 · 숙박 · 관광

- `links[]`를 종류 태그 · 제목 · 도메인 · 외부 링크 아이콘으로 나열(`target=_blank rel=noopener`). 캡션 `region_link (수동 관리)`.

### 3-11. PlanCard (사이드바, sticky top)

| 요소                                                   | 동작                                                                                     |
| ------------------------------------------------------ | ---------------------------------------------------------------------------------------- |
| `{composite}점 · 종합` / `{N}곳 중 {rank}위 · {grade}` | ScoreCard와 같은 값                                                                      |
| 방문 월 select                                         | `month` 쿼리 변경 (`연간` 포함 13개)                                                     |
| 체류 기간 select                                       | `1주 · 2주 · 한 달` — 표시 전용(계산에 영향 없음). 즐겨찾기 메모로 전달할 예정(W-08)     |
| 프리셋 select                                          | `preset` 쿼리 변경. `custom`이면 W-02 링크 "직접 설정은 티어리스트에서" 안내             |

| `공유하기`                                             | URL 복사                                                                                 |
| 요약 4줄                                               | 가기 좋은 달 / 피할 달 / 주말 ÷ 주중 낮 체류 / 지원사업(첫 번째 `links` 중 kind=support) |

## 4. URL 상태

| 키        | 값                              | 기본값           |
| --------- | ------------------------------- | ---------------- |
| `month`   | `annual` \| `2025-01`~`2025-12` | `2025-12` (공통) |
| `preset`  | `quiet` \| `lively` \| `custom` | `quiet` (공통)   |
| `metrics` | custom일 때                     | W-02와 동일      |

- `month=annual`이면 월 의존 문구는 "연간"으로, 월별 막대의 선택 강조는 없음, 체감 투표는 최신 달 기준으로 표시하고 캡션에 명시.
- 존재하지 않는 `sggId` → 404 페이지(`NotFoundPage`).

## 5. API 계약

### 5-1. 재사용: `GET /api/tier?month={month}&scope=sigungu` (W-02 §5)

점수·순위·등급·세부 등급은 이 응답으로 계산한다. 쿼리 키가 같으므로 W-02에서 넘어오면 캐시를 그대로 쓴다.

### 5-2. `GET /api/regions/{sggId}?month={month}`

```ts
// features/region/types.ts
export type SeasonType = 'summer_beach' | 'spring_autumn' | 'second_half_rise' | 'flat'
export type DongKind = 'living' | 'tourist'
export type LinkKind = 'support' | 'stay' | 'tour'

export type RegionDetailResponse = {
  id: string
  name: string // 고성군
  province: string // 강원특별자치도
  tags: string[] // ['해안', '속초시 인접']
  seasonType: SeasonType // 계절 NMF 최대 비중 유형
  photos: { url: string; credit?: string }[]
  month: MonthParam
  stats: {
    crowdIndex: number // 해당 월 방문 ÷ 연중 최대 × 100 (annual: 평균)
    dayInflow: number // 평일 낮 체류 ÷ 새벽 체류 (소수 2자리)
    quietRank: number // dayInflow 오름차순 순위 (시군구 중)
    peerShare: number // 20~40대 방문 비율 % (정수)
    overnightCoef: number // 숙박 계수 (소수 2자리)
    weekendRatio: number // 주말 낮 체류 ÷ 주중 낮 체류 (소수 2자리)
  }
  months: { month: number; crowd: number }[] // 1~12, crowd 0~100
  bestMonths: number[] // crowd 최저 2개월, 오름차순
  avoidMonths: number[] // crowd 최고 2개월
  peerOffpeakMonths: number[] // peer_offpeak 최고 2개월
  dongs: RegionDong[]
  excludedDongs: { name: string; reason: 'special_facility' | 'masked' }[]
  links: { kind: LinkKind; title: string; url: string }[]
}

export type RegionDong = {
  id: string
  name: string
  kind: DongKind
  landmark: string // '거진항', '송지호 해안' … 수동 관리
  quietScore: number // 전체 행정동 중 day_inflow 백분위 (낮을수록 높음), 0~100
  peakMonth: number // 동 자체 혼잡 최대 월
  crowdOfPeak: number // 선택 월 혼잡 ÷ 자체 최대 × 100 (annual: 100)
}
```

산출 규칙(계약): `stats`·`months`는 수동면 등 특수시설 동을 제외한 합계로 계산한다(W-02 백분위와 같은 모집단). `peerOffpeakMonths`는 시군구 내 또래 비중 z − 혼잡 z 상위 2개월. `seasonType`은 소속 동의 계절 NMF 비중 평균 중 최대.
