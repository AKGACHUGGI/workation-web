## 1. 테마 구조

- 테마 상태는 `<html data-theme="light|dark">` 하나로 관리한다.
- `src/index.css`의 `@theme`는 지금처럼 라이트 값을 기본으로 둔다. 다크 값은 `:root[data-theme="dark"]`에서 의미 토큰만 다시 정의한다.
- `[data-theme="light"]` 블록에 라이트 의미 토큰을 한 번 더 적는다. 지도 컨테이너에 `data-theme="light"`를 붙이면 그 안쪽은 라이트 값으로 되돌아간다. CSS 변수는 상속되므로 지도 안 핀, 범례, 배지, `mapStyle.ts`의 `var(--color-…)`가 모두 라이트로 계산된다.
  - 다크 블록과 라이트 블록이 같은 토큰 목록을 갖도록, 라이트 블록은 다크 블록 바로 위에 두고 같은 순서로 적는다.
- `color-scheme`도 같이 바꾼다(`:root[data-theme="dark"] { color-scheme: dark }`, 라이트 범위는 `light`). 스크롤바, 입력창, 날짜 선택 같은 브라우저 기본 UI도 어두워진다.
- 원시 색(rausch, gray, babu 등)은 바꾸지 않는다. 다크 값이 필요하면 기존 원시 색을 고르고, 없을 때만 원시 색을 추가한다(예: 다크 바탕용 회색 `gray-850` 같은 단계).

## 4. 전환 동작

### 4-1. 화면이 그려지기 전 적용
`index.html` `<head>`에 짧은 인라인 스크립트를 넣는다. 화면이 그려지기 전에 `data-theme`를 붙여서, 새로고침할 때 흰 화면이 번쩍이지 않게 한다.

1. `localStorage`의 `theme` 값을 읽는다(`'light' | 'dark'`). 읽기는 try/catch로 감싼다.
2. 저장값이 없거나 읽지 못하면 `matchMedia('(prefers-color-scheme: dark)')`를 따른다.
3. `document.documentElement.dataset.theme`에 결과를 넣는다.

### 4-2. `useTheme` 훅
- 위치: `src/hooks/useTheme.ts`
- 반환: `{ theme: 'light' | 'dark', toggle: () => void }`
- 저장값이 없으면 시스템 설정 변경(`matchMedia` `change` 이벤트)을 실시간으로 반영한다.
- `toggle`은 반대 테마를 `<html>`에 적용하고 `localStorage`에 저장한다. 쓰기도 try/catch로 감싼다. 저장에 실패해도 현재 화면은 바뀐다.
- 한 번 저장하면 이후로는 저장값이 시스템 설정보다 우선한다.

### 4-3. 내비바 버튼
- `Navbar.tsx` 오른쪽 `data-slot="auth-menu"` 안, 언어 버튼 바로 옆에 둔다. 모양은 언어 버튼과 같다(`text-text-primary hover:bg-bg-subtle size-10 rounded-full`).
- 라이트에서는 달 아이콘, `aria-label="다크 모드로 전환"`. 다크에서는 해 아이콘, `aria-label="라이트 모드로 전환"`.
- 아이콘이 바뀔 때 살짝 회전하며 교체된다. `motion-reduce`에서는 회전 없이 바로 바뀐다.

### 4-4. 전환 순간 처리
테마가 바뀌는 순간에는 화면 전체 transition을 한 프레임 동안 끈다(`<html>`에 잠깐 클래스를 붙여 `transition: none !important`). 각 요소의 색 전환 시간이 제각각이라 화면이 얼룩지게 바뀌는 것을 막는다.

## 5. 지도 라이트 고정

- `DongMap`, `ExploreMap`, `RegionHeatmap`의 가장 바깥 컨테이너에 `data-theme="light"`를 붙인다. 공통 `GoogleMapProvider`나 `MapLoadGuard`에 붙일 수 있으면 그쪽에 한 번만 붙인다.
- 지도 타일(Google `mapId` 스타일)은 건드리지 않는다.
- 지도 로딩 스켈레톤도 지도 범위 안이면 라이트로 보인다. 다크 페이지에서 회색 사각형이 밝게 보이는 것은 의도한 동작이다.

## 6. 쫀득한 세그먼트 토글

### 6-1. 대상
- `src/components/ui/Segmented.tsx` 사용처 8곳: HourlyCurveSection:72, DongSearchList:48, DongPickerModal:46, HeatmapControls:19, TierControls:32, MetricGroupTabs:30·40, TierHeader:18, ComparePage:78
- `src/features/explore/components/panel/DayToggle.tsx` (지도 탐색 주중/주말)

### 6-2. 구조
- 지금은 버튼마다 선택 색을 칠한다. 바꾼 뒤에는 선택 표시를 **움직이는 칸(thumb)** 하나로 분리한다. 칸은 컨테이너 안에서 `absolute`로 위치하고, 버튼은 그 위에 글자만 그린다.
- 선택된 버튼의 `offsetLeft`, `offsetWidth`를 재서 칸의 `left`, `right`를 정한다. 컨테이너 크기가 바뀌면(`ResizeObserver`) 다시 잰다.
- 처음 그려질 때는 움직이지 않고 제자리에 나타난다.
- 값이 `null`이면 칸을 숨긴다(지금 동작 유지).
- `ink`/`surface` 두 모양, `size` `sm`/`md`, `className`, 접근성 속성(`role="tablist"`, `role="tab"`, `aria-selected`)은 그대로 유지한다. 칸에는 `aria-hidden`을 붙인다.
- `DayToggle`은 같은 칸 로직을 쓰도록 맞춘다. `Segmented`로 바꿔 끼울 수 있으면 바꾸고, 크기나 모양이 맞지 않으면 칸 로직만 공통 훅(`src/hooks/useSlidingThumb.ts`)으로 빼서 같이 쓴다.

### 6-3. 모션
내비바 탭 밑줄(`TabIndicator`)의 앞끝·뒤끝 전환 방식을 그대로 가져온다. 새 라이브러리는 쓰지 않는다.

1. **움츠림** (약 80ms): 칸이 제자리에서 가운데로 작아진다. `scaleX` 약 0.92, `scaleY` 약 0.90. Web Animations API로 처리한다.
2. **늘어남**: 가는 방향의 앞끝이 먼저 움직이고 뒤끝이 늦게 따라온다. 오른쪽으로 갈 때는 `right`가 빠르고 `left`가 느리며, 왼쪽으로 갈 때는 반대다. 잠깐 칸이 두 칸에 걸쳐 길게 늘어난다.
3. **도착**: `--ease-spring`으로 살짝 지나쳤다 돌아오며 멈추고, 크기도 1로 돌아온다.

- 전체 450ms 안쪽.
- 글자색은 칸이 지나가는 시점에 교차한다(선택 → 새 선택 칸 글자색, 이전 칸은 `text-secondary`로).
- 굵기는 바꾸지 않는다. 굵기가 바뀌면 글자 폭이 달라져 칸 위치가 흔들린다.
- 선택 안 된 칸: 글자 그대로, `text-secondary`, 마우스를 올리면 `text-primary`.
- `prefers-reduced-motion`: 움츠림과 출렁임을 빼고 바로 이동한다.
- 다크모드에서 칸 색: `surface`는 `bg-surface`, `ink`는 `selected-bg`(다크에서 밝은 색)를 그대로 쓴다. 토큰만 따르므로 따로 처리하지 않는다.

## 8. 테스트

### 단위 (vitest)
- `useTheme`
  - 저장값이 있으면 시스템 설정보다 우선한다
  - 저장값이 없으면 시스템 설정 변경을 반영한다
  - `toggle`이 `<html data-theme>`와 저장값을 바꾼다
  - `localStorage`가 예외를 던져도 동작한다
- 내비바 테마 버튼: 라벨과 아이콘이 테마에 따라 바뀐다
- `Segmented`
  - 기존 테스트가 그대로 통과한다
  - 선택이 바뀌면 칸 위치(`left`, `right`)가 새 버튼 기준으로 갱신된다
  - 값이 `null`이면 칸이 숨겨진다
- `DayToggle`: 기존 동작(주중/주말 전환)이 그대로 유지된다

### e2e (playwright)
- 다크로 바꾼 뒤 새로고침해도 다크가 유지된다
- 다크에서 지도 컨테이너 안 요소의 계산된 배경색이 라이트 값이다
- 시스템 설정을 다크로 에뮬레이션(`colorScheme: 'dark'`)하고 저장값이 없으면 다크로 시작한다

### 수동 확인
- 홈, 랭킹, 지역, 동 프로필, 비교, 지도 탐색, 마이 화면을 다크로 한 번씩 본다
- 차트, 토스트, 툴팁, 모달, 사진 캡션, 카카오 버튼을 확인한다

- 원시 색 팔레트 전면 개편
